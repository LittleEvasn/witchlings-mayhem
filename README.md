# Witchlings' Mayhem · 마녀들의 사고현장

Godot 4.6.2 / 1인용 루미 경로 / 0.9

## 최신 플레이 · 루미 한 판

시작 부품 선택 → 이야기·조작 안내 → 5웨이브 → 보스 → 루미 일반 결말 → 두 오브 결과·재도전.
일반 전투90/105/120/135초, 보스 제한150초로 전투 최대10분. 제작·편집·시험은 전투 시계와 분리하며 준비 완료를 직접 누른다. 준비 포함12~15분은 목표이며 실제 준비 시간은 제한하지 않는다.
웨이브 보상은 중복 없는 유물, 마석으로 구체 제작/강화. 소리 설정·최근10회 기록·루미 단서만 저장되며 실험 도중 이어하기 저장은 없다.

에디터 없는 Windows 실행: `artifacts/builds/lumi-run/WitchlingsMayhem.exe`.
재빌드: `python tools/build_lumi.py`. 구현과 남은 사항: [루미 한 판](docs/LUMI-RUN-v1.md).
아래 0.6~0.8 설명은 개발 이력이다. 이전 구체 수/패시브/60초 상점 문구보다 최신 구현 보고와 PROJECT-HANDOFF가 우선한다.

## 실행

이 폴더의 `project.godot`를 Godot에서 열고 **F5**, 또는 `Play.cmd` 실행.
기본 창 1280 × 800, 논리 화면 1440 × 900. 창 비율이 달라지면 화면 비율을 유지한다.

## 공격 구체 강화·합성 · 0.8

상점의 **강화 · 합성** 탭에서 공격 구체 9종을 +4까지 강화한다. 같은 종류의 낮거나 같은 단계 구체 하나를 소모하면 무료이며, 중복이 없으면 기존 돈인 마석(G)을 사용한다. 도감에 있는 두 종류를 각각 +4로 만들면 12 G로 새 공격 마법 한 개를 합성한다. 합성 마법 5종에도 기존 보조와 연결을 사용할 수 있다.

장착한 구체는 제작 결과로 자동 교체된다. 제작은 즉시 확정되므로 조합 편집의 되돌리기로 취소되지 않는다. 재료·수치·검증과 남은 밸런스 문제는 [강화·합성 보고](docs/SPELL-FORGE.md)를 참고한다.

## 두 오브와 공격별 편집 · 0.7

공격을 먼저 고르고 보조를 붙이는 작업대로 변경했다. 두 오브는 각각 6칸짜리 독립 주문과 시전 주기를 가진다. 시작 시 오브 2는 비어 있으며 보유 구체를 공유한다. 보조 10종은 공격 9종 모두에 장착 가능하다. 상세 동작과 검사 결과는 [오브 작업대 보고](docs/ORB-WORKBENCH.md)를 참고한다.

## 마법 특화 개편 · 0.6 기반

총 22종 구체(공격 9·보조 10·연결 3), 네 시작 꾸러미, 상점 연구 구매를 추가했다. 구현 범위·수치·검증·남은 밸런스 문제는 [마법 특화 구현 보고](docs/MAGIC-BUILDS-IMPLEMENTATION.md)를 참고한다.

- 작은 정원: 접목 장판을 같은 자리에 키우기.
- 큰 한 발: 응축으로 느리고 강한 공격.
- 반짝 연사: 각인을 쌓아 폭발시키기.
- 얼음 실험: 냉기 축적 → 동결 → 파쇄.
- 추가 공격: 서리숨결·벼락·달무리 위성·잔불 발자국. 추가 연결: 소멸 후·귀환 후.

## 한 판

작은 마녀 실습장에서 적을 피하며 자동으로 주문을 시전한다. 마나는 없다.
90/105/120/135초의 실습 네 번을 버티고 끝없는 모범답안을 처치하면 승리한다.
마지막 실습의 제한 시간은150초. 전투 시간은 최대10분이며 보상/조합/시험 시간은 제외한다.

| 조작 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 커서 방향으로 조준. 공격은 적 유무에 관계없이 자동 시전 |
| Space | 이동 방향 회피, 짧은 무적, 재사용 1.7초 |
| Tab | 전투: 조합 편집·적용 / 상점: 조합 적용 / 시험: 상점 복귀 |
| Esc | 일시정지 / 전투 편집 취소 / 시험에서 상점으로 복귀 |
| M | 효과음 켜기/끄기 |

적이 떨어뜨린 조각은 근처에서 끌어당겨 **돈(G)**으로 습득한다. 자동 레벨 성장은 없다.
실습 완료 시 체력 +15, 놓친 마석 회수, 완료 보너스20G를 받고 **세 유물 후보 중 하나**를 무료로 선택한다.

## 상점과 준비 시간

`전투 → 유물 선택 → 시간 제한 없는 제작·조합 → 준비 완료 → 다음 웨이브`

- 유물12종 중 아직 없는 유물만 제시한다.
- 제작·편집은 시간 제한이 없으며 시험 발사도 전투 시계·획득 기록에 영향을 주지 않는다.
- 연구 목록 1칸에서 원하는 구체를 정가로 선택 구매하고, 나머지 3칸은 무작위로 진열한다. 연구 구매는 상점당 한 번이며 새 상품(5 G)으로 횟수가 초기화되지 않는다.
- 임시 가격: 별빛탄 8 / 명중 후 10 / 꽃폭탄·관통 12 / 갈래 14 / 추적 16 G. 달빛 부메랑·가시꽃 덫·도탄·거대화 14 / 소용돌이·메아리 18 G.
- 돈과 구매 구체는 다음 웨이브로 이월. 다음 웨이브 시작 버튼으로 즉시 출발 가능.
- 시간 종료 시 마지막으로 **적용한 주문**으로 자동 출발. 미적용 편집만 취소하며 구매 물건은 보존.
- 상점은 구체만 판매한다. 유물, 유료 능력 강화, 멀티 교환은 아직 포함하지 않는다.
- 위 시간·가격·보너스는 첫 플레이용 조정값이며 재미나 경제 밸런스 검증 결과가 아니다.

## 적과 웨이브 · 0.5

- 기본 적 → 약한 적 다수 → 돌진 적 혼합 → 근접·원거리 혼합 → 보스와 지원으로 5웨이브를 구분한다.
- 적은 무작위 가장자리에서 개별 출현한다. 생성 위치를 미리 표시하지 않으며, 원거리 적의 실제 공격은 방향선으로 예고한다.
- 상점 제목 아래에서 다음 실습의 적 구성과 특징을 확인할 수 있다.
- 시간표·무리 크기·동시 등장 제한·드롭 상한은 `scripts/waves.gd`에서 조정한다.
- 꽃폭탄은 피해 20, 기본 간격 0.576초로 조정했다. 집중 공격·광역·관통의 역할을 실제 마법 엔진으로 비교했다.
- 변경 수치, 비교 결과, 관련 검증과 남은 재미 문제는 [WAVES-v05](docs/WAVES-v05.md)에 기록했다.

## 조합 작업대 · 0.7

- 상점 한 화면에서 구매, 오브 선택, 공격별 조합, 보유 구체를 함께 사용한다.
- 공격 ①/②를 선택한 뒤 보유 공격을 누르면 교체하고, 보조를 누르거나 공격 카드에 끌면 부착한다. 내부 보조 → 공격 순서는 자동 정리한다.
- ‘공격 순서 ⇄’는 보조까지 묶어서 순서를 바꾸고, ‘다른 오브로 ↗’는 한 공격 묶음을 다른 오브로 옮긴다.
- 보조를 다른 공격 카드로 드래그하면 옮긴다. 우클릭하거나 보유 목록에 놓으면 해제한다. 공격 카드의 ×는 해당 묶음을 비운다.
- 두 오브가 보유 수량을 공유한다. 동일한 사본을 중복 장착할 수 없고, 종류별 최대 4개까지 판매한다.
- 편집 도중의 불완전한 조합은 허용하고, 문제 칸과 이유를 표시한다. 유효한 조합만 적용·시험할 수 있다.
- 되돌리기는 두 오브의 최근 30회 편집을 함께 보관한다. ‘기존 주문’은 선택한 오브를 마지막 적용 상태로 되돌린다.
- 구매한 종류는 보유 목록에서 강조한다. 구매·진열 변경으로 편집 내용이 사라지지 않는다.
- ‘시험 발사’는 준비 시간을 멈추고 경기장에 반격하지 않는 표적 4개를 표시한다. WASD·회피로 움직일 수 있고, 마우스를 위쪽 경기장에 두면 자동 시전한다.
- 시험 중 아래 작업대에서 조합을 바꾸면 즉시 반영한다. 구체를 끌거나 작업대를 조작할 때는 새 발사가 멈춘다.
- 시험에는 실제 마법 엔진과 구매한 구체만 사용한다. 시험 표적은 죽거나 돈을 드롭하지 않는다.
- 시험 종료 시 투사체·장판·덫·메아리·표적을 정리하고 플레이어 위치·전투 통계를 복원한다.
- ‘주문 적용’은 조합을 확정한다. ‘적용하고 다음 웨이브’는 유효한 편집 조합을 적용하고 출발한다.
- 준비 시간 종료 시 미적용 편집은 취소되고 마지막 적용 조합으로 출발한다. 구입한 구체는 유지한다.

## 마법 조합

최대 6칸, 최대 두 단계. 왼쪽에서 오른쪽으로 해석한다.

`보조 + 공격 → 연결(명중 후 / 소멸 후 / 귀환 후) → 보조 + 공격`

예: `갈래 → 추적 → 별빛탄 → 명중 후 → 꽃폭탄`. 보조는 생략해도 된다.

- **별빛탄**: 빠른 직격 탄환.
- **꽃폭탄**: 명중하거나 수명이 끝나면 범위 폭발.
- **달빛 부메랑**: 약 0.65초 날아간 뒤 현재 플레이어 위치로 귀환. 왕복 각 구간 적 1명, 관통을 넣으면 각 3명. 나갈 때 추적·도탄 적용, 귀환은 플레이어 우선.
- **소용돌이 씨앗**: 적과 접촉하거나 약 272px 비행 후 3초 소용돌이 설치. 처음 0.35초 모은 뒤 0.25초마다 약한 피해. 보스는 끌어당기지 않음.
- **가시꽃 덫**: 씨앗이 적과 접촉하거나 비행 종료 시 설치. 0.25초 후 무장, 접근한 적에게 범위 피해 후 소멸. 미발동 상태는 6초 후 소멸.
- **도탄**: 다른 적으로 최대 2회. 일반 탄은 먼저 도탄하고 이후 관통. 일반 씨앗은 도탄 뒤 설치하며, 관통 씨앗은 각 접촉 지점에 위력을 나눠 설치한다.
- **거대화**: 투사체 충돌 크기와 폭발·장판 범위 1.6배, 전체 주문 시전 간격 1.2배. 두 단계 모두 장착해도 간격 패널티는 한 번.
- **메아리**: 0.18초 뒤 같은 발사 위치와 방향에서 위력 55% 복사본. 복사본은 다시 복제하지 않지만 자신의 후속 공격은 한 번 발동 가능.
- **갈래**: 뒤 공격을 3갈래로 발사, 각 탄 위력 65%. 이 감소율은 해당 탄에서 발동하는 후속 주문에도 이어진다.
- **추적**: 뒤 공격이 가까운 적을 향해 휘어진다. 상점에서 구입.
- **관통**: 뒤 공격이 적 2명을 더 통과한다. 씨앗은 비행 사거리 2배, 최대 세 곳에 각 1/3 위력으로 설치한다. 남은 몫은 마지막 위치에 모아 설치한다. 상점에서 구입.
- **명중 후**: 각 투사체의 첫 명중 지점에서 다음 공격을 위력 65%로 한 번 발사. 소용돌이·덫은 설치 후 실제 피해를 줄 때 한 번 발동. 부메랑 왕복·도탄·지속 피해로 중복 발동하지 않음. 재시전 간격은 두 공격 중 느린 쪽 기준.

부품 버튼을 누르면 끝에 추가, 주문 칸을 누르면 제거한다. 부품 위에 마우스를 올리면 설명.
구체마다 실제 보유 수량이 있다. 장착은 보유분을 예약하며 제거하면 다시 사용할 수 있다.
같은 구체를 두 번 장착하려면 두 개를 보유해야 한다. 편집 취소로 구매한 물건이 사라지지 않는다.
잘못된 문법은 이유를 표시하고 적용을 막는다. 전투 중 편집은 전투를 멈추지만, 상점에서 편집하면 준비 시간은 계속 흐른다.
전투 중 변경을 적용하면 기존 탄·장판·메아리는 당시 설정으로 끝나고 다음 시전부터 새 주문을 쓴다. 서로 다른 적용 세대는 접목하지 않으며, 변경으로 긴 시전 대기를 줄일 수 없다. 시험 편집에서는 이전 시험 효과를 지우고 새 조합을 바로 반영한다.

새 효과는 구분 가능한 벡터 표시다: 초승달 부메랑, 보라색 나선 소용돌이, 연두색 꽃잎 덫.
기존 12종의 배경 설명은 `docs/SPELLS-v03.md`, 현재 22종의 동작·제한·검증은 `docs/MAGIC-BUILDS-IMPLEMENTATION.md`.

## 구현 범위

- 주인공 루미 1명, 추격 슬라임 / 거리 유지 원거리 임프 / 예고 후 돌진하는 딱정벌레.
- 마지막 보스는 딱정벌레 그림을 크게 사용하며 방사형 탄막과 돌진을 조합한다.
- 체력, 회피 무적, 마우스 조준·자동 시전, 돈, 패시브 보상과 상점, 조합 편집, 승패, 재시작.
- 신규 생성 2D 원화 사용. 기존 MageGame / DuckGame 구매 에셋은 사용하지 않음.
- 캐릭터는 정지 원화에 흔들림·기울기·피격 점멸만 적용. 프레임별 걷기/공격 애니메이션은 아직 없음.
- 투사체·폭발·돈 조각 표시는 코드 기반 벡터 효과, 효과음은 짧은 합성음이다.
- 멀티플레이, 저장/메타 성장, 추가 캐릭터, 다수 스테이지는 이번 범위 밖.

## 구조와 확인

- `scripts/economy.gd`: 돈·보유 수량·무작위 진열·구매·유료 갱신.
- `scripts/spells.gd`: 문법 검증/두 단계 주문 컴파일.
- `scripts/game.gd`: 전투와 한 판 진행, 공간 격자로 주변 적 검색.
- `scripts/spell_runtime.gd`: 투사체 선분 충돌, 왕복·도탄, 지속 장판·덫·메아리. 최대 투사체 180 / 장판 24 / 대기 메아리 32.
- `scripts/actor.gd`: 캐릭터 그림/간단한 움직임.
- `scripts/magic_visuals.gd`: 상한이 있는 가벼운 전투 효과.
- `scripts/interface.gd`: 타이틀/HUD/보상/상점과 조합 작업대/시험/결과.
- `scripts/orb_control.gd`: Godot 기본 드래그 앤 드롭, 중앙 미리보기와 삽입 위치 표시.

`tests/prototype_test.gd`는 이 시제품의 이동, 회피, 명중 연결, 보조 효과, 편집, 보상, 승패, 재시작 및 개체 상한을 검사한다.
`tools/run_tests.py`는 로컬 Godot 실행 경로를 사용한다. 이번 마법 확장 집중 검사는 `python tools/run_tests.py spell_expansion_test`. 결과는 `artifacts/spell-expansion-test-results.txt`.
상점 흐름 검사는 `python tools/run_tests.py shop_flow_test`.
기존 전체 검사 파일은 새 규칙에 맞춰 갱신했지만 이번 작업에서 무관한 전체 검사는 실행하지 않았다.
자동 검사와 재미 평가는 별개다. 첫 판에서 조합 변화가 체감되는지, 적의 압박이 적절한지는 플레이 피드백으로 조정해야 한다.

새 이미지의 생성 방식과 프롬프트는 `assets/art/GENERATION.md`에 기록했다.
Godot 공식 참고: [입력 처리](https://docs.godotengine.org/en/4.6/tutorials/inputs/inputevent.html), [2D 스프라이트](https://docs.godotengine.org/en/4.6/tutorials/2d/2d_sprite_animation.html).

이번 작업 집중 검사는 `python tools/run_tests.py workbench_test` (41개). 네이티브 창 입력 검사는 `tests/workbench_input_probe.gd`를 실행 중인 게임에서 호출한다. 상세 기록은 `artifacts/VERIFICATION-v04.md`.


## 마법 측정실

시작 화면 → **마법 측정실**. 구체를 자유롭게 편집하고 단일·밀집·일렬·분산·계속 접근 환경에서 실제 피해, 과잉 피해, 접촉률, 폭발·장판·연계, 효과별 기여를 측정한다. JSON·CSV 자동 저장과 로컬 일괄 실행 도구를 제공한다. 사용법·측정 조건·한계는 [MEASUREMENT-LAB.md](docs/MEASUREMENT-LAB.md) 참고.

측정실은 정가와 시작 구체를 제외한 추가 구매 비용을 함께 표시한다. 연계 상속·거대화·관통 씨앗의 조정과 전후 비교는 [BALANCE-PASS-1.md](docs/BALANCE-PASS-1.md) 참고.

현재 연계 주문은 느린 공격 기준으로 재시전한다. 상점·편집·시험 화면에도 간격을 표시한다. 같은 6개 구체의 16배치 비교와 보상 관측은 [BALANCE-RECAST.md](docs/BALANCE-RECAST.md)에 정리했다.
