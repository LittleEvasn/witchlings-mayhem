# 오브 확장·선택 강화 — 개편 2 구현

2026-10-29. `CONTENT-AND-CORE-REDESIGN-v1.md` 8절을 바탕으로 구현했다. 마법/구체 강화와 별개로 오브 자체에 성장 이력을 저장한다.

## 획득과 비용

- 새 판은 **오브 1개, 6칸**으로 시작한다. 시작 조합도 여기에만 놓인다.
- **6/12/18분 휴식부터** 각각 2/3/4번째 오브를 제작할 수 있다. 추가 가격은 **100/160/240마석**. 해금은 다음 휴식에도 유지하며 아직 해금되지 않은 오브는 살 수 없다.
- 추가 오브는 빈 상태다. 이미 가진 공격을 무료 복제하거나 기존 구체를 자동 이동하지 않는다. 네 개가 최대다.
- 선택한 오브의 강화는 **최대 다섯 번**. +1~+5 비용은 **30/50/75/105/140**마석이다. 후보 세 개 중 하나를 고를 때만 소비한다.
- 후보는 중복 없이 제시하며, 닫았다가 다시 열어도 같은 후보를 유지한다. 현재 조합에 더 이상 적용되지 않는 조건부 후보가 있다면 유효 후보로 재구성한다. 선택 직전에도 조건·오브·단계·경제 revision을 재검사한다.
- 모든 가격은 첫 경제 가설이다. 30분 사람 플레이에서 구매율·강화율을 확인한 최종 밸런스 수치가 아니다. 오브 추가 500 + 네 개 전부 강화 1600 = 총2100마석이며, 한 판에 전부 만강을 보장하지 않는다.

## 강화 후보

| 후보 | 한 번의 효과 | 같은 오브 한도 / 조건 |
| --- | --- | --- |
| 여분 소켓 | 오른쪽에 빈칸 +1 | 2회, 최대8칸 |
| 빠른 순환 | 순환 후 대기 -8% | 2회, 합산 -16% |
| 강한 코어 | 이 오브 피해 +12% | 2회, 합산 +24% |
| 넓은 파동 | 크기·반경 +10% | 2회, 합산 +20% |
| 코어 완충 | 실제 피격 후 다음 독립 주문 대기 면제 | 1회, 재사용8초, HP/보호막 소비 필요 |
| 빠른 순차 | 독립 공격 사이 간격 -20% | 2회, 합산 -40%, 독립 공격2개 이상 |
| 오래가는 코어 | 투사체·위성·장판 수명 +15% | 2회, 합산 +30%, 해당 공격 보유 |
| 빠른 전개 | 날아가는 투사체 속도 +15% | 2회, 합산 +30%, 해당 공격 보유 |
| 집중 조준 | 순위 분산 대신 가장 가까운 적 조준 | 1회, 오브2개 이상 |
| 연계 안정기 | 연결 후속 위력 +10%p, 최대100% | 1회, 강화 여지가 있는 연결 필요 |

빠른 순환은 장판 틱이나 후속 연결 지연을 줄이지 않는다. 빠른 순차는 별도 간격에만 적용한다. 이중 사건은 기존의 두 가지 50% 예산을 유지하므로 연계 안정기가 바꾸지 않는다. 일반 +3 연결/지연 점화 등 이미100%인 연결만 있다면 안정기를 제시하지 않는다.

기본 후보 다섯 종류만으로도 마지막 다섯 번째 결정까지 세 종류 이상이 남는다. 현재 매 시전 시 표적을 새로 정렬하므로, 설계의 선택 후보였던 ‘여유 있는 조준’은 실질 차이가 없어 제외했다. 이름만 다른 빈 효과로 후보 수를 채우지 않았다.

## 실행·편집·저장

- 오브1~4는 기본적으로 첫째~넷째 가까운 적을 각각 조준한다. 표적이 부족하면 마지막 유효 표적을 공유한다. 집중 조준은 해당 오브만 첫째 적으로 바꾼다. 기존 낙뢰의 주변 무작위 배치는 유지한다.
- 피해/크기/수명/속도는 시전 트리에 적용하며 후속·복제·합성 내부 효과에 두 번 곱하지 않는다. 피해는 한 번의 시전자 스냅샷을 자식이 재사용한다.
- 슬롯 추가는 오른쪽으로만 한다. 빈칸·부분 실행·강화/합성 위치·되돌리기는 유지한다. 강화로 얻은 용량을 되돌리기로 줄이거나 무료 확장하지 않는다.
- 제작대는 오브 탭으로 편집 대상을 바꾸며, 시험·개인창·전투 HUD·결과에도 네 개/여덟 칸을 표시한다. 개인창 오브 목록은 스크롤로 접근하며 일반 인벤 비정지는 유지한다.
- 준비 저장에 오브별 선택 이력·남은 후보·용량을 기록한다. 이미 존재하는 두/세 오브 저장은 제거하지 않는다. 옛 속도+1/+2/+3은 사용한 강화 횟수로 계산하고 순환·순차 간격 모두 기존 성능을 legacy 보정으로 보존한다. +3의 세 번째 투자는 별도 legacy 사용 이력으로 남겨 새 상한 밖의 같은 후보를 지급하지 않는다.
- 구형 저장도6칸, 새 저장은 실제 선택에 따른6~8칸을 엄격히 검사한다. 잘못된 자료를 조용히 잘라내거나 재고를 삭제하지 않는다.
