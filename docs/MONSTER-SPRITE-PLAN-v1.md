## 1. 무엇을 12종으로 세는가

‘종’은 **독립된 기본 실루엣/원화** 기준이다. 같은 몸통의 색/소품 교체는 파생형, 같은 원화의 체력·속도 변경은 전투 데이터다. 거대한 기존 딱정벌레 보스는 새 원화가 아니다.

현재 3개를 살리고 신규9개를 만든다. 새9개가 각자 독립 AI9개를 필요로 하지는 않는다. 공통 추격/측면접근/돌진/원거리/특수보상 행동을 재사용하고 눈에 보이는 중요한 차이만 추가한다. 보스는 별도2외형 제작 대상으로 관리한다. 이번 12개에 포함하지 않는다.

세계관은 ‘숙제 대신 움직이게 만든 실습 도구/실패작들이 마석을 품고 날뛴다’. 모든 적을 인형처럼 비슷한 몸통으로 만들지 않고 젤리·종이·금속·천·버섯·도자기 형태로 구분한다. 미소녀 SD 주인공을 중심에 두고, 공포보다는 사고를 일으키는 귀여운 위험물이라는 인상을 유지한다.

## 3. 등장 비율과 압박

총 동시300명을 목표로 할 때 전부 복잡한 적으로 채우지 않는다. 정해진 통로 예고로 적이 한곳에서만 나오는 방식으로 되돌리지 않는다. 기본 출현은 플레이어 화면 바깥 여러 방향 무작위, 전술 적만 짧은 출현/공격 예고를 사용한다.

| 전투 시간 | 활성 일반 외형 수 | 역할 구성 목표 |
|---|---:|---|
| 0~6분 | 1/2/3/4 + 드문11 | 기본 추격75%, 빠른 측면15%, 돌진≤8%, 보상≤2% |
| 6~12분 | +5/6/8 | 단순 추격70% 이상, 전술 적 합계≤25%, 특별보상≤5% |
| 12~18분 | +7/9/10 | 원거리 동시≤6, 돌진 예고/돌진중 합계≤4, 압박정예≤1 |
| 18~30분 | +12, 기존 파생 혼합 | 모든12종 동시등장을 목표로 하지 않음. 해당 구간 주력4~6외형+특수 |

기존3외형과 신규9외형의 출시 종류 비율은25:75다. **출현 수 비중까지25:75로 강제하지 않는다.** 초반에는 기존3개가 절반 이상, 후반도 단순한 기존 젤리/박쥐가 주력 떼에 남는다. 새로운 그림을 샀다는 이유로 기본 떼를 전부 교체하지 않는다.

큰 적은 시야를 점유하는 대신 머릿수를 줄인다. 가마솥을 플레이어 바로 위에 생성하거나 물리적으로 탈출 불가능한 원을 만들지 않는다. 피격 판정은 발밑 몸통 기준이며, 뿔/날개 끝이 스쳤다고 피해를 받게 하지 않는다.

## 4. 생산용 공통 명세

현재 SD 아틀라스(1254×1254 RGBA)를 스타일 기준으로 사용한다. 진한 외곽선·단순한3단계 명암·둥근 양감·작은 눈과 큰 몸통 대비를 보존한다. 도트 에셋과 섞거나 캐릭터보다 적의 세부 묘사를 더 높이지 않는다. 색은 소재 구분용이며 원거리/정예/폭발 위험은 실루엣·소품·예고를 함께 쓴다.

- 2D 사선 위에서 내려보는 현재 시점. 정면에 가까운3/4, 오른쪽 기준으로 좌우 반전 가능. 바닥 그림자는 별도 공유 그림자를 재사용한다.
- 원본 캔버스512×512 RGBA/투명, 일반 본체가 대략320~400px 안에 들어오게. 정예는 같은 캔버스에서 크게 그리는 대신 게임 표시 크기를 별도 데이터로 둔다.
- 일반 pivot=(256,420), 발밑 중심. 날개/모자 등 장식으로 pivot을 바꾸지 않는다. 손수레 같은 넓은 원형도 같은 발밑 기준. 충돌 반경은 원화 바운딩박스에서 자동 산출하지 않고 몸통으로 지정.
- 이번 최소 생산은 **기본 정지 이미지12장(기존3 재사용+신규9)**. 현재 bob/기울기/깜빡임 동작을 먼저 재사용한다. 정지 그림을 걷기 애니메이션이라고 보고하지 않는다.
- 출시 모션 최소안: 공통 idle2/run4/hit1/death3=10프레임×12=120프레임, 같은 포즈를 공유하는 프레임은 파일 중복을 피할 수 있다. 현재3종도 모션을 추가하려면 이 수량에 들어간다.
- 중요 공격 별도: 딱정벌레 windup2/dash1/recover1, 토끼 jump3/land1, 가마솥 압박 windup2, 버섯 fire3, 촛대 fuse3/explode3, 마도서 rotate3, 보상 주머니 flee2, 손수레 roll2. 총량은 위120과 별도26프레임 목표이며 기존 공통 프레임 재사용 시 실제 신규 수를 줄인다. VFX가 필요한 폭발은 캐릭터 원화와 별도 명세.
- 각 새 외형별 고유512 PNG 하나는 약1MiB 비압축. 120프레임을 모두512로 VRAM에 상주시키면 약120MiB(밉/패딩 제외)이므로 실제 표시 크기에 맞춘256 파생본/아틀라스/로드 정책을 먼저 확인한다. 투명 여백을 비싼 텍스처로 반복하지 않는다.
- 파일 예: `assets/art/enemies/leaf_jelly/idle_00.png`, 파생은 `variant_inkbag` 등 명시. 라이선스·제작 출처·수정·검수 상태를 함께 기록. 아직 생성되지 않은 파일을 있는 것처럼 등록하지 않는다.

### 필요한 매니페스트 필드

`id / base_family / existing_or_new / role / variant / source / rights_note / canvas / pivot / displayed_height / collision_radius / animation / frames / atlas / approval_status`.

작성한 기계 판독용 목록: [MONSTER-ASSET-MANIFEST-v1.json](MONSTER-ASSET-MANIFEST-v1.json). 신규 파일의 실제 path는 null이며 계획 경로만 별도 기록했다. 기존3종의 현재 크기/피벗을512 표준으로 이미 변환한 것으로 읽으면 안 된다.

## 5. 실제 제작 순서

1. 기존3개를 따로 잘라 둔 참조 시트와 크기/피벗/판정 명세. 그림 재생성은 하지 않음.
2. 대표 새 적 **태엽 토끼1개**로 소재·눈·선·밀도·움직임 방향을 결정. 수정해야 하는 그림 수를 최소화.
3. 첫 묶음3개: 답안지/토끼/가마솥. 기본 떼·도약·압박의 서로 다른 실루엣 확인.
4. 둘째 묶음3개: 잉크단지/방울버섯/촛대. 원거리와 바닥 위험의 가독성 검수.
5. 셋째 묶음3개: 방패 마도서/도둑 주머니/보급 손수레. 전술·보상 출현 연결.
6. 12종의 공통 모션과 중요 공격 포즈. 이 작업 전에는 임시 그림/최종 모션을 구분해서 보고.
7. 보스 별도2외형: 12분 구간 정예형 보스1, 30분 최종보스1을 재사용 가능한 다른 실루엣으로 제작. 보스 등장 시각/휴식 조건은 현재6분 고정 휴식을 변경하지 않고 별도 논의.

완료 기준은 고정 시드 대량 배치에서 주력 적/원거리/돌진/정예/보상 구별, 이동로 안전, 공격 예고 일치, 실제 크기 판독, 프레임 p95와 드로콜이다. 12장 제작 완료와 재미/30분 난도 검증 완료는 다른 항목이다.
