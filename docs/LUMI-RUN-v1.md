# 루미 한 판 · 구현/검증 기록

사용자 승인: 루미 한 명으로 시작→성장→완성 조합 활용→보스→일반 엔딩→결과·재도전 경로를 완성한다. 최신 시간 목표는 전투8~10분, 자유 제작 포함12~15분이며 이전 출시회의5분 기준보다 우선한다.

## 이번 구현
- `run_content.gd`의 5장: 90/105/120/135/150초. 일반 전투7분30초, 보스 제한2분30초. 보스를 빨리 처치하면 짧아진다. 편집/준비/시험은 전투 시간에 포함하지 않는다.
- 기존 시작부품4종 선택→루미 이야기/조작 안내→전투. 선택은 캐릭터4명이 아니라 시작 조합4종이다.
- 무작위 출현 유지. 약30초 주기의 짧은 생성속도 완화만 추가. 전투방향/위치를 미리 고정하지 않는다.
- 웨이브 드롭 상한48/64/78/90/24, 기존 완료보상20×4 유지. 보스 전 최대수입360G. 상한은 실수입/적정 난이도의 증거가 아니다.
- 보스 `끝없는 모범답안`: 조준 고정 탄막/고정 위치 예고폭발/예고돌진. 체력50%에 탄막5→7발, 폭발1→3곳. 무적·속성면역·강제조합 없이 기존 마법으로 공격 가능. 기존 갑주벌레 그림 재사용, 독립 보스 아트 완성은 아님.
- 보스 무작위 배치 실패시 화면밖 외곽의 결정적 위치를 재검사. 생성 전에는 전투 시계를 소비하지 않는다. 중복 생성 방지.
- 승리/사망/시간초과 분리→루미 일반 결말→두 오브/유물/전투·준비 시간/획득 마석 결과. 다시시작과 타이틀 복귀.
- 설정(효과음/음악)·최근10회 결과·루미단서만 user://profile-v1.json에 저장. 진행 중인 실험은 이어하기 저장하지 않는다. 손상된 주파일은 백업에서 읽고 오류를 안내한다. 영구전투강화 없음.
- 자체 합성한 짧은 음악3곡을 준비/전투/보스에 사용. 원본샘플 없는 재현 가능한 음악 스케치(`tools/compose_run_music.py`), 최종 음질/취향 승인 전. 캐릭터/맵은 기존 이미지를 유지.

## 담당과 조사 근거
- 총괄/구현: 현재 세션 Sol6.1/high.
- Luna/high 읽기 조사: 시작키트→start_run, complete_wave→reward→shop→launch_next_wave, 끝날때 시험·결과 격리 지점 확인. 현재5분·수입272G상한·보스생성실패 미복구·마지막드롭 누락 지적. 테스트나 편집은 하지 않음.
- 독립검토: 구현 후 상태전이/보스/프로필/시간격리의 구체적 결함 위주로 별도 기록.

## 검증 상태
- `python tools/run_tests.py lumi_run_test`: **62검사/0실패**. 순서/시간경계/보상중복/자유제작·시험격리/보스3패턴·배치대체·중복/치명타정리/사망·시간초과/재시작/결과/프로필 재로드·구조손상 복구.
- `prep_board_test`: **35검사/0실패**. 기존 드래그·두 오브·강화·되돌리기·시험·수동 다음 웨이브 유지. 새 마법 전수검사는 하지 않았다.
- `tests/lumi_run_probe.gd`: 시드20261026, 60Hz 실제 전투 엔진 전체경로. 무적·가장가까운적조준·원형이동 봇이 실제 제작안을 구입하고 마석 강화. 마지막 결과 **전투475.45초(약7분55초)**, 보스전25.38초. 누적수입68/152/250/360/372G, 단계별처치79/149/149/190/10. 끝날때 주력+4·메아리/갈래/각인과 두번째 소용돌이 오브. 3웨이브 전에 주력+4를 완성하고 마지막 일반전투+보스까지 활용했다. 자동봇이라 인간 생존난이도/12~15분 체류시간·재미의 근거는 아니다.
- 헤드리스 계산단계 p95 약0.81~1.03ms. 별도의 실제 100렌더프레임 표본 p95 **17.944ms**, 당시 적48/탄16/장판0. 이는 극한 유물·장판 조합/저사양 전체성능 검사가 아니다. 기존 극한 생성량 문제는 별도 남아 있다.
- 실제 Godot4.6.2 화면: 타이틀·인트로·제작·보스예고·승리결말·결과. 보스 제목/안내문 겹침과 강조버튼 포커스 글자 대비를 수정 후 재확인. 스크린샷은 배치/상태를 검수하도록 런타임으로 해당 장면을 구성했으며, 사람의 자연스러운 완주 영상이 아니다. 검사중 결과는 실제 사용자 프로필에 저장하지 않았다.
- 독립검토 Sol6.1/high가 결과기록 구조손상/전투중편집시간누락 두 결함 보고→총괄 수정→검토자 읽기 재확인. 상세 `LUMI-RUN-REVIEW-v1.md`.
- `python tools/build_lumi.py`: 에디터 없이 실행되는 Windows x86_64 단일 EXE **108,531,824bytes**. 일반 창/헤드리스 시작·종료 모두 exit0, 오류·경고 없음. MCP 도우미와 개발파일은 배포에서 제외. project.godot의 SHA-256 유지. 설정/프로필 파일 저장·복구는 위 엔진 검사, 배포본은 시작 스모크 확인이며 완주 조작 검사는 소스 실행에서 수행했다.
