# 마석 회수와 피해 숫자 · 2026-10-29

사용자 범위: **응축은 개편하지 않는다. 마석 회수와 피해 숫자만 구현한다.**

## 마석
- 직접 가까이 가서 줍는 마석: 기존처럼 돈과 경험치 지급, 습득 유물 효과 유지.
- 6분 간격 휴식 때 남은 마석: 전액 돈만 지급. 경험치·레벨업·습득 회복 효과 없음. 이미 얻은 경험치는 보존한다.
- 회수할 목록을 먼저 비운 뒤 지급하여, 상자 선택 때문에 휴식 처리가 재진입해도 중복 지급되지 않는다. 기존 미지급 처치값 반환도 돈만 지급한다.
- 기존 승리 시 남은 마석의 돈 회수도 같은 함수를 사용한다. 패배 시 남은 마석 폐기는 기존대로다. 시험 발사는 회수/돈 지급 없음.
- 휴식 회복 15와 클리어 보상, 상자 보상, 경험치 곡선은 변경하지 않았다.

## 피해 숫자
- 공통 damage_enemy 경로에서 실제 깎인 체력 min(요청 피해, 남은 체력)을 표시한다. 예: 체력 10에 50 피해 → 10. 측정기의 피해 기록은 기존 규칙을 유지한다.
- 시험 표적은 체력이 줄지 않는 기존 규칙을 유지하며 측정기에 기록한 피해를 표시한다.
- 기존 Jua 글꼴, 밝은 숫자와 어두운 외곽선, 짧은 확대/상승/사라짐. 0.60초 후 제거한다. 가짜 치명타 표시는 추가하지 않는다.
- 같은 적에 0.12초 안에 들어오는 연타는 실제 피해를 합산한다. 첫 표시 시간을 연장하지 않는다. 적당 최대 2개, 화면 전체 최대 64개, 화면 밖 표시는 생략한다. 생략은 표시만 제한하며 피해량을 바꾸지 않는다.
- 가독성을 위해 10 이상은 정수, 1~10은 소수 1자리, 1 미만은 소수 2자리로 반올림한다. 0.01 미만은 <0.01. 합산 원값은 보존한다.
- 하나의 공유 Node2D가 그리며 피격별 노드/Label/Tween을 만들지 않는다. 전투 RNG를 소비하지 않는다. 보상 정지 동안 숫자도 정지, 시험/마법 정리 시 이전 숫자 제거.
- 설정의 ‘피해 숫자’ 토글로 끄고 켤 수 있고 다음 실행에도 유지한다. 옛 프로필에는 기본 켜짐.
