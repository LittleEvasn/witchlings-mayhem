# 30분 생존·보상 상자·오브 제작 — 2026-10-28

사용자의 최신 뱀서식 진행 결정을 구현한 두 번째 묶음이다. docs/VS-GROWTH-v1.md의 첫 묶음에 이어 적용한다. 과거 짧은5웨이브/유료 합성/두 오브 고정 문서보다 이 문서와 실제 코드가 우선한다.

## 한 판 진행
- 전투시간 0~6/6~12/12~18/18~24/24~30분의5구간. 6·12·18·24분에 무제한 제작 휴식. 휴식은 보스 처치가 아닌 전투시간 기준이다.
- 보상 선택, 보상 후 편집, 제작, 시험, Esc 일시정지는 전투시간에 포함하지 않는다. 평소 인벤토리는 비정지.
- 30분에 최종 보스가 등장한다. 이후에도 전투가 계속되며 처치해야 승리한다. 예전150초 시간초과 패배는 제거했다. 실제 한 판은30분+보스전+플레이어 준비/선택시간이다.
- 휴식 진입 때 남은 마석/상자를 회수한다. 대기 보상을 먼저 순서대로 처리하고 제작으로 진입한다. 생성 예약/투사체/적 공격은 휴식에서 정리한다.
- 예전 짧은 구간의 준비 저장은 같은 순서의6분 휴식으로 옮긴다. 새 저장은 run_rules=survival-30-v1로 구분하며 현재 전투시간을 그대로 복원한다.

## 보상 상자와 합성
- 압박 정예(sentinel) 처치 시 상자를 남긴다. 플레이어70거리 안에서 획득, 휴식 때 남은 상자는 회수한다. 원래 있던 정예 외에 전투120초 간격으로1마리 압박 정예를 시도한다. 이미 정예가 있거나 입구가 막히면1초 후 재시도하며 예약을 쌓지 않는다.
- 일반 상자는 보유 중이며+3미만인 마법만 강화 후보로 낸다. 새 마법/유물은 레벨업 또는 제작에서 얻는다. 후보 소진 시 돈/회복으로 대체한다.
- 지정된 부모 두 종류가 모두+3이면 다음 상자에 합성 선택지를 최소1개 보장한다. 여러 조합이 준비되면 그중 무작위로 선택한다. 공격9/보조7/연결2의 기존 완성형18종을 그대로 사용한다.
- 합성은 무료. 부모 실물2개를 소비하고 완성형1개를 생성한다. 장착 부모도 소비한다. 소비된 공격 때문에 고아가 된 사건 연결을 다른 공격에 몰래 붙이지 않고 가방으로 해제한다.
- 기존 첫 부모의 장착 자리에 완성형을 배치한다. 부모가 가방에만 있으면 결과도 가방에 생긴다. 획득 후 정지된 편집 창에서 배치할 수 있다.
- 같은 완성형은 한 판에 한 번. 소비한 기본 종류는 다시 보상/제작에 등장하여0단계부터 다시 얻을 수 있다. 기존 합성 도감은 재료 안내용이며 제작함의 유료 합성은 차단했다.

## 오브·유물 제작
초기 조정값이며 최종30분 경제 밸런스를 검증한 수치가 아니다.

| 항목 | 현재 구현 |
|---|---|
| 시작 오브 |2개, 각각6칸 |
| 추가 오브 |180마석, 세 번째 오브까지 |
| 오브 강화 |선택 오브의 시전 속도+10%씩, 최대3단계(+30%),60/120/180마석 |
| 실제 간격 |기존 순차/순환 간격 ÷(1+0.1×오브단계). 다른 오브는 영향 없음 |
| 유물 제작 |휴식마다 미보유 후보 최대3종, 각80마석, 중복 소유 불가 |

- 기존 마법 제작/중복 자동+1/마석 직접+1은 유지한다. 오브·유물은 별도 탭에서 제작한다.
- 세 번째 오브도 독립 시전, 세 번째 가까운 적을 조준하며 표적 부족 시 기존 공유 규칙을 따른다. 기존 개별 구체를 여러 오브에 복제하지 않는다.
- 넓은 제작함은 오브 선택 버튼3개와 현재 오브부터2행을 표시한다. 좁은 시험 창은 오브 순환 버튼으로3개 모두 접근한다. 전투 개인창/HUD/결과도3오브를 처리한다.
- 저장에 오브 수·강화·유물 후보·획득 유물·완료 합성·대기 상자 원인을 보존한다. 오래된 구매 영수증/이전 오브 강화 버튼은 거절한다. 새 판에서는 모두 초기화한다.

## 적 물량·드롭
- Waves.WAVES 한 곳에서 구간별 적 조합/체력/동시 제한/무리를 조정한다. 정상 구간 동시 상한80/150/220/280/300, 전체 안전 상한320. 원거리 동시 제한0/2/4/6/8, 돌진 적1/3/4/6/8.
- 시간별 보충 목표15→70→140→210→270→300. 0.25초마다 부족량을 최대10명까지 무작위 화면 밖에 보충한다. 추가로12~18초 간격의 시간차 무리가 존재한다. 생성 예고 위치를 HUD로 알려주지 않는다.
- 화면 밖/플레이어220안전거리/적끼리 진입 간격 검사를 유지한다. 상한·위치 검사에 실패한 요청을 무제한 적재하지 않는다. 최종 보스 뒤 지원 목표는180이며 이미 존재하는 적을 강제로 지우지는 않는다.
- 기존 구간별 돈 드롭 예산을 제거했다. 일반 적3처치당1마석, 튼튼한 적3마석, 현장 운반자/호위는 기존 별도 보상. 마석1당 경험치2/돈1은 유지. 휴식 완료20마석/체력15회복도 유지한다.
- 단독 정예 HP=350+누적 전투초×1.5, 최종 보스 HP30000. 모두 초기 조정값이며 실제 사람의 한 판 플레이 난도/경제 검증은 별개다.

## 성능과 한계
- 수정 전300마리/강화 갈래·별빛탄·명중후 벼락/위성 조건에서 CPU 분리 측정: 타깃 정렬 약3.39ms, 적 갱신6.42ms, 전체 평균11.93ms. 헤드리스3초 샘플이며 렌더링 FPS가 아니다.
- 타깃 정렬은 실제 오브 시전 때만 수행. 로컬 적 분리 조향은10Hz로 분산 계산하고 이동·공격은 기존 물리틱마다 수행한다.
- 기존 그림자/체력바를 공통 캔버스 패스로 묶고 엔진 Y정렬로 몸체 앞뒤 순서를 유지했다. 별도 적 그림을 만들지 않았다.
- 실제 렌더300마리/2오브 부하에서 드로콜921→463, 관측 프레임 평균18.66→17.40ms, p95 24.57→22.44ms. 짧은 샘플이고 전후 미세한 적 위치/발사 수가 달라 엄밀한 전체 성능 개선율로 해석하지 않는다.
- 마지막 고정시드3오브 부하(갈래·거대화·별빛탄·명중후 벼락 / 위성 / 꽃폭탄·소멸후 소용돌이): CPU 평균6.81ms/p95 13.58ms, 렌더 프레임 평균18.21ms/p95 24.54ms, 적300·투사체9·영역4·드로콜567. **60FPS 고정은 아직 보장하지 못한다.** 혼잡할 때 프레임 흔들림이 남는다.
- 재현 도구 tools/survival_render_probe.gd는 별도 게임 검사 세션에서만 호출한다. 불사300마리 조건이므로 일반 적의 생존시간/돈/난도와 다르다.
- 전체30분에 걸친 마법 성장·휴식 제작 가격·보스HP·마석 총량의 재미/경제 밸런스는 실제 플레이로 추가 확인해야 한다. 자동 통과를 재미 개선 근거로 쓰지 않는다.
