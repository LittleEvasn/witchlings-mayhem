## 비용 절감의 실제 상태

에이전트를 나눈 것만으로 사용량이 줄었다고 입증하지 못했다. 현재 정확한 토큰 사용량/금액과 같은 업무를 단독으로 처리한 대조군 기록이 없으므로 절감률·원화를 만들지 않는다. 여러 직원의 반복 열람과 인계는 오히려 사용량을 늘릴 수 있다.

비용 관리는 총괄 업무다. 별도의 '비용관리 AI'를 고용하지 않는다.
- 작은 수정/검증은 총괄이 처리한다. 좁은 조사만 Luna, 위험한 상태/수량 변경만 독립 검토, 게임 방향이 막힐 때 또는 사용자가 요청할 때만 Astra/high.
- fresh 최소 문맥, 질문 범위 제한, 동시 보조1명, 재위임금지, 실패 반복 호출금지, 무관한 전체 검사금지를 유지한다.
- 기획 완료를 이유로 자동 재회의/자동 추가 작업을 만들지 않는다. 대시보드의 상태 확인·기록은 모델 호출과 구분한다.
- 이번은 사용자 지정 Astra/high1회뿐이다. 총괄이 BGM 제거/공식자료/직원 기록을 병행했고 추가 조사·QA·재검토 모델은 부르지 않았다. 사용량 수치는 미제공으로 기록한다. 고비용 모델을 호출한 이번 한 건 자체를 토큰 절약 실적으로 주장하지 않는다.

게임 기획 결과는 GAME-IDEAS-ENEMIES-AND-REWARDS-v1.md. 보상·몬스터 개선은 제안이며 이번 BGM 변경과 구분한다.
