# 제작 체크포인트·발견 도감 v1

2026-10-28. 로드맵 3번의 실제 구현 기록이다. 1번 제작함과 2번 타이틀 흐름 위에 연결했다. 보조·연결 최종 합성, 구매 GUI, 새 아트는 이번 범위가 아니다.

## 플레이어에게 달라진 점

- 웨이브를 마치고 유물을 고른 뒤 준비 시간에 자동 저장한다. 구체 구매·강화·합성·조합 편집·미수령 보상 수령 등의 변경도 저장하며, 준비 시간은 5초마다 갱신한다.
- 제작함의 **저장 후 타이틀**로 나간 뒤 타이틀의 **이어하기 · N웨이브 준비**로 돌아온다. 유효한 저장이 없으면 이어하기 버튼은 나오지 않는다.
- 저장 범위는 **웨이브 사이 준비 시간**이다. **준비 완료로 전투를 시작하면 이전 체크포인트를 폐기한다. 전투 도중 종료한 실험은 이어할 수 없다.** 타이틀과 제작함에서 이 경계를 안내한다. 전투 중 임의 저장이나 이전 준비 구간으로 되돌리기는 구현하지 않았다.
- 이어할 준비 상태가 있을 때 새 실험을 확정하면 교체 확인을 거친다. 취소하면 기존 저장을 유지한다. 저장 실패 시 준비 완료·타이틀 복귀·정상 종료를 중단하고 화면에 실패 이유를 표시한다.
- 타이틀과 제작함에서 발견 도감을 연다. 주문 18종 / 공격 완성 합성 9종 / 유물 12종을 구분한다. 실제 얻은 항목만 발견 처리하고, 제작 후보를 구경하거나 시작 조합을 미리보기만 해서는 해금하지 않는다.
- 발견한 주문은 기본/+1/+2/+3 행동을, 유물은 효과·발동 조건을 보여 준다. 미발견 합성은 재료 +3 두 개와 12마석이라는 힌트를 제공한다. 도감에서 아이템을 지급하거나 장착하지 않는다.
- 발견 기록은 실험 실패·새 실험에서도 남는다. 영구 능력치 보너스는 추가하지 않았다.

## 저장 내용과 경계

`scripts/run_checkpoint.gd`가 `user://checkpoint-v1.json` 및 `.bak`에 동일한 최신 체크포인트를 저장한다. 프로필은 기존 `user://profile-v1.json`에 선택적 발견 배열과 완료 실험 ID를 추가한다. 기존 소리 설정·결과·도입 확인 기록은 유지한다.

준비 저장에는 다음이 포함된다.

- 실험 ID, 시작 조합, 완료 웨이브와 전투/준비 시간, 체력과 실험 능력치.
- 플레이어 위치·방향·남은 회피 상태, 두 오브의 강화 구체 순서·임시 편집·되돌리기 이력.
- 마석, 실물 재고, 제작 후보·가격·무료/판매 상태, 연구 구매 여부.
- 유물과 발동 카운터, 아직 수령하지 않은 주문 선택권과 이미 지급한 웨이브 키.
- 완료 웨이브 기록과 측정 카운터, 선택 중인 제작 탭·구체·가방 필터.
- 본체/유물/보상 RNG의 seed와 state. JSON 실수 변환으로 64비트 정밀도를 잃지 않도록 십진 문자열로 보관한다.

적·투사체·시험 표적은 저장하지 않는다. 시험 발사 진입 전에 원래 준비 상태를 저장하며 시험 중 체력·경제·시간·RNG·회피 방향/무적 상태는 준비로 돌아올 때 복원한다. 시험 중 바꾼 조합은 기존 편집 규칙대로 반영하고 복귀 시 저장한다.

스키마, 콘텐츠 버전, 구체 ID/강화, 두 오브의 실물 수량, 제작/유물/보상 데이터를 검증한 뒤 복원한다. 문법이 아직 완성되지 않아 침묵 중인 임시 조합은 합법적인 편집 상태로 보존한다. 과거 콘텐츠 버전의 호환을 임의 추정하지 않는다.

각 미러는 임시 파일 쓰기·flush·이름 교체를 거친다. 높은 sequence의 유효한 파일을 택한다. 전투/새 실험을 시작하기 전 두 미러에 폐기 표식을 기록하므로 주 파일을 잃어도 예비 파일에서 소비된 체크포인트가 살아나지 않는다. 읽을 수 없는 파일을 덮기 전 `.unreadable-타임스탬프` 사본을 남기며 사본 보존에 실패하면 덮어쓰기를 중단한다. 디스크·OS의 모든 장애를 보장하는 시스템은 아니다.

발견은 실제 인벤토리/유물 획득 경로에서 기록한다. 기존 프로필은 남아 있는 최근 결과의 두 오브·유물 정보를 발견 목록으로 옮긴다. 과거에 얻었지만 결과에도 남지 않은 항목까지 역추정하지 않는다. 같은 실험 ID의 종료 결과를 중복 집계하지 않는다.
