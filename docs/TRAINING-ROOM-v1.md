# 마법 자유 훈련장 · 2026-10-30

타이틀의 **마법 훈련장 · 자유 실험**으로 진입한다. 기본30·합성30을 자유 장착하며 기본 구체 강화 0~3단계를 선택한다. 네 오브 모두 8칸, 기존 드래그·우클릭 해제·빈칸 배치를 재사용한다. 편집 즉시 자동 발사에 반영된다. 기존 시험용 고정 표적 네 개를 재사용하며 죽거나 반격·보상을 주지 않는다.
