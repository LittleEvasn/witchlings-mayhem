## 실제 구현

기존 젤리·박쥐·딱정벌레를 재사용하고 신규9개를 추가했다. 색 변경이나 기존 보스 확대는 새 종으로 세지 않는다. 몬스터 ID와 기존 전투 kind1/2/3을 분리하여 피해/속도/보상 배열을12칸으로 잘못 인덱싱하지 않는다. 기본 추격·돌진·사격을 재사용하면서 필요한 행동만 추가했다.

속도·HP·표시 크기·판정 반경·종별 상한·등장 풀은 `scripts/monster_catalog.gd`. 실제 기본 속도는 기존 kind는 combat_tempo, 새 일반 종은 catalog.speed+구간×2다. 정예/보상 역할은 기존 전용 공식과 별도 속도를 사용한다. 최근 플레이어200/일반92~100 설정을 유지했다. 토끼 도약300은 짧은 공격 구간에만 적용한다.

- 기존 무작위 화면 밖 생성/6분 간격 휴식/30분/후반300상한 유지. 기존 생성 요청 안에서 종을 고르며 별도 대량 생성기를 만들지 않았다. 등장 비율·cap·인구 목표를 한꺼번에 늘리지 않았다.
- 단순 젤리·종이·박쥐가 주력. 잉크8/토끼6/버섯6/마도서6/촛대4/정예1 상한. 후반 원거리 전체 상한8은 유지. 진행 중인 돌진·사격·도약·자폭 예고를 합쳐 최대4로 제한한다. 딱정벌레는650거리 내에서만 새 돌진을 예고한다.
- 잉크 위험은 최대10개, 지속 중 편집으로 지울 수 없다. 휴식/재시작/타이틀/종료 때 정리한다. 재배치 시 도약/예고 상태 초기화.
- 방패 방향은 발밑 금색 호, 회전 중 붉은 예고로 읽는다. 방향이 없는 피해는 임의로 막지 않는다. 실제 HP/측정기/피해 숫자는 방패를 반영한 같은 피해를 사용한다.
- 기존 운반자 코드는 요청 호출이 없어 자연 등장하지 않았다. 구간75초에 한 번만 연결했다. 안전한 자리 실패 시 생성 빚을 쌓지 않는다. 일찍 잡은 그룹은 기존 보상 상자1개를 떨어뜨리며, 기존 가까이서 회수하는6XP 재료 기회도 유지한다. 놓쳤다고 무료 보상을 자동 지급하지 않는다. 기존 가격/경험치 곡선/마법·유물 종류는 변경하지 않았다.
- 손수레 호위는 리더 생존 중 편대를 따르며, 리더 사망 후에는 일반 접근. 그룹 처치 상자는 마지막 호위까지 처치한 후 한 번만 생성.

## 아트와 한계

`assets/art/enemies/monsters-v1.png` 공용1024×768 아틀라스, 개별256 PNG12개, 발밑 피벗128/240. 실제9개 신규 그림은 built-in image_gen으로 기존 SD 아틀라스를 참고해 생성했다. 태엽 토끼를 대표로 고른 뒤 같은 스타일의8종 가족 시트를 만들었다. 보존 원본/정확한 프롬프트/가공 경로는 `assets/art/enemies/PROMPTS-AND-PROVENANCE.md`, 가공 스크립트 `tools/prepare_monster_art.py`(Pillow), 머신 목록 `assets/art/enemies/manifest.json`.

현재는 종당 **정지 이미지1장**에 기존 bob/기울기/깜빡임과 토끼 수직 이동을 적용한다. 걷기/사망/고유 공격 프레임을 제작한 것으로 보고하지 않는다. 신규 보스 외형도 만들지 않았다. 출시 최종 아트 승인·정식 모션 제작은 남아 있다. 구입/Pixel Crawler 재도입/Cubism 사용 없음.
