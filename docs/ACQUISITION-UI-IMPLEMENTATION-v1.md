# 개편3 — 획득 UI와 안전한 자동 장착

2026-10-29. 개편1 고정 슬롯/부분 실행과 개편2 오브 성장을 유지한 기능 구현이다. 최종 GUI 아트 확정이나 전체 UI 재제작은 아니다.

## 구현
- 레벨업/상자: 전장 위 중앙 3장 카드, 큰 기존 아이콘, 공격·보조·연결·유물·완성 합성 역할 표식, 신규/강화 구분, 실제 전후 효과와 예상 장착 위치. 하단은 실제 1~4오브/6~8칸 요약과 대상 칸 강조다.
- 공통 `acquisition_view.gd` 모델을 레벨·상자·제작 미리보기·오브 성장에서 사용한다. 제작/오브는 기존 작업대의 크기에 맞춘 표현을 유지한다. 제작 완료는 기존 슬롯으로 아이콘 이동/결과 메시지, 보상은 획득 확인과 실제 위치를 표시한다.
- 상자는 열기 → 봉인 아이콘 확대 0.8초 → 실제 3후보 → 선택/확인 순서다. 개봉·확인 애니메이션이 재고를 지급하지 않는다. 합성 부모 소비와 결과 위치는 같은 트랜잭션 계획으로 미리보기/실행한다.
- 클릭/카드 본문/방향키·Enter 선택. 시작 180ms 및 누른 확정 입력의 해제까지 입력을 막아 전투 클릭의 오선택을 방지한다. 오래된 revision과 이미 수령한 보상은 재지급하지 않는다.
- 기본은 획득 후 `계속` 또는 선택적 `조합 편집`. 편집은 보상 정지 유지, 평소 인벤토리는 비정지다. 연속 보상은 전투 프레임 없이 다음 선택으로 이어진다. Esc 일시정지/복귀 시 미수령 화면을 복구한다.
- 설정 `자동 장착` 기본 켬, `빠른 획득` 기본 끔. 제작에도 자동 장착 토글, 보상마다 가방에만 보관 토글이 있다. 빠른 획득은 상자 개봉을 생략하고 확인을 0.25초 후 넘기며 3택 선택 자체는 생략하지 않는다. 구형 프로필은 기본값으로 호환한다.

## 자동 장착 계약
`auto_equip.gd`는 실제 빈칸만 계획한다. 기존 구체를 밀거나 교체하지 않는다. 편집/적용 양쪽 배열에서 같은 자리가 안전해야 하며 재고 예약도 확인한다.

- 신규 공격: 빈 오브 우선, 기존 오브에서는 뒤쪽 빈칸 우선. 기존 연결 대상을 바꾸거나 독립 주문을 후속으로 만들면 가방으로 보낸다.
- 보조: 오른쪽에 유효 적용 대상이 있는 자리만. 연결: 양쪽 유효 공격을 의도대로 연결할 빈자리만. 무효/불안전/만석이면 이유와 함께 가방에 남긴다.
- 중복 강화는 기존 실물과 위치를 그대로 갱신한다. 완성 합성은 부모를 소비하고 앞 부모 자리부터 계획하며, 가방 전용일 때 부모의 연결도 함께 정리한다.
- 보조의 전역 오른쪽 범위, 연결 위력/발동 횟수, 마법/유물 수량·가격·30분 전투는 바꾸지 않았다.
