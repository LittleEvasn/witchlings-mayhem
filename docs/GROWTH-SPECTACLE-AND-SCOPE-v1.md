# 보이는 +3 강화·자동강화·후반 화력 조사 · 2026-10-27

## 상태와 결론
사용자 확정 방향은 ‘최대+3, 수치만이 아니라 눈에 보이는 공격 변화’와 기존 RELEASE-SCOPE-AND-UI-v1.md의 UI 방향이다. **게임 코드는 아직+4 규칙 그대로다.** 자동 중복강화/+3 이후 복사본은 검토안이며 이번에 구현하지 않았다. 이 문서의 예시는 제안 수치다. 소환/마나/멀티/새 마법 대량 추가는 범위 밖이다.

권고: 새로 얻은 기본 구체는 기본적으로 자동강화하되 ‘별도 보관’을 허용한다. 이미 장착한 실물끼리는 자동 소비하지 않는다. 강화는 각 마법의 기본 행동을 눈에 띄게 발전시킨다. 후반 체감 부족의 확인된 원인은 공격 수량·주기·체류량이 강화로 거의 늘지 않고 표현도 옅다는 데 있다. 단순 생성 제한 해제가 해법이라는 근거는 없다.

## 1. 왜 현재 후반이 화면을 덮지 않는가

### 실제 코드
- spell_progression.gd: 피해 배율은1+0.2×단계, 크기는1+0.04×단계. +4도 크기는1.16배다. 기본 별빛탄 충돌 반경5가5.8이 되고 FHD에서 핵심 탄 지름12px가13.92px가 되는 정도다. 피해1.8배와 시각적 성장은 별개다.
- spells.gd branches와 modifier_effects.gd: 갈래 수는 장착 개수당+2다. 갈래 강화는 각 탄의 위력, 메아리 강화는 복제 위력을 올린다. **장착 개수가 같다면 강화 전후 발수/반복 횟수는 같다.**
- spells.gd interval/next_cast: 독립 공격은 순차 재생하고, 순환 대기는 가장 느린 공격 간격과 거대화/응축 개수로 결정한다. 공격 강화는 발사 간격을 줄이지 않는다. 두 오브는 독립 시전원2개이고 각 오브에는 복수의 독립 공격이 가능하다. 옛 ‘공격2개만’ 제한으로 되돌아간 것은 아니다.
- spell_runtime.gd: 별빛탄 기본 반경5/속도440/수명2.6초, 일반 탄은 관통이 없으면 첫 접촉 뒤 제거된다. 가까운 적 자동 조준과 합쳐져 많은 탄이 플레이어 근처에서 짧게 끝난다. 2.6초는 최대수명이지 항상 그만큼 화면에 남는 시간이 아니다.
- spell_behaviors.gd/magic_visuals.gd: 번개 실제 번쩍임0.2초, 작은 탄/짧은 꼬리/선으로 표현한다. 장판 채움 알파0.08, 윤곽선1.8px라 넓어도 옅다. 겹친 정원은 대표 하나를 그리며 성장 질량3/범위1.2배에서 멈춘다. 위성은 같은 주문/슬롯 최대2묶음,1.8초 수명이다.
- 종결 합성은 두+4와12G가 필요해 늦고 비싸며 기존 단계 성장은 피해 중심이다. 이 획득 시점/선택 문제는 이번에 사람 플레이로 추적하지 않았으므로 사용자 피드백과 경제 코드에 근거한 원인 가설로 구분한다.
- 안전 제한은 탄180/장판256/대기메아리32/틱당emit64/연결깊이6다. 극단 조합에 영향을 줄 수 있으나 아래 측정에서는 막힘이0이다. 모든 실제 빌드가 제한에 걸리지 않는다고 일반화하지 않는다.

## 3. +3 강화 권고

|구체|기본|+1|+2|+3|
|---|---|---|---|---|
|별빛탄|1발|굵기1.4배|평행2발|2발 굵기1.9배|
|소용돌이|반경86/3초|110/3.5초|140/4초|175/4.5초|
|거대화 보조|범위1.6배|1.9배|2.2배|2.6배|

모두 초기 시제품 가설이며 현재 수치가 아니다. 소용돌이는 현재 기본 반경과 일치시키는 구현 검토가 필요하다. 별빛탄2발은 각 탄을 해당 단계 단발 피해의65%부터 시험하므로 단순2배 화력을 보장하지 않는다. 거대화 순환 대기1.2배는 우선 유지한다.

- 공격은 원래 형태가 발전한다. 별빛탄의 좁은 평행2발은 갈래의 넓은 확산과 구분한다. ‘같은 방향 작은 다발’도 갈래와 결합했을 때 생성량/역할이 겹치므로 함께 검증한다.
- 모든 공격 만강에 유도를 붙이지 않는다. 유도가 자연스러운 특정 공격의 개별 특화 후보는 가능하나 현재 추적 보조를 무가치하게 만들면 안 된다.
- 장판은 넓어지고 오래 남는 변화, 왕복탄은 큰 궤도/큰 회전날, 낙뢰는 낙뢰 묶음/범위 등 주문의 핵심 행동에 맞춰 설계한다. 전체19기본 구체의 단계별 확정표는 후속 구현 전에 필요하다.
- 보조 역시 발수/반복/연쇄 대상으로 보이는 성장을 가질 수 있다. 효과를 피해 효율만 올리는 현재값에서 바꾸되 갈래×메아리×후속주문의 곱폭증을 함께 검토한다. 생성 제한을 터뜨려 조용히 잘라내는 것을 밸런스로 삼지 않는다.
- 후반 목표: 주력+3 하나, 역할 있는 보조 강화 하나, 합성 또는 사건 연결을 갖추고 각 오브가 다른 일을 하도록. 탄막형/큰 한 방/광역 구역 점유가 서로 다른 방식으로 강해 보인다.

## 4. 중복 자동강화 권고

‘같은 구체 합치기(강화)’와 ‘다른 공격 결합(완성 합성)’을 UI 용어에서 구분한다.

권고 기본 흐름: 첫 획득+0 → 같은 종류 새 기본 획득마다+1 → +3이면 다음 획득은 별도+0. 기본 구체4개로 첫+3이 된다. **사용자 고민안의 기본 동작은 채택하되 ‘별도 보관’을 허용**하는 제안이다.

- 이유: 강제 방식이면 별빛탄2개를 두 오브에 나눠 쓰거나 갈래 두 개를 중첩하는 선택이 첫+3 전에는 막힌다. 현재 game.gd/economy.gd는 두 오브 실물 예약을 합산하므로 실제 제약이다.
- 새로 얻는+0만 자동 소비하고 기존 장착 실물을 마음대로 서로 합치지 않는다. 대상은 이름/단계/오브/슬롯으로 표시한다. 여러 대상이면 지정한 하나에 적용한다.
- 획득 선택 카드에 ‘별빛탄+1→+2’처럼 기본 결과를 표시하고 ‘별도 보관’으로+0 실물을 선택할 수 있다. 선택을 매번 강제하는 별도 팝업은 만들지 않는다.
- +3 대상은 소비하지 않는다. 새+0을 실물로 추가한다. 그 후 새 복사본의 강화 대상을 표시한다. 동일한 실물1개를 두 오브/여러 슬롯에 무료 복제하지 않는다.
- 연결 구체는 강화하지 않고 늘 별도 획득한다. 완성형 합성의 중복 역시 추가 완성품이며 기본 자동강화와 분리한다.
- 공격과 보조 둘 다 이 기준을 검토하되 보조 중복 장착은 보존한다. 완전 강제 자동합치기보다 적은 조작과 실험 자유를 함께 보존한다.
- 서로 다른 지정 공격의 **+3 두 실물**로 완성 합성하는 방향을 권고한다. 소비/빈 슬롯/출력 장착 위치를 미리 보여준다. 자동강화가 합성까지 자동 실행한다는 뜻은 아니다.
- 이미 강화된 재료끼리의 수동 병합 규칙, 기존+4 데이터 변환, 기존+3이 새 행동+3과 어느 정도 위력인지, 유물 공구함/가격/실험 보상·장착 재고의 일관성은 후속 확정 사항이다. +4를 단순 삭제/상한 잘라내기로 처리하지 않는다.

## 5. 출시 분량과 한 판

이전24종/유물18/보스2는 **작은 첫 출시의 제작 위험을 줄인 초기 범위**다. 유료 정식판의 충분한 분량을 실측으로 입증한 숫자가 아니다. 특히 합성5개는 독립 시작 마법5개와 같은 선택량이 아니다.

현재 코드 한 판은 일반4+최종보스1=총5웨이브,90/105/120/135/보스상한150초(전투상한600초)다. 출시용으로 먼저 완성할 일반 루미 루트 권고는 다음과 같다.

|웨이브|길이|성장/전투 역할|
|---|---:|---|
|1|60초|첫 재료와 제작에 빨리 진입|
|2|75초|첫 강화의 차이를 확인|
|3|90초|주력 성장/합성 목표 재료 확보|
|4|105초|완성 주력·연결/합성을 활용|
|5|보스 목표120초/상한150초|만든 조합을 마지막 회피와 함께 사용|

전투 목표450초=7분30초, 상한480초=8분. 준비 포함10~12분은 사람 플레이 전의 목표 가설이며 준비는 무제한이다. 셋째 준비에 완성하면 마지막 일반전105+보스목표120=225초=3분45초 활용할 수 있다. 너무 늦게 완성하는 상태를 시간만 늘려 감추지 않는다.

콘텐츠 최소안: 기본공격9+보조8+연결2+합성5=24,유물18,일반 전투행동6,보상1,일반보스1+후속진보스1. 일반5웨이브에 보스2개가 모두 등장한다는 뜻이 아니다. 진엔딩 루트의 추가전투 여부·시간은 아직 확정하지 않았다.

‘완성된 다양한 콘텐츠 게임’이 목표라면 이 수량만으로 충분하다고 말할 수 없다. 다만 +3 단계에서 실제 외형/행동 차이가 생기고 합성을 써볼 수 있는 한 판을 먼저 마감한 다음, 반복 플레이에서 모자라는 역할/유물/보스 패턴을 채우는 순서가 낫다. 단계별 강화3개를 서로 다른 마법3종으로 과장 집계하지 않는다. 보스2종은 무작위 보스 선택의 풍부함을 주는 숫자는 아니다.
