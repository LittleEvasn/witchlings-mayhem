# 보상 경험·몬스터 역할·다음 제작 방향

2026-10-27. 게임 아이디어 담당 Astra/high 실제 호출1회와 총괄의 검토·공식자료 확인을 합친 **설계 제안**이다. 아래 몬스터/보상 UI는 이번에 구현하지 않았다. 이번 게임 변경은 별도 BGM 제거뿐이다.

## 왜 옆의 마법 선택이 밋밋한가

현재는 30초+12처치 → 작은 배지 → 인벤과 같은 서랍의 일반 설명 → 가방 지급이다. 코드는 정상 작동하지만 발견·공개·선택·획득의 박자가 약하고, 선택 후 어떤 조합이 가능해지는지 보여주지 않는다. 사용자 피드백을 기준으로 개선한다. 옆 배치 자체만으로 재미 유무를 단정하지 않는다.

총괄이 확인한 참고:
- [Hades 공식 패치 노트](https://www.supergiantgames.com/blog/hades-welcome-to-hell-update-patch-notes/): Boon/Upgrade를 고를 때 종류별 사운드를 구분하고 보상 선택의 피드백을 개선한 기록. [별도 업데이트](https://www.supergiantgames.com/blog/get-pumped-for-the-beefy-update/)도 보상 인터페이스 개선을 명시한다. 여기서 가져올 것은 획득 순간을 독립된 경험으로 다루는 점이다. 실제 화면을 새로 플레이하거나 해당 게임의 시간정지 정책을 검증한 것은 아니다.
- [Brotato 공식 소개](https://store.steampowered.com/app/1942280/Brotato/): 자동 발사, 20~90초 웨이브, 웨이브 사이 재료로 상품 획득을 명시한다. 짧게 싸우고 성장 선택을 하는 리듬을 참고하되 수치와 상점을 그대로 이식하지 않는다.

권고안은 **인벤은 옆 서랍, 마법 획득은 별도의 작은 보상 무대**다.
1. 획득 가능해지면 짧은 재료 발견 표시와 효과음. 강제로 창을 열지 않고 선택권은 보관한다.
2. 플레이어가 열면 화면 아래쪽에 세 구체/카드를 나란히 공개한다. 플레이어 중심과 위쪽 전장을 비우고 세 선택은 한눈에 비교한다. 현재 인벤 페이지를 여는 감각과 분리한다.
3. 이름·짧은 행동·현재 성장에 주는 의미를 먼저 표시한다. 예: 같은 기본 구체를 보유하면 '강화 재료', 새 공격이면 '새 주문'. 장착 미리보기는 실제 삽입 위치를 기준으로 계산해야 하며 '아무 위치에 넣어도 적용' 같은 거짓 안내를 하지 않는다.
4. 하나를 고르면 가방으로 들어가는 짧은 피드백과 새 구체 표시. 자동 교체/장착은 하지 않고 필요하면 곧바로 개인 조합 창을 연다.
5. 세계는 계속 움직인다. 닫기/나중에 선택 허용, 화면 암막/장시간 애니메이션/무적/타인 선택 대기는 기본으로 넣지 않는다. 큰 세 카드가 전장을 가리거나 선택을 강요하면 실패다. 보상 UI 위치와 크기는 실제 화면에서 확인한다.

Astra의 후속 제안은 **재료를 훔친 도주 운반자**다. 이동하면 자동 조준의 최근접/차근접 표적도 달라지므로 추격 경로 자체가 공격 대상 선택이 된다. 잡으면 재료를 회수해 기존 선택권을 일찍 받는다. 놓쳐도 조건을 충족한 기존 선택권은 웨이브 종료 때 주는 완충안을 권한다. 추가 보상 중첩이 아니라 기존18G 예산의 '지금 성장할 기회'를 옮기는 안이다. 이는 아직 승인·구현되지 않은 제안이다. 일반 성장 전체를 사라지는 적 하나에 걸지 않는다.

## 현재 적 코드와 사용자 관찰

일반 적은 근접(kind1), 사격(kind2), 돌진(kind3) 세 종류다. 보스는 별도 행동이 있지만 기존 kind3 그림을 크게 사용한다. 약한 떼/일렬 편성/색 변경을 각각 독립 몬스터 종으로 세지 않는다.

- 플레이어 속도240, 일반 적 기본58/68/52에 wave×3. 추격 속도는 대략 플레이어의1/4~1/3이며 상태이상·사격 정지 등은 별도다.
- 일반 돌진345×0.55초는 약190 거리이며 예고0.8초. 분리 힘과 둔화·경계 때문에 실제 이동은 달라질 수 있다.
- 일반 적(kind3 포함)은 현재 넉백·빙결·흡인에 대한 전용 슈퍼아머 역할이 없다. 보스의 예외와 일반 정예를 혼동하지 않는다.
- 코드: scripts/waves.gd, game.gd, actor.gd, spell_behaviors.gd. 직접 난이도를 실측한 수치가 아니라 코드의 초기값·계산이다.

괴수공주 7항목은 **사용자가 플레이하며 관찰한 설계 입력**이다. 우리가 해당 게임을 직접 플레이하거나 실제 프리팹 수치까지 확인한 사실로 바꾸어 쓰지 않는다.

## 몇 종을 목표로 할 것인가

Astra 권고는 먼저 기존 전투3 + 보상 운반자1 = 비보스4역할만 검증하는 것이다. 총괄은 사용자가 원하는 '근처 단독 슈퍼아머 정예'를 돌진과 구별해야 한다고 판단해, **짧은 한 판의 다음 목표를 전투4종 + 보상1종 = 비보스5종, 기존 보스1종**으로 정한다. 이 다섯을 한 번에 추가하는 구현 지시가 아니다. 처음 고칠 것은 여전히 기존3종이다.

| 역할 / 임시 이름 | 행동과 플레이어 판단 | 구현 순서 |
|---|---|---|
| 근접 · 뒤쫓는 실패작 | 충분한 속도로 접근해 후퇴하며 빈 통로를 고르게 한다. 약한 떼를 광역으로 지우는 쾌감은 유지한다. | 기존 수정1 |
| 돌진 · 튀어나오는 실패작 | 예고 때 방향을 고정하고 길게 돌진, 종료 후 빈틈. 뒤로만 도망가면 따라붙지만 옆으로 피할 수 있다. | 기존 수정1 |
| 원거리 · 잉크 뱉는 실패작 | 근접 무리 뒤에서 현재 위치를 겨냥하는 예고 사격. 사수에게 접근할지 진로를 바꿀지 고른다. | 기존 활용2 |
| 압박 정예 · 과팽창 실패작 | 안전거리와 출현 예고를 확보한 근처에 한 마리. 큰 몸체·높은 밀치기 저항·꾸준한 추격으로 자리를 비우게 한다. 돌진형과 다른 지속 압박 역할. | 신규 후속 |
| 보상 · 마석 물고 튀는 실패작 | 잠깐 머뭇거리다가 도망. 일반 적 사이를 지나가며 표적을 선택하고 보상을 일찍 얻는다. 전투 위협보다 선택 목표다. | 신규 먼저 |

배회 보상 무리는 **운반자1 + 기존 호위3~4명의 편성**으로 만들 수 있다. 새로운 종 네 개를 제작하지 않는다. 단독 운반자의 추격이 먼저 재미있는지 확인하고 이후 같은 시스템에 배회 편성을 더한다. 보스도 여러 종을 바로 만들지 않는다.

초기 실험 수치는 확정 밸런스가 아니다:
- 일반 추격145~170(플레이어의60~71%)부터 비교. 약한 떼 전체를 동시에 빠르게/단단하게 만들지 않는다.
- 단독 압박 정예는 일반 적보다 플레이어 속도에 가까운 추격을 별도로 시험한다. 밀치기 저항을 슈퍼아머의 중심으로 두되 모든 빙결/둔화/마법 피해를 면역 처리하지 않는다. 접촉 위치에 즉시 생성하거나 도주로를 전부 막지 않는다.
- 일반 돌진은300~360 거리, 동시1마리부터. 예고·방향 고정·종료 빈틈을 함께 검증한다. 몸체만 키우고 충돌 범위를 엉뚱하게 늘리지 않는다.
- 운반자 도주180~200, 추격4~6초부터. 너무 오래 쫓아야 하면 반복 심부름이 된다. 벼락으로 우연히 처치해도 정상 성공으로 인정한다.
- 적 크기는 실제 투명 여백을 제외한 몸체/화면 비율로 비교한다. 기존 atlas target_size78/94는 실제 불투명 몸체 폭이 아니다. 그림·피격 반경·통과 가능한 틈을 함께 맞춘다.

## 사용자 7항목 반영

1. 슈퍼아머 단단한 단독 정예: 장기 목표의 전투4번째 역할. 기존 돌진에 모든 저항을 한꺼번에 붙이지 않는다.
2. 근처 도주 보상 적: 먼저 추가할 새로운 종류. 성장 기회와 자동 조준 위치 선택을 결합한다.
3. 배회 보상 무리: 기존 적과 운반자의 편성으로 후속 적용.
4. 느린 공격/빠른 처치 차이: 전체 공속을 일괄 낮추는 것은 보류. 현재의 조합/쓸어버리는 재미를 보존하고 정예의 처치시간·접근시간을 먼저 비교한다.
5. 큰 유닛: 종별 실루엣과 몸체 크기 차이를 확보하되 큰 적만 화면에 채우지 않는다. 가독성과 도주 틈이 필요하다.
6. 비슷한 추격 속도: 현재 속도 격차부터 줄이고 지속 추격의 실효성을 확인한다.
7. 긴 돌진: 거리와 회피 가능한 빈틈을 함께 개선한다.

## 다음 세 작업

1. 기존 근접·돌진의 속도/거리/크기와 등장 비중만 작은 범위로 조정하고 첫 두 웨이브를 비교한다. 정지 벼락이 언제 위험해지는지, 움직이면 살아나는지, 강한 조합의 쾌감이 남는지 사용자에게 확인한다.
2. 보상 전용 공개·선택 연출을 인벤에서 분리한다. 기존 선택권·예산·비정지 정책을 재사용하며 이 단계에 새 적을 묶지 않아도 된다.
3. 도주 운반자 → 배회 보상 편성 → 단독 압박 정예를 순차 적용한다. 매번 첫 두 웨이브의 빈 시간을 확인하고, 지루하면 전투 시간을 줄인다. 마법 수/맵 크기/캐릭터/멀티 확대는 뒤로 둔다.

실제 재미는 아직 가설이다. 자동 검사 개수와 '출시할 게임에 충분한 종류 수'를 동일시하지 않는다. 현재 맵은 사용자가 충분하다고 판단했으므로 확대/미관 작업을 재개하지 않는다.
