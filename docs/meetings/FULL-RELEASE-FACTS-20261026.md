# 전체 출시 회의 공통 근거

## 사용자 기준
현재 마법 조합은 재미있다는 평가. 맵/몬스터/제작/유물은 현재 개발 단계에 충분하다는 뜻이며 상품 전체가 완성됐다는 승인은 아니다. 귀여운2D SD 미소녀, 마법조합 로그라이크 서바이벌. 기존 맵 미관 재작업·새 마나·소환·멀티를 이번 기획에 자동 추가하지 않는다. 오브2x6/순차·오른쪽 보조/연결/강화0~4/유물보상→마석제작 불변.

## 현재 코드 사실 (Luna 읽기 조사 + 총괄 확인)
- 기본 공격9, 보조8, 연결2(명중 후/소멸 후). 시작 꾸러미4. 옛 README의22구체/연결3 등은 현재값으로 쓰지 않는다. spells.gd, economy.gd.
- 완성형 합성5가 UI/진행 코드에 있다. 오브2개가 모두 발사한다. 기존 조합이 재미있다는 사용자 평가를 보존.
- 플레이어1인 외형, 일반 적 아트3종. actor.gd는 하나의 아틀라스를 크롭, 적3종 중 하나를 크게해 보스 표시. 애니메이션은 바운스/기울임/좌우반전, 정식 동작 시트 아님.
- 웨이브5, 전투최대5분(45초x4+120초보스). 마지막 승리는 보스사망, 시간초과 패배. 매 준비 시간은 현재 제한없음. 실제 초보/숙련 플레이 시간과 난도는 이번 미측정.
- 유물12, 중복없는 보상선택. 구체제작/강화/합성/드래그/시험발사 있음.
- 타이틀/시작꾸러미/전투/보상/제작/결과/재시작 있음. 타이틀을 새로 만들 필요는 없다.
- 캐릭터선택/고유액티브/일반엔딩4/진엔딩/영구해금/도감/게임프로필 저장은 현재 지정 코드에서 구현 확인 못함. 재시작 초기화+다른조합 재시도가 현재 반복동기.
- 배경1장, characters.png 1장: image_gen 생성 프로토타입임이 assets/art/GENERATION.md에 기록. 기존MageGame 유료팩 미사용. 효과음은 game.gd:1331~ 코드 생성5종, 오디오파일/BGM 없음.
- 기존화면 artifacts/relics-live-combat.png, relics-crafting.png를 총괄이 확인. 고대비 글리프/도형 VFX와 문서형 조작 UI는 표현 마감 검토대상. 캡처 시점 자료이며 이번 새 실행은 아님.
- 알려진 보스생성 실패시 진행 위험, 극단 조합 렌더p95 43.652ms는 이전 회의/RELICS-v1.md에 기록. 버그만 고치면 상용완성이라는 결론 금지.
- export_presets.cfg 없음, Play.cmd는 개발PC Godot 절대경로. pause설정은 계속/다시시작+M효과음토글. 게임설정/기록 저장 확인 못함.

## 사용자가 이전에 준 이야기 구상 (총괄이 원본 읽음; 구현/최종승인과 구분)
원본은 프로젝트 상위 `마녀들의 사고현장.md`이며 사용자 자신이 대략 쓴 이야기라고 제공했다. 그 문서의 '합의' 표현만으로 현재 모든 기획을 확정하지 않는다.
- 숙제를 대신할 자율 마법조수를 만들다 사고. 교수님이 돌아오기 전, 실패작 몬스터를 잡아 마석으로 마법/유물을 급조해 수습. 판이 끝나면 만든것은 사라짐.
- 네 마녀: 루미(게으른천재/목표제한누락), 네라(소심한인형술사/거절못하는인격), 세라(수재/끝없는검증), 모카(열혈/과도한마력공급).
- 각 캐릭터 일반클리어로 실수엔딩4+교정설계도4해금, 한판에서 교정장치4확보하면 진보스/진엔딩. 실물초기화·제작가능설계도만영구해금. RNG때문에 불가능한 조건 피할 것.
- 액티브 아이디어: 루미 자기투사체복제, 네라 인형의원격시전, 세라 흡인블랙홀, 모카 대시잔상지뢰. 네라의 인형 소환은 현재 '소환추가금지'와 충돌가능. 설정상마나는 플레이비용이 아님. 캐릭터능력/시간/해금은 새 설계제안으로 표시할 것.
- 실패: 교수님수습/훈계. 성공: 니들이치워. 진엔딩: 사고원인교정. 현실AI브랜드명은 내부가칭이므로 공개판에 고유명칭 권고.

회의 목표는 위 기반을 출시할 하나의 상품 경험으로 완성하는 권고안. 콘텐츠·반복플레이·전투/보스·캐릭터/스토리·아트/사운드·UI/접근성·저장/성능·빌드QA·Steam상점/출시/지원 전부 검토한다. 모든것을이번달만든다고일정/비용약속하지말고 단계와 완료기준을 제시한다.
