결과는 두오브·합성·유물·사망원인 복기. 다음판은 다른마녀의사고, 못완성한연결, 못넘은패턴이라는 구체적목표. 강한조합을쓸시간/제작이해/보스급종료 문제가보이면 해당구간시간부터조정. 숫자시간을상품가치증거로쓰지않는다.
