# 총괄 의견: 제품 제작·배포·출시 운영

이 문서는 회의 자료다. 코드 구현/신규 실행 검사/사용자 플레이 관찰은 하지 않았다. Steam/Windows는 현재의 권고 운영 가정이며 최종 플랫폼·가격·발매일은 승인받아야 한다.

## 기술 밖에서 완성해야 할 일
- 콘텐츠 목표와 한 판의 긴장/성장/결말, 판 사이 해금 동기를 먼저 명세. 현재 5분 실험을 버그 없이 돌리는 것만으로 판매 가능한 분량이라고 판정하지 않는다. 물량 추가 효과는 플레이로 검증.
- 캐릭터·적/보스·마법/유물 아이콘·타격/상태/경고 VFX·배경·UI·로고에 하나의 아트 기준과 제작 목록. SD 미소녀의 표정/성격이 읽혀야 함. 프로토타입 단일 정지 그림의 바운스, 글리프 아이콘, 보스 확대 재사용은 출시 품질 평가 항목. 고가 애니메이션 공법을 미리 강요하지 않음.
- 전투/준비/보스/결과 BGM과 발사·명중·피격·회피·드롭·제작·강화·합성·UI 피드백의 음향 체계. 음량 우선순위·동시 재생 제한·오디오 켜짐/꺼짐 모두에서 필요한 정보 전달. 음성 연기는 선택 사항.
- 첫 판은 짧은 실제 조작 안내로 첫 보상/제작/두 오브 사용까지 도달. 설명서 읽기를 강요하지 않고 조합결과 미리보기·이유 있는 실패안내 제공. 후속 판은 생략 가능.
- 문구 용어 통일(마석/제작/구체/오브/유물), 설정·도움말·결과·도감·크레딧. 지원 해상도/창비율에서 잘림/글자 크기, 키 변경, 색외 모양 구분, 섬광/흔들림 완화. 게임패드는 구현·검증하기 전 지원으로 광고하지 않는다.

## 제품 기술과 검사 범위
- 로컬 프로필: 설정·해금·엔딩/도감·최고기록. 판의 마석/마법/유물은 원래대로 초기화. 버전/마이그레이션/백업·손상 복구. 중간 저장은 런 길이/준비시간 설계가 정해진 뒤 필요 여부 결정.
- 현재 Git 없는 상태에서 버전 관리·변경 전 복구 지점·반복 가능한 빌드·버전/로그를 마련. 기존 파일 보존, 구매/원본 자료와 실제 런타임 사용 자원 구분.
- Windows 에디터 없는 독립 실행, 개발용 MCP/시험 도구 배포 포함 정책, 경로/폰트/라이선스, 종료/재시작/포커스/해상도/입력/세이브 검증. 스토어 표기 최소사양은 실제 배포 빌드 측정으로 정함.
- 일반/보스/최대효과 조합의 CPU·렌더 프레임·메모리·입출력 측정. 정상 동작을 임의 생략하는 상한으로 화력 문제를 숨기지 않음. 알려진보스실패·수량보존·강제정리시연결불발·시험분리 등 관련 회귀검사.
- 외부 신규 플레이어의 첫 행동/제작 이해/사망 이해/재도전 자발성/빌드 선택 기록. 목표 예시(팀 기준 제안): 초기 5명 중4명이 실시간 도움 없이 첫 제작과 다음웨이브, 최소3명이 자발적으로 다음판 다른조합 시도. 적은 표본의 방향성 신호이며 재미나 매출 보장은 아님.

## Steam에 필요한 실제 일
아래는 2026-10-26 공식 문서 조회에 근거. 스토어 작업은 자료 준비와 초안까지만 자동 진행하며 실제 계약·결제·신상/세금/계좌제출·가격 확정·공개 게시/발매는 사용자 명의 승인 단계다.

1. 파트너 등록, 배포계약/신원 확인, 결제·세금·은행 정보, 앱/권한 설정. 현재 문서는 앱 수수료 결제 후 초기 출시 대기21일과 Coming Soon 최소2주를 안내한다. 계정별 적용/정책은 실제 등록 때 재확인. [공식 Onboarding](https://partner.steamgames.com/doc/gettingstarted/onboarding?l=english), [공식 Release Options](https://partner.steamgames.com/doc/store/types?l=english).
2. 실제 출시 내용과 맞는 소개문/지원언어·입력/시스템 요구사항·장르태그·캡슐/로고/라이브러리그래픽·게임플레이영상·스크린샷. 스크린샷은 실제 게임플레이 최소5장, 캡슐은 읽을 수 있는 게임명/로고와 최신 규격. 캐릭터 컨셉아트를 실제 플레이로 광고하지 않음. [공식 그래픽자산](https://partner.steamgames.com/doc/store/assets/standard?l=english), [공식 Review Process](https://partner.steamgames.com/doc/store/review_process?l=english).
3. 상점과 빌드 체크리스트/검토 둘 다 완료. 광고한 기능은 제출 빌드에서 실제 제공되어야 함. 검토가 끝나도 자동 출시되지 않으며 공개 출시 버튼 실행이 별도로 필요하다. [공식 Release Process](https://partner.steamgames.com/doc/store/releasing?l=english).
4. 콘텐츠 설문/등급, 이미지·폰트·음악·코드 의존성의 사용권/표시 의무 정리. 현재 GENERATION.md가 생성형AI 아트의 프로토타입 사용을 기록하므로 실제 배포에 남는 생성콘텐츠를 파악해 설문에 정확히 기재. 이 회의는 개별 콘텐츠 권리를 법적으로 보증하지 않는다. 내부 AI제품 실명 가칭은 독자적인 마법 인격 이름으로 바꾸는 방향 권고. [공식 Content Survey](https://partner.steamgames.com/doc/gettingstarted/contentsurvey?l=english).
5. 대표 완성 구간이 생기면 Coming Soon 자료를 준비하고, 테스트 데모/Playtest와 피드백 창구를 운영. 미구현 캐릭터/멀티를 현재 기능처럼 홍보하지 않음. 스토어 광고/외부연락/플랫폼 게시를 임의로 실행하지 않음.
6. 출시 후보 빌드 잠금→저장 호환/업데이트·롤백 확인→상점/빌드 승인→사용자 발매 승인→릴리스노트/버그 접수/우선 패치. 실명계약·가격/마감 결정은 AI 직원이 대신 결정하지 않음.

## 선택 기능
Steam 업적/클라우드, 게임패드/SteamDeck, 추가 언어·음성·하드모드·엔드리스·온라인 랭킹·멀티·DLC는 모든 출시작의 의무가 아니다. 특히 멀티는 사용자가 나중으로 둔 항목이다. 기능/지원으로 상점에 약속하면 그때부터 실제 빌드 검증이 필요하다.
