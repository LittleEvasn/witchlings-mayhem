## 확정된 타이틀 화면 구조

1. **배경 전체 화면**: 풍경이 시각 중심. 별도의 메뉴 배경판·좌우 2분할·캐릭터 쇼케이스 박스는 **사용하지 않음**.
2. **오른쪽 상단:** 게임 로고 `마녀들의 사고현장`.
3. **오른쪽 중하단:** `이어하기` / `새 실험` / `마법 훈련장` / `발견 도감` / `실험 기록` / `설정` / `종료` 를 **세로 텍스트 목록**으로 배치.
4. **텍스트 메뉴에는 박스·테두리·패널 없음.** 선택된 **한 항목의 왼쪽**에만 작은 삼각형 `▶` 커서 표시.
5. `이어하기`·`새 실험`은 큰 글씨, 나머지 5개 보조 기능은 조금 작은 글씨. 메뉴 사이 작은 구분 간격.
6. **화면 왼쪽 하단:** 짧은 이동/선택 조작 안내.
7. 전체 배경의 달·산·구름·나무·마법학교 실루엣은 HTML/CSS 임시 장면이며 **최종 게임 배경 아트 승인이나 원작 자산의 도입이 아님**.
8. HTML 목업의 커서 이동(↑↓·마우스 오버)과 실행 시연(Enter·Z·클릭)은 승인 화면의 조작 **예시**. 실제 게임 기능과 체크포인트 연결을 구현했다는 뜻은 아님.
