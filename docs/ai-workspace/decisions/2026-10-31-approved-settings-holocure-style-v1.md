## 채택 대상 — 설정 화면만

1. **상단 큰 설정 제목**, 하나의 읽기 쉬운 설정 패널.
2. **세로로 정돈된 설정 행**: 항목별 왼쪽 작은 아이콘 + 옵션명, **오른쪽 상태/체크박스/토글**의 반복적이고 일관된 구성. 각 행에 선택/호버 시 식별 가능한 강조 상태.
3. **필요한 실제 기능에만 슬라이더**. HoloCure는 체크박스·토글·슬라이더를 혼용하지만, 우리 프로젝트에는 효과음 음량 슬라이더처럼 현재 구현이 없는 조작을 **보이기만 하게 만들지 않는다**.
4. 항목이 패널 높이를 넘는 경우 **세로 스크롤**. 현재 지원하는 옵션이 적어도 괜히 많은 빈 탭을 만들지 않는다.
5. **시각적 참고:** HoloCure의 선명한 구획, 항목별 아이콘, 단정한 줄맞춤, 오른쪽 정렬된 상태 제어. **원작의 파란색·픽셀아트 픽셀 디자인 자체를 그대로 복사하지 않는다**. 우리 게임의 2D 카툰·크림/라벤더 등 기존 UI 톤에 맞춰 변형.
6. **중요한 정확성:** 검토한 0.5 스크린샷의 왼쪽 작은 아이콘은 **각 옵션에 붙은 아이콘**이며, 이를 임의로 '왼쪽 카테고리 탭'으로 해석해서 필수 UI로 만들지 않는다. HoloCure에 일반/그래픽 옵션 범주가 있다는 것과 해당 캡처 왼쪽에 카테고리 레일이 보인다는 주장은 다르다.
7. 지금 우리 게임에서 **실제로 지원되는 옵션**을 기준으로 초기 화면 구성: `효과음 On/Off`, `상자 개봉 생략 On/Off`, `피해 숫자 On/Off`. `배경 음악`은 현재 음원/기능이 없어 기존처럼 미지원·비활성으로 처리하거나 숨길지를 추후 결정. 키 재설정·투명도·해상도·화면 흔들림·음량 조절 등은 UI 디자인 승인만으로 새 기능을 구현하지 않는다.

## ESC 팝업 및 상태 복귀와 분리

- **이번 승인 대상은 설정 화면 디자인**이다. 기존 07번 보고서의 ESC 팝업에 관한 Hades II 중심 레퍼런스·`계속하기` 우선·재시작/타이틀 위험 행동 확인창 권고는 **기존 제안으로 보존**, 여기서 ESC 팝업 전체 레이아웃까지 승인했다고 기록하지 않는다.
- `타이틀 → 설정 → 돌아가기 = 타이틀`, `일시정지 → 설정 → 돌아가기 = 일시정지`라는 기존 복귀 계약은 그대로 유지.
- 설정을 닫는 과정에서 전투 자동 재개, 보상 정지 해제, 체크포인트 변경, 부적절한 ESC 이중 실행이 없어야 한다.
- HoloCure의 게임 고유 옵션이나 저장 파일 구조를 그대로 도입하지 않는다.
