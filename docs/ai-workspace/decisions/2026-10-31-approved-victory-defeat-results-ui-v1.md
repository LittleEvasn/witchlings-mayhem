## 승인한 06번 디자인 방향

1. **공통 레이아웃, 분리된 감정:** 승리·패배는 같은 기본 정보 구조를 사용하되 큰 결과 제목, 캐릭터 반응, 분위기(명도/색), 연출을 각각 차별화.
2. **결말과 결과를 같은 한 화면에 표시.** 의무적으로 별도 엔딩 페이지/통계 페이지를 넘기지 않음.
3. **정보 위계:** 크게 표시한 승패 결과 → 캐릭터 반응/짧은 결말 → 실제 런 핵심 통계 → 오브·유물 빌드 → 재도전.
4. **상세:** 전투 시간, 제작·편집 시간, 처치, 획득 마석, 도달 웨이브(특히 패배 시) 등 **실제 저장된 데이터** 중심. 최대 4개 오브의 마법 슬롯 순서/성장 단계 및 획득 유물을 가독성 있게 표시.
5. **재도전 동선:** `같은 시작 조합으로 다시`를 주 행동으로, `다른 시작 조합 고르기`와 `타이틀`을 구분. 실제 기존 런 시작·프로필·저장 계약 유지.
6. **참고 게임 역할을 원문 그대로 채용:** **Brotato**(결과 통계와 빌드 기록), **HoloCure**(큰 승패 선언과 간결한 재도전), **Hades**(승리 기념 연출). **Vampire Survivors / Deep Rock Galactic: Survivor**의 정밀 통계는 향후 별도 전투 계측이 있을 때만 참고.
7. **패배도 빌드를 동일하게 기록.** 강한 비극이 아니라 마법 실험 실패의 코믹한 분위기를 유지. 승패 별표정/특별 VFX·음향·전체 배경 교체는 원문에서 **추가 아트·구체 구현 검토 사항**이지 이번 승인으로 제작된 자산이 아님.

## 최신 확정 정책의 우선순위

- 06번 원문에 남은 옛 문구·교수님 직접 대사는 **채용 대상 아님**. [최신 시스템 UI 문체 결정](2026-10-31-battle-ui-copy-tone-no-cutesy-dialogue.md)과 [확정 스토리](../reports/2026-10-30-professor-game-over-only-and-general-ending-cleanup.md) 우선.
- **게임 오버:** `GAME OVER`, `교수님에게 혼났다.` (교수님 직접 등장·초상·대사 없음).
- **일반 승리:** `사고 수습 완료`, 일반 엔딩의 실제 확정 대사 중 `……이거 언제 치우지?`(모카) 등 최신 스토리 사용. 진엔딩 내용은 원문 06번 UI 보고서로 새로 확정하지 않음.
- 제목/통계/기능 버튼에서는 유치한 감탄문·임의 격려 대사 금지. 인물의 확정된 스토리 대사는 시스템 메시지와 구분.
- **DPS, 오브별 피해량, 마법별 기여도**는 현재 보고서 기준 저장·계측되지 않으므로 표시 금지. 별도 계측 설계와 코드 검증 없이는 가상 수치로 채우지 않음.
- **도달 웨이브**는 기존 런 기록에는 있으며 결과의 우선 표시 대상으로 개선 제안. 이번 승인 자체는 데이터/코드 변경 아님.
- 단서/영구 해금이나 마석 보상이 발생했다고 사실과 다르게 표시하지 않음.
