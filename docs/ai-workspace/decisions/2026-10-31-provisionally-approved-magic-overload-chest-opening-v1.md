2. **보상 1개:** 상자에서 중앙 보상 아이콘 **1개가 빠르게 튀어나오는** 일반 연출. 짧게 끝내 반복 개봉의 피로 최소화.

5. **결과·스킵:** 실제 보상 수와 아이콘/이름을 명확하게 보여준다. **연출 건너뛰기**와 음향 On/Off를 제공하되, 스킵·연타·취소로 **보상 지급 횟수/내용을 변경하지 않는다**.
6. **새로운 발견과 중첩 방지:** 별도 [12번 최초 발견 간소화안](2026-10-31-approved-first-discovery-notification-integrated-v1.md)을 적용해 첫 발견 배지/강조를 **기존 보상 공개 안에 통합**. 보물상자 잭팟과 똑같은 물품의 첫 발견이 별개의 큰 컷신 2회로 중첩되지 않음.

## 실제 게임 구현에서 반드시 지킬 계약

- **기존 `scripts/combat_rewards.gd`의 1/3/5개 추첨·지급/합성 후보 재평가와 실제 보상 규칙을 그대로 사용.** 이 문서가 확률·경제·합성 결과를 바꾸지는 않는다.
- **공개용 시연 파일의 `1개/3개/5개` 강제 선택 버튼은 개발 테스트 전용**이며 게임 출시 UI에 넣지 않는다. HTML 내 임시 샘플 보상명/이미지는 **게임 실제 드롭이 아님**. 회전/빛/마법진을 실제 랜덤 추첨이나 지급 계산기로 사용하지 않는다.
- 상자 보상 **1/3/5개는 모두 획득하는 수량**이며 레벨업 3중 1택과 다른 기능. 후보/지급 결과에 없는 마법·유물을 시각적으로 실제 당첨된 것처럼 보여주지 않는다.

- 상자 개봉/보상 정리 단계에서 정지 상태 유지; 실제 보상 지급 뒤 [기존 보상/가방/오브 3상태 승인](2026-10-31-approved-reward-ui-inventory-three-state-flow.md)대로 돌아가고 플레이어의 **전투 재개** 입력 전에는 자동 전투 재개 금지.
- **최신 전투 HUD** 가방·오브/자원 배치와 부딪치지 않을 것. 내부 시연 CSS의 가상 전장/마법 아이콘을 최종 게임 아트로 보지 않는다.
