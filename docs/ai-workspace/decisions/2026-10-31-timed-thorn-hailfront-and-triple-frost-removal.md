## 확정 사항

1. **`timed_thorn` / 시한 가시꽃 / `thorn + timer` 완성 합성을 삭제한다.** 현재 구현의 두 차례 가시파·마지막 폭발 설계는 더 이상 최신 기준이 아니다. 기본 `thorn`과 기본 연결 `timer` 자체를 삭제하지는 않는다.
2. 삭제한 시한 가시꽃의 자리는 **`element_ice + fall` / 빙결 + 낙하**의 새 합성으로 교체한다. 가칭/보고서상 제안 이름은 **빙설 전선**.
3. 새 합성의 핵심은 **구름이 천천히 전진하며 그 아래에 계속 우박을 떨어뜨리는 것**이다. 개별 우박은 실제 착탄 피해와 냉기 누적을 가해야 한다. 이동하지 않는 냉기장판/한 번 낙하/구름 그림만으로 대체 금지.
4. 얼음+낙하는 **보조 `element_ice` + 보조 `fall`** 조합이다. 기존 **얼음검 `frost` + 낙하** 조합과 구별해야 한다. 새 결과는 실제 공격을 수행할 별도 합성 실행체·공격 프로필이 필요하다. 새 내부 ID는 세이브·도감 호환 검토 후 결정한다.
5. **`triple_frost` / 빙정 삼중파 / `frost + fan` 완성 합성을 대체 없이 삭제한다.** 기본 `frost`(얼음검 개편)와 기본 `fan`은 유지하며, 임의의 신규 합성을 `frost + fan`에 배정하지 않는다.
6. 현행 완성 합성 **30개**를 전제로 `timed_thorn`→빙설 전선은 **1:1 교체**이고 `triple_frost`는 **1개 순감**이므로 **향후 설계 목표 29개/1개 공석**. 현재 코드가 즉시 29개로 변경된 것은 아니다.
7. **시간 트리거(`timer`)의 새 마법공예 휘감기(3204) 기반 '후속 마법 B의 부모 주변 공전' 개편 결정은 유효**하며 이번 삭제로 취소하지 않는다. `clock_satellite` 등 다른 `timer` 조합, `cold_flame` 등 다른 `frost` 조합도 임의 삭제하지 않는다.
