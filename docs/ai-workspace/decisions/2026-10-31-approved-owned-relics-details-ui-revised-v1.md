## 확정한 화면별 구성

1. **전투 HUD:** 이미 승인된 **오른쪽 상단 유물 아이콘 세로 배열**을 따른다. 과거 11번 보고서의 **왼쪽 아래 유물 가로줄 유지 권고는 폐기**한다. 실제 보유 중인 유물만 아이콘으로 표시하며 획득 전 가짜 칸·등급·장착 슬롯을 만들지 않는다. Slay the Spire는 **작은 보유 아이콘 + 빠른 호버 확인의 정보 구조**만 참고한다.
2. **아이콘 호버/키보드 포커스:** 09번에 승인한 **Magicraft식 공통 툴팁의 짧은 버전**(아이콘, 이름, 핵심 효과, 주요 수치, 중요한 발동 조건/예외). HUD에서 전장을 가리는 긴 설명 패널을 반복하여 만들지 않는다.
3. **보유 유물 보기:** `유물 N` 진입을 통해 **이번 실험에서 실제 보유한 유물의 작은 아이콘 목록 + 선택한 유물 한 개의 상세**를 표시한다. 현재 코드의 3열 대형 텍스트 카드 나열은 축소/교체 대상. 목록 항목 선택 시 오른쪽 또는 충분한 가로 공간의 상세 영역만 갱신하며 닫기/키보드 탐색 가능.
4. **큰 상세:** Magicraft식 카드 구조를 09번 툴팁과 **공유**한다. 유물 아이콘/이름 → 실제 효과/장단점의 수치 분리 → 발동 조건 → 예외 → 현재 런에 존재하는 동적 수치 → 승인된 플레이버 문구(있을 때만). 별도의 유물 카드 정보 규격을 중복 설계하지 않는다.
5. **실제 상태 예시:** `scripts/relics.gd`가 제공하는 저금통의 **현재 마석 연동 피해 보너스**, 장갑의 **다음 복제까지 직접 시전 수**, 영혼 솜옷의 **보호막/처치 누적** 등은 실제 런 상태에서만 표시. 미지원 상태/등급/강화 레벨은 가상 생성하지 않는다.
6. **연계:** 04 도감의 발견/미발견 유물, 06 결과 화면의 보유 유물, 08 과거 실험 기록의 저장 유물, 09 공통 툴팁, 05 제작·보상 화면의 같은 유물 이름/효과 규격을 재사용. **현재 보유**와 **과거·발견 목록**은 분명히 구분한다.

## 코드·구현 경계 (별도 검증)

- **현재 소스:** `scripts/relics.gd`에 유물 정의 12종, 보유 배열 `owned`, 중복 획득 방지, `tier="unassigned"`, 유물 자체 강화/탈착 기능 없음. 새로운 강화·합성·등급·장착/해제 버튼 추가 **불승인**.
- **버튼 목적지 결함 후보:** `scripts/interface.gd::show_relics()`가 전투에서 `open_personal("relics")` 호출, `scripts/personal_window.gd::build()`가 `personal_tab="inventory"`로 덮어씀. 클릭 시 **유물창 대신 가방으로 연결될 가능성**을 실제 Godot로 재현·검증하고 유물 목록/상세로 연결. 아직 수정/실행하지 않았음.
- **전투 중 전체 보유창의 정지 여부는 미확정**: 기존 가방의 비정지, 보상 선택의 정지, ESC 닫기 우선순위/포커스, 기존 `RelicUI.inventory()`의 일시정지 구현을 비교한 뒤 별도 결정. 승인된 디자인만으로 어느 동작도 강제하지 않는다.
- 보유 수 0/1/최대 12, 세로열에서의 화면 경계/축약·스크롤, 현재 효과 수치 갱신, Tab·ESC 닫기, 입력 방해, 1280×720/1600×900/1920×1080 실렌더와 키보드/마우스 테스트 필요.
- 유물 정식 아이콘/최종 색상/팝업 크기·애니메이션은 별도 시각 목업·실제 게임 검증 대상. 아직 PNG 아트를 GitHub에 첨부한 것으로 간주하지 않는다.
- [유물 28종 플레이버 텍스트](../reports/2026-10-31-relic-flavor-texts-28-draft.md)는 **초안(PROPOSED)** 이고 실제 코드의 12종 효과·아이콘/획득 시스템과 통합 승인된 것이 아니다.
- **10번 웨이브·보스 등장 UI는 별개 보류 항목**이며 11번 승인과 무관하다.

**최종 범위:** 별도의 유물 성장 화면을 만드는 작업이 아니라 **승인 전투 HUD의 보유 아이콘 + 09번 공통 툴팁 + 필요한 때만 여는 간단한 보유 목록·상세**를 연결하는 UI 개선안.
