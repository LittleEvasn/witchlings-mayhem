## 사용자 확정

1. 대상은 기존 완성 합성 **붕괴 소용돌이** (`collapse_vortex`), 기본 레시피 **소용돌이 씨앗(`vortex`) + 소멸 후(`expire`)** 유지.
2. 기본 블랙홀과 달리 **중심핵/크기는 작고, 흡인력이 매우 강하다**. 적이 실제로 중심으로 몰려야 한다.
3. **주위 비행 탄환을 흡입·흡수**하여 핵 내부에 저장하는 기믹이 있다. 단순 탄환 카운트/VFX만으로 대체하지 않는다.
4. **일정 시간 뒤 한 차례 붕괴·폭발**하면서 흡수한 **탄환을 사방으로 다시 발사하고**, 끌어모은 **적들도 중심 바깥으로 강하게 날려 보낸다**. 적이 단순 삭제되는 기능이나 종료 충격파만으로 대체하면 불합격.
5. 기존 구현의 ‘범위에 들어온 적 ID 수로 종료 충격파 피해 증가’ 중심의 **단순 종료 AoE 고유 기믹은 최신 개편으로 대체**한다. 새 폭발의 자체 피해 공식은 아직 미확정.
6. 기존 **기본 블랙홀(`vortex`)의 지속 흡인** 및 합성 **화이트홀(`orbit_vortex`)의 지속 반발**과 독립된 정체성을 보존한다.

## 구체적 구현 선택 — 사용자 미확정

- 어떤 종류의 탄환을 흡수할지: 플레이어 마법탄 `projectiles`와 적 탄 `hostile_shots`를 모두 검토. 광선/장판/위성은 별도 예외 필요.
- 흡수 탄환의 **원본 공격 성질/피해·원소·관통** 최대한 보존하여 재발사 권고. 모든 종류의 완전 복원이 확정된 것은 아님. **원본을 평범한 별빛탄으로 전부 대체하지 않는 방향** 권고.
- 적 탄환을 플레이어 공격으로 반사할지 적 탄환으로 유지할지, 소유권·피해 대상·친화력은 별도 결정.
- 몬스터를 실제 제거하지 않고 중심으로 모았다가 **방출 속도**를 주고 정상 AI에 복귀시키는 방식 권고. 보스/엘리트 저항 값 미확정.
- 흡입 반경/핵 크기, 흡입력, 충전 시간, 폭발/탄환 피해, 재발사 속도·저장 상한·성능 최적화 및 다른 연결/보조와의 상호작용 수치는 모두 미확정. 상한으로 흡수 탄환이 사라지는 경우를 감추지 말 것.
- **현재 코드 변경 및 Godot 실행·테스트·화면 확인·성능 측정 미실시**. 이번 요청은 GitHub 설계 기록에 한정된다.

## 구현 시 최소 합격 조건

- 일반 블랙홀 대비 작은 중심핵/강력한 실제 적 흡입.
- 주위에 있는 실제 탄환이 핵으로 이동·흡수되고 재발사 전에는 피해/갱신이 멈춤.
- 시간 경과 후 실제 폭발 **한 번**, 저장 탄환 여러 방향으로 **실제로 이동·충돌·피해**, 모인 적도 실제 방사형 이동.
- 탄환 0개/적 0명, 다수 탄환/300명 안팎 적, 4오브, 정상 종료·강제 종료, 상한/저장량 초과, 사망/맵 경계/보스/연결/다른 소용돌이 합성과의 회귀 시험.
- 화면 효과만 만들거나 단순히 피격자 수로 충격파 피해를 키우는 것으로 완료 처리하지 않을 것.

**결론:** 작은 붕괴핵에서 **강력 흡인 → 적·탄환 축적 → 폭발과 함께 탄환·적 방출**의 실제 게임플레이 동작으로 개편한다. **수치/호환성은 후속 설계, 게임 구현은 별도 지시 전까지 미수행**.
