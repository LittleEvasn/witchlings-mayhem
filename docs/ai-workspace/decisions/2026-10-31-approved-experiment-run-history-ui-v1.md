## 승인 구조

- 왼쪽: 최신순 **최근 최대 10판** 목록, 전체/수습/실패 필터, 행을 선택하면 오른쪽 상세 교체.
- 오른쪽: 선택한 기록의 승패, 시작 조합, 전투·제작 시간, 처치, 총 획득 마석, 도달 웨이브, 종료 이유, **최종 오브 배열(최대 4개)**, 획득 유물 아이콘/툴팁.
- 완료 웨이브 스냅샷을 접어서 펼치는 진행 이력. 실제 저장된 완료 웨이브만 표시.
- 06번 승패 결과와 오브 슬롯·유물·통계 카드 표현을 공유하되, 결과는 현재 런 상태, 실험 기록은 영구 프로필 스냅샷 사용.
- 참고: Slay the Spire Run History(기록 선택·빌드 복기), Hades Security Log(실험 일지 분위기), Monster Train(진행 복기). Scry, Spire Vault는 외부 보조 참고.
- 전체 누적 수습/실패 수치와 최근 최대 10건 개별 목록은 구분. 목록이 없는 상태·필터 결과가 없는 상태 제공. 타이틀로 복귀.

## 구현 정확성

- 기록 스키마에 없는 플레이 날짜, **오브 자체 성장 랭크**, DPS/오브별 피해량은 임의 추가하지 않음. 부품 ID의 +N과 오브 성장 랭크를 혼동하지 않음.
- 웨이브별 earned는 해당 완료 시점까지 **누적 획득 마석**. 패배 구간 완료 스냅샷을 임의 생성하지 않음.
- 기존 최근 10건 보존 정책 및 게임 경제·진행·저장 스키마 유지.
- 실제 UI 크기/화면 비율/원본 그래픽은 이후 목업·구현 시 검증. 원작 이미지·아트 반입 승인 아님.

원문 보고서는 수정 없이 보존하고, 이 결정이 해당 화면의 최신 사용자 채택 방향이다.
