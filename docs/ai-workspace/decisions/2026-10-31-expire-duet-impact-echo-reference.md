## 확정한 변경 (향후 구현)

1. **`expire` / ‘소멸 후’ → 마법공예 이중주(3201)식:** 부모 마법이 실제로 파괴·소멸하면 뒤의 마법을 그 자리에서 발사하면서 **부모 마법의 현재 계산 피해 일부를 후속 피해에 추가**한다. 기존 단순 후속 공격 피해 배율 `50/65/80/100%`로만 구현하는 방식은 교체 대상이다. 부모 누적 실피해 합계가 아닌 **부모 공격력 계산값**을 사용한다.
2. **`impact` / ‘명중 후’ → 마법공예 메아리(3205)식:** 부모 마법의 유효 명중 후 뒤의 마법을 발사하되 **부모 개체당 최초 1회 제한을 폐지**, **발동 쿨다운**이 지난 뒤 새로운 명중이 발생하면 다시 후속 발사를 허용한다. 시간당 반복과 실제 피해 여부까지 검사한다.
3. **원래 구체 보존:** 우리 게임의 별도 `echo` 보조 ‘메아리’(시간차 반복)는 변경하지 않음. `dual_event` ‘이중 사건’ 합성은 원작 이중주와 다른 기능이며 별도 호환 확인 대상. `impact`·`expire` **저장 ID/카드 이름은 유지**를 기본안으로 설정. 이 변경만을 이유로 전체 연결 문법의 보조 초기화 규칙을 임의 변경하지 않는다.

## 원작 근거와 원칙상 미확정

- 원작 이중주 **Lv1/2/3 = 부모 현재 계산 피해의 30% / 60% / 120% 추가**. 소멸 시 여러 이중주가 있으면 각 항목마다 후속 시전하는 구조.
