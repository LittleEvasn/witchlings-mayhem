## 방향 요약

**펼친 마법서처럼 보이는 한 화면에서 상점과 편집을 동시에 제공한다.** 우선 해결할 문제는 구매·가방·오브·합성을 확인하기 위해 탭을 반복해서 오가는 동선이다.

| 왼쪽 페이지 — 보유/편집 (항상 보임) | 오른쪽 페이지 — 구매/제작 (작업에 따라 변경) |
|---|---|
| 가방(위쪽): 구매 후 추가된 구체 확인 | 마법 상품 진열·구매 |
| 오브(가방 아래): 현재 보유한 오브와 마법 배열을 직접 편집 | 마법 합성: 재료·보유 상태·완성 결과 확인 |
| 드래그/우클릭 해제, 되돌리기, 조합 결과·경고 확인 | 오브 성장·유물 제작 등 작업 모드 전환 |

- **기본 동선:** 오른쪽에서 상품 확인·구매 → 왼쪽 가방에서 입고 확인 → 같은 화면에서 오브로 배치 → 결과 확인 → 시험 발사.
- **왼쪽 페이지는 고정**, 오른쪽 페이지에서 상점/합성/성장 등의 작업만 전환. 합성을 열었다고 가방·오브가 사라지지 않는다.
- **가방은 수평 한 줄 + 가로 스크롤**, 오브는 실제 보유 수만큼 각자 한 줄(기존 승인된 [인벤토리 구조](../reports/2026-10-31-reward-ui-codefaithful-three-states-approved-v1.md)과 일치). 가짜 4오브 상시 생성·임의 2D 가방 격자 추가 금지.
- 책등은 **얇은 구분 요소**에 그치고 두꺼운 장식·과도한 재질 표현으로 실사용 공간을 줄이지 않는다.
- 맨 아래 **되돌리기 / 시험 발사 / 준비 완료** 구분. 상품 상세는 오른쪽 작업 맥락에서 처리.
- **UI 원리 참고:** Backpack Battles의 상품/보유품 동시 확인 및 Noita식 마법 배열의 명확성. 원작 자산·규칙 복제 금지.
