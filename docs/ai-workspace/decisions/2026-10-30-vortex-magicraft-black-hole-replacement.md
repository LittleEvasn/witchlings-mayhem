# DEC-2026-10-30-06 · 소용돌이 씨앗을 마법공예 블랙홀 방식으로 전환, 중첩 시스템 폐기

- **상태: APPROVED — 사용자 직접 결정 / 게임 구현·테스트 미진행**
- **결정일:** 2026-10-30
- **사용자 원문:** “일단 블랙홀 코드 그대로 가져와 / 소용돌이끼리 겹치는거 없애고 / 그렇게 보고서 작성해놔”
- **구현 보고서:** [MAGIC-VORTEX-2026-10-30-01](../reports/2026-10-30-vortex-replace-with-magicraft-black-hole.md)

## 확정

1. 우리 게임 **소용돌이 씨앗(`vortex`)**의 기본 동작을 **마법공예(Magicraft) 블랙홀(`Spell1007`, 코드 ID 1007)**의 구현에 맞춰 변경한다. 단순 비슷한 보라색 장판이 아니라 원작의 **이동·지속 흡입·주기적 피해·시간에 따른 반경 성장·소멸 처리**를 실제 소스 기준으로 정밀 이식하는 것이 목표다.
2. **소용돌이끼리 겹쳐서 병합·중첩 성장하는 기존 시스템을 삭제한다.** `register_garden()`·`refresh_gardens()`의 소용돌이 간 `garden_key/garden_id/garden_mass` 묶기, 거리 48 이내 앵커 강제 일치, `mass`에 따른 범위 1.0~1.2배 성장과 3중첩 보상은 소용돌이에 적용하지 않는다.
3. 사용자 표현 **“블랙홀 코드 그대로 가져와”**를 구현 충실도 지시로 그대로 기록한다. 원작의 확인 가능한 구조와 계산을 Godot의 언어·좌표·엔진 이벤트에 가능한 한 **동일하게 대응**시키며 임의로 생략하지 않는다. 역컴파일된 제3자 상업 게임 소스의 **문자 그대로 직접 복제·재배포는 이용 권한 확인이 필요**하다. 권한이 불명확하면 원본 동작·수식을 상세 대조해 독립 포팅한다.
4. **다른 공격에 전용으로 있는 중첩 시스템까지 제거하라는 결정은 아님.** 가시꽃 덫(`thorn`)은 현행 중첩 시스템을 유지한다. 원작 블랙홀로 전환해도 `orbit_vortex`/공전 소용돌이 및 `collapse_vortex`/붕괴 소용돌이 등 기존 소용돌이 합성의 이름·효과는 **임의 삭제하지 않고 새 기본 동작에 맞게 호환성 검토**한다.
5. **이번 작업은 보고서 기록만.** 게임 소스 수정·웹 재배포·Godot 플레이 검증은 실행하지 않는다.

## 아직 결론 내리지 않은 상세 정책

- 물리적으로 설치 범위가 겹치는 **서로 다른 소용돌이 개체**까지 생성 자체를 금지할지, 기존 개체를 교체할지, 위치를 밀어낼지 등은 신규 배치 정책으로 별도 결정해야 한다. 단, **기존 소용돌이 간 병합·합쳐서 성장하는 규칙은 복원 금지**.
- 게임 내 표시 명칭 “소용돌이 씨앗”은 사용자가 개명을 지시하지 않았으므로 **우선 유지**한다. 블랙홀과 같은 이동형 공격으로 교체될 때 이름·아이콘 적합성은 별도 검토.
- 원작 블랙홀의 피해 단위, 매초 성장 계수, 강화 0~3 대응 수치, 이동/낙하/관통/공전 보조와의 적용 규칙은 코드 대조·전투 테스트를 거쳐 기록한다.

**이 결정은 새로운 기획안의 즉시 코드 구현을 의미하지 않는다.**
