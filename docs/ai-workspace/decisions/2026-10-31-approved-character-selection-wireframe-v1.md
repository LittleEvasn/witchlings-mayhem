- **사용자 원문:** “좋아 이대로 보고서 올려”
- **채용 이미지:** `마녀들의_사고현장_캐릭터_선택_화면.png`, 1672×941px, SHA-256 `16e87036b42822bdab190ff4c09aeef1c6bc990005471b984f441a8e256a9377`; 채팅에서 제시한 **흑백·연보라 와이어프레임**, 채색 일러스트 콘셉트 화면 아님. PNG GitHub 바이너리는 이번 등록에 없음.
- **최신 상세 보고서:** [UI-CHAR-2026-10-31-01](../reports/2026-10-31-character-selection-wireframe-approved-v1.md)

## 채용 배치

1. 왼쪽 상단 `마녀들의 사고현장` 로고 / **오른쪽 상단 `타이틀로` 독립 버튼**.
2. 왼쪽 큰 캐릭터 일러스트/실루엣 영역 아래에 네라·루미·모카·세라 **4인 가로 초상화**. 선택 강조는 보라색 테두리/체크.
3. 오른쪽 위 `인물 이름 → 캐릭터 소개 → 플레이 스타일` 정보 패널.
4. 오른쪽 중단에 `작은 정원 / 큰 한 발 / 반짝 연사 / 얼음 실험` **시작 마법 4종 가로 카드**. 실제 지급 데이터와 설명 일치 필요.
5. 오른쪽 아래에 큰 `실험 시작` 주 버튼. **`타이틀로`와 붙여 놓지 않음**.
6. 캐릭터/시작 마법은 **한 준비 화면에서 동시에 선택**하고, 실제 전투는 `실험 시작`으로만 확정. 별도 2단계 화면은 이 최신 채용 배치보다 우선하지 않음.

## 승인하지 않은 요소

- 사용자 채용은 **UX 배치**다. 회색 실루엣/기본 인물 루미/작은 정원 선택/그림 아이콘 및 세부 캐릭터 소개·플레이 스타일은 예시이며, 네 마녀의 실제 외형·개별 능력·밸런스 데이터 승인 아님.
- 게임 코드상 플레이 가능한 인물 수는 별도 확인 필요. 과거 UI 보고서는 **루미만 실 플레이가 확인**됐으며, 다른 세 명을 실제 선택·전투 개시 가능한 상태로 거짓 표시하지 않는다.
- PNG는 채팅에서 실제 생성·확인되었지만 **GitHub에 바이너리로 첨부하지 않았다**. 동일 파일 식별에는 보고서의 SHA 사용.
- 픽셀 절대 좌표, 구매 GUI 스킨, 최종 일러스트, 도입 토글/스토리 흐름 변경, 게임 코드 변경, Godot 실행·테스트는 이번 승인에 포함되지 않는다.

이 결정은 캐릭터 선택 UI 구조에서 [구 조사 보고서](../reports/2026-10-30-character-selection-ui-research-proposal.md)와 [구 통합 설계 v0.2](../reports/2026-10-31-ui-integrated-design-v02.md)의 상충하는 미승인 배치 제안보다 우선한다.
