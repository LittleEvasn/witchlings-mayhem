## 승인된 상태 3개

1. **보상 선택:** 화면 중앙 세로 보상 카드 3개(합성 가능 시 4개). 실제 가방 한 줄과 오브 슬롯은 일부 보이되 보상 카드가 일부를 가려도 됨. 전투 정지.
2. **Tab 편집:** 보상 카드를 숨기고 실제 가방 **한 줄/최소 31칸/가로 스크롤** 및 **보유 오브별 가로 슬롯 6~8칸, 최대 네 줄**을 전체 표시·드래그 편집. Tab 재입력 시 기존 후보로 돌아오며 다시 뽑지 않음. 전투 정지 유지.
3. **보상 획득 후:** 카드가 사라지고 인벤토리를 충분히 정리할 수 있음. **‘전투 재개’를 누를 때까지 계속 정지**, 조작·정리 시간 제한 없음.

**가짜 UI 금지:** 기존 실물 `compact_inventory.gd`, `prep_slot.gd`, `inventory_bag_scroll.gd` 기반을 우선하며, 5열×4행 격자 가방 또는 오른쪽 독립 장비창은 승인한 구조가 아니다. 네 오브는 목업의 보유 예시이지 시작 보유 수량이 아니다.

**획득 처리:** 신규 일반 마법은 가방으로 들어가지만 기존 장착 마법 강화는 그 슬롯이 갱신될 수 있으며, 합성은 부모를 소비해 오브/가방이 실제 변경될 수 있다. 별도 승인 없이 ‘모든 종류의 보상은 항상 가방에만 지급’ 규칙을 구현하지 않는다.

- **기존 코드:** 보상 UI가 인벤토리 전체를 항상 생성. 보상 정지 중 Tab은 무시. 보상 지급 후 정지된 `edit`와 명시적 `continue_combat` 존재.
- **새로 구현할 기능:** 중앙 카드 오버레이와 Tab 2상태 UI 전환(후보·지급·정지 상태 변경 없이).
- **검증:** 구현/입력 테스트/실제 Godot 스크린샷/사용자 시각 검토는 아직 수행되지 않았다.
