# DEC-2026-10-31-02 · 게임 UI 문구 톤 — 유치한 구어체·불필요한 전투 대사 금지

- **결정일:** 2026-10-31
- **상태:** **APPROVED — 사용자 명시 지시로 확정된 '문체 및 표현 원칙'**. 개별 UI 문자열과 추가 연출의 최종 채택/게임 구현까지 승인한 것은 아님.
- **대상:** 《마녀들의 사고현장》의 전투 HUD, 이벤트 알림, 보상, 상자, 발견, 제작, 메뉴, 승패 결과 등 **시스템/게임플레이 UI 문구** 및 향후 문구 작성 제안.
- **사용자 원문:** “실패작들에게 둘러싸였어! 같은건 존나 유치해”, “그 유치한 말투도 안쓰게 적어두고”
- **자세한 대체 문구/코드 점검:** [UI-COPY-2026-10-31-01](../reports/2026-10-31-game-ui-short-copy-overhaul-v1.md)

## 1. 확정 원칙

1. **게임플레이 UI는 캐릭터처럼 떠들지 않는다.** 감탄·독려·친근한 반말을 기본 문법으로 사용하지 않는다. 문장보다는 **명사형 상태명 / 짧은 기능 안내 / 수치 / 실제 대상 이름** 우선.
2. **“~했어!”, “~할까?”, “~해봐”, “좋아!”, “대박!”, “행운이 함께했어!”, “멋지게 해냈어!”**와 같은 **유아용 애니메이션식 안내/불필요한 감탄사 금지**. 특정 문장 하나만 치환하고 비슷한 말투로 다시 작성하는 것도 금지.
3. **위험 자체가 화면에서 명확한 상황에는 전투 대사를 띄우지 않는다.** 일반 적 출현, 박쥐 떼 횡단, 포위 이벤트는 **기본 무문구**. 적 실루엣·동선·경고색·실제 화면/효과음(기존 것)으로 인지시킨다. 필요한 실전 식별 정보가 있다면 대사 대신 아이콘·방향 표시·간결한 상태 라벨로 검토.
4. **신규 획득·진화·합성·상자 개봉은 시스템 정보만 표기**하고 보상의 기대/만족감은 카드·아이콘·수량·연출로 전달. 없는 보상/기능을 과장해서 약속하지 않는다.
5. **문구를 꼭 쓰는 상황에는 사실에 맞는 표현만 표기한다.** 발생하지 않은 적/보스 등장, 기록되지 않은 영구 발견, 실패한 제작·합성 성공, 지급 전 획득 완료를 알리지 않는다.
6. **플레이어가 실시간 판단해야 할 정보는 남긴다.** 금지하는 것은 불필요한 구어체와 스포일러성 감탄문이지, 접근성·조작 설명·오류 사유·치명적 위험 정보 자체가 아니다. 꼭 필요한 경고는 무문구 원칙보다 우선하되 **객관적·짧은 표현**을 사용한다.
7. **게임 스토리/튜토리얼의 실제 인물 대사는 별도 층위**다. 네 마녀의 성격을 드러내는 의도적인 캐릭터 대화까지 전부 무표정한 시스템 문구로 바꾸라는 뜻이 아니다. 다만 스토리 대사에서도 어른이 아이에게 상황을 읽어주는 듯한 억지스러운 애교·과잉 감탄을 지양하고 자연스러운 인물 말투를 유지한다.
8. **유물 플레이버 텍스트는 별도 승인된 문학적/패러디적 글쓰기 영역.** 전투 안내 문구를 가벼운 농담으로 채우지 말라는 규칙을 이유로 기존 유물 설명문을 일괄 삭제하지 않는다.
9. 기존 자료/예전 UI 문서에 상충하는 문구 예시가 있으면 **최신 결정과 교체 보고서가 우선**한다. 작성자/담당자가 이전 문구를 그대로 구현하면 안 된다.

## 2. 폐기되는 대표 표현 / 대체 방향

| 구형 표현 (폐기) | 결정 |
|---|---|
| `실패작들에게 둘러싸였어!`, `실패작이 둘러쌌어! 틈으로 빠져나가거나 뚫어봐.` | 포위 발생 시 기본 문구 **없음**. 실제 포위 형태·빈틈/위험 피드백으로 전달 |
| `박쥐 떼가 전장을 가로질러!` | 횡단 이벤트 기본 문구 **없음** |
| `행운이 함께했어!`, `대박!`, `상자를 열어볼까?` | **금지**. 상자 버튼 `열기`, 결과 아이콘·개수만 표시 |
| `새로운 마법 발견했어!`, `도감에 기록했어!` | `신규 마법`, `신규 합성`, `신규 유물` 등 기능 라벨 검토 |
| `다음 실험에서는 다른 주문을.`, `같이 해보자`, `좋아!` 등의 UI 격려 | 결과/행동/상태만 전달; 임의 대사 삽입 금지 |

## 3. 기존 확정 스토리 규칙 유지

- 게임 오버: **`GAME OVER` / `교수님에게 혼났다.`**
- 일반 엔딩: **`사고 수습 완료`**, 스토리 대사 **`……이거 언제 치우지?`**(모카) 등 기존 확정 원고 유지.
- 교수님은 스토리 장면에 실제 등장하지 않음.

## 4. 구현/검증 경계

- 본 문서는 **표현 원칙 확정 및 문서화**. 게임 스크립트·UI 씬·에셋은 변경하지 않았고 Godot 실제 출력도 테스트하지 않았다.
