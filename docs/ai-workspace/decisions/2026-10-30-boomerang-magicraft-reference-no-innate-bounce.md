# DEC-2026-10-30-04 · 달빛 부메랑: 마법공예 회선검 기준, 기본 도탄 삭제

- **상태: APPROVED — 사용자가 직접 확정한 설계 방향 / 구현·테스트 미실시**
- **날짜:** 2026-10-30
- **보고서:** [MAGIC-BOOMERANG-2026-10-30-01](../reports/2026-10-30-moon-boomerang-magicraft-reference-redesign.md)

- **참고:** Magicraft(마법공예) 회선검, 원작 내부 이름 回旋之刃 / Boomerang Blade, 원작 능력 코드 1022.

## 확정 결정

1. **달빛 부메랑의 핵심 비행과 귀환 방식은 마법공예 회선검을 기준으로 재설계한다.** 기존의 ‘목표까지 정해진 베지어 곡선 → 명중 시 도탄 또는 즉시 귀환’ 중심의 구조 대신, 진행 관성을 유지하며 시전자 방향으로 **매 프레임 부드럽게 휘어 돌아오는 왕복 비행**을 기본 동작으로 삼는다. 원작 코드를 복제하거나 자산을 반입하지 않고 검증된 메커니즘을 Godot에서 독립 구현한다.
2. **달빛 부메랑 자체에 기본 내장된 도탄을 삭제한다.** ‘강화 단계에 따라 내장 도탄 횟수가 증가’하는 현행 설계도 철회한다. 적에게 맞았다는 이유만으로 자동으로 다른 적을 찾아 도탄하는 기본 무기가 아니다.
3. 기본 컨셉은 **관통하는 회선검형 탄환의 출발·귀환 경로 활용**이다. 동일 적을 왕복으로 다시 맞힐 수 있는 구조를 우선한다. 구체적 재타격 쿨다운·피해/관통/속도·강화 증가량은 별도 밸런스 검증에서 결정한다.
4. 이 결정이 삭제하는 것은 **달빛 부메랑의 기본 내장 도탄**이다. 별도 **‘도탄’ 보조 마법 전체**, 다른 마법의 도탄 기능, 합성 보조 ‘포식 도탄’을 삭제하라는 지시로 확대 해석하지 않는다. ‘도탄 + 달빛 부메랑’ 결합의 상세 동작과 ‘쌍월륜’(부메랑+도탄) 합성은 이번 결정에 맞춰 **별도 호환성 검토** 대상이다.
5. **보고서에만 기록한다.** 사용자 요청은 게임 코드 변경이나 배포가 아닌 보고서 등록이다. 실제 구현·Godot 테스트·웹 배포는 미실시.

- `scripts/spell_progression.gd`: `data.ricochets = r`, 합성 기본 3회, '추가 도탄 ... 귀환' 업그레이드 설명.

정확한 이동 공식, 초당 회전 속도, 최대 비행 거리, 관통 수, 동일 대상 왕복 재타격 쿨다운, 강화 단계별 성장, 도탄 보조 및 쌍월륜과의 합성 규칙. 참고 게임의 수치를 무조건 그대로 이식하지 않는다.
