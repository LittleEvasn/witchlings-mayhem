## 승인 범위 — 기존 04 보고서의 UI 방향 그대로

1. **조회 전용 도감**: 상위 탭 `주문 / 완성 합성 / 유물`, 발견 수/전체 수 확인. 실제 획득만 발견 등록. 도감에서 마법·유물을 지급하거나 장착하지 않는다.
2. **좌측 아이콘 목록 + 우측 상세 정보**의 2영역 구조. 아이콘 목록은 **6열×5행 초기 시제품(96×96, 간격 10)**을 우선 시험한다. 이는 **구현 테스트 목표**이지 모든 해상도·항목에서 절대 좌표/최종 칸수 확정은 아니다. 1280×720 등이 좁으면 5열/셀 크기 조정 비교 가능.
3. **주문/완성 합성의 역할 필터:** `전체 / 공격 / 보조 / 연결`. 유물 탭은 해당 역할 필터를 강제하지 않는다.
4. **발견/미발견 표시:** 목록에서 아이콘 또는 `?` 표시; 발견 상태와 이름·효과 공개 수준은 실제 프로필과 현재 공개 정책을 따른다. **기존 미발견 완성 합성의 두 부모 재료 힌트는 숨기지 않는다.**
5. **오른쪽 상세:** 선택 항목 이름, 역할, 설명, 발견 상태; 일반 주문은 `기본 / +1 / +2 / +3` 전환과 **이전 단계 대비 변경점**을 읽기 쉽게. 강화 설명은 카탈로그 실데이터이며 가짜 수치를 추가하지 않는다.
6. **합성 상세:** `[재료 A +3] + [재료 B +3] → [완성 합성]` 구조. 재료 선택 시 해당 기본 주문 상세로 이동하고, 기본 주문에서는 관련 완성 합성 링크로 돌아갈 수 있게 한다. 조합 레시피·경제·강화 규칙은 UI 개선으로 변경하지 않는다.
7. **탐색 상태 보존:** 목록 스크롤, 선택 항목, 필터, 합성 ↔ 재료 상세 왕복, 키보드·패드 포커스, 타이틀·제작함으로 돌아가는 기존 `collection_origin` 복귀 계약을 유지한다.
8. **아트 방향:** 참고 작품 중 **Magicraft의 서적/책갈피 인상**을 일부 활용하되 평면적인 크림/라벤더·둥근 패널과 가독성을 우선. **과한 종이·목재·금속 질감이나 원작 아트 복사는 금지**. 최종 구체 디자인 스킨/그림은 별도 시안·검토.
9. **참고 게임 역할:** Magicraft(마법 서적/상세), Vampire Survivors(발견 아이콘 격자), Slay the Spire(강화 비교), Noita(아이콘 수집), HoloCure Armory(분류) 등은 보고서에서 각각 기재한 UI 장점만 참고. Terraria/Hades의 몬스터·인물 도감은 **향후 가능성**일 뿐 새 화면의 확정 개발 범위가 아니다.

## 기존 데이터와 최신 결정이 다른 부분 — 원문 수치 교체 승인 아님

- 04 보고서 **작성 시점**에는 **일반 주문 30, 완성 합성 30, 유물 12**라는 코드·설계 현황이 있었으며, 역할별 예시(기본 12/15/3, 합성 24/5/1)는 그 데이터 기준이다.
- 이후 **2026-10-31 최신 합성 기획 결정은 기존 30종 중 11종 유지·개편, 19종 폐기**. [최신 합성 검토 보고서](../reports/2026-10-31-final-five-fusions-disposition-and-30-roster-review-complete.md)는 확인 당시 실제 코드 `FUSIONS`가 **29종 활성**이며 기획 삭제가 대부분 미반영이라고 명시한다. 그 **29는 기존 보고서의 코드 관찰값이지 이 결정에서 새로 검사한 실시간 숫자가 아니다**.
- **따라서 도감의 완성 합성 30개/역할별 합성 분포를 미래 최종 수량으로 확정하지 않는다.** UI는 실제 활성 카탈로그/최신 승인된 콘텐츠 정의를 읽어 동적으로 개수·발견률·필터를 표시할 목표이며, 폐기 19종을 자동 복구하거나 30개를 채우려고 새 합성을 만들지 않는다.
- 일반 주문 30/유물 12도 실제 구현 때 **현재 카탈로그와 프로필을 대조**한다. 문서 수량은 구현 시점의 근거이며 새로운 경제·발견 정책을 정하는 값이 아니다.
- 비공개 완성 합성의 **재료 힌트는 유지**, 완성 결과의 상세 효과는 기존 발견 조건을 따른다. 별도 저장 정책 없이 `NEW` 열람 추적을 새로 만들지 않는다.
