# MAGIC-VORTEX-2026-10-30-01 · 소용돌이 씨앗 → 마법공예 블랙홀 방식 개편

**상태: APPROVED — 사용자 설계 확정, 게임 코드 미수정, Godot 테스트 미실행.**
[확정 결정 문서](../decisions/2026-10-30-vortex-magicraft-black-hole-replacement.md)

> 사용자 요청: **“일단 블랙홀 코드 그대로 가져와. 소용돌이끼리 겹치는거 없애고.”**

## 확정 변경 요구

1. 기본 공격 `vortex`(소용돌이 씨앗)는 **마법공예(Magicraft) 블랙홀(Black Hole, 원작 주문 1007)**의 실제 소스에 근거해 새로 구현한다. 검증된 원본의 이동, 적 흡입, 주기적 범위 피해, 시간에 따른 성장, 수명과 종료 동작을 충실하게 Godot에 포팅한다. **원래 소용돌이 씨앗에 블랙홀 그림만 덧씌우는 편법은 불합격**.
2. 기존 소용돌이들의 **서로 겹치기·병합·중첩을 통한 크기 성장 메커니즘을 완전히 폐기**한다. 같은 위치에 반복 설치해 성장하는 `garden_id`/ `garden_mass`/ `garden_merges`/ `garden_full` 규칙은 소용돌이에 더는 사용하지 않는다.
3. 원작처럼 **블랙홀 하나가 스스로 성장**한다. 원작 자료에서 기본 1단계는 성장하지 않고 2·3단계는 시간 비례 반경이 커진다. 적 처치/흡입 수량에 따른 성장을 원작으로 오인하지 않는다.
4. **소용돌이의 기본 도탄·설치/중첩 전제를 제거하거나 교체**하더라도 별도의 도탄 보조와 다른 주문 기능을 함부로 삭제하지 않는다. 공전 소용돌이 `orbit_vortex`, 붕괴 소용돌이 `collapse_vortex`는 새 기본 공격과의 호환성을 다시 확인한다.
5. **가시꽃 덫 `thorn`은 중첩 함수를 공유하므로 유지**한다. 공용 함수를 통째로 삭제하면 다른 공격에 영향을 주므로 반드시 소용돌이 대상 분기만 제거/분리한다.
6. 이름 변경은 지시되지 않았다. 표시명 **소용돌이 씨앗**은 우선 유지하며 공격 설명에서 “같은 곳에 모아 심으면 범위 성장” 문구를 삭제한다.

## 원작 수치·연산 비교

| 값 | 원작 블랙홀 1/2/3레벨 | 우리 현행 소용돌이 씨앗 |
|---|---|---|
| 기본 피해 설정 | 22 / 56 / 140 | 장판 파생 피해 2.5 기준에서 계산 |
| 기본 반경 | 2.25 Unity 단위 | 강화 0~3: 86/105/125/150 Godot 픽셀 |
| 지속시간 | 모두 5초 | 강화 0~3: 3/3.5/4/4.5초 |
| 피해 간격 | 0.25초 | 0.25초 |
| 속도 설정 | 1.2 Unity 단위 | 씨앗 이동 320 Godot 픽셀/초 |
| 성장 파라미터 `Float1` | 0 / 0.4 / 0.8 | 다른 소용돌이 합체 수에 따라 +10~20% |

원작 `Spell1007Job.cs`의 반경 증가 공식은 `growth = Float1 * DeltaTime / 2 * TimeScale`이고, 실제 충돌 판정도 매 업데이트의 성장 반경을 사용한다. 적이 없는 곳에서도 성장 단계라면 시간이 흐르며 커진다. 원작의 `damage`는 DPS형 값이므로 틱당 피해와 혼동하면 안 된다. 서로 다른 게임 엔진의 수치를 그대로 대입하지 말고 좌표·피해 단위 변환과 결과를 대조할 것. 우리 4개 강화단계에 대한 원작 3개 레벨의 정확한 매핑은 아직 **미확정**이다.

## 현재 코드의 수정 위치

- **`scripts/spell_behaviors.gd`**: `register_garden()`의 근거리(48) 그룹 합치기와 `refresh_gardens()`의 `mass` 성장 규칙을 **소용돌이에 한해 폐기**. 다른 공격 `thorn` 기능 유지.
- **`scripts/spell_runtime.gd`**: 씨앗 `install()`과 `update_zones()`의 현재 설치 후 정지하는 지속피해·당김을 블랙홀의 이동형 지속 개체로 전환. 현재의 `garden` 호출과 연동된 소용돌이 분기 제거. 발동/소멸/후속 마법 이벤트 유지 여부 검사.
- **`scripts/spell_progression.gd`**: 기존 반경·지속시간 중심 강화에서 원작의 강화별 시간 성장 개념으로 변경.
- **`scripts/magic_catalog.gd`**: 기존 중첩 성장 설명 삭제, 새로운 블랙홀식 작동 설명.
- **`scripts/magic_extensions.gd`**: 공전 소용돌이·붕괴 소용돌이의 새 중심·공격 판정·종료 이벤트 재검토.
- **`scripts/magic_visuals.gd`**: 실제 충돌·흡입 반경을 따라 커지는 블랙홀 비주얼.

## 겹침 처리에서 구분할 사항

**확정:** 소용돌이끼리 합체, 중첩 스택, 합친 개수에 따른 크기 성장 모두 삭제. 사용자 발언의 “겹치는거 없애고”를 고려해 같은 위치에서 여러 소용돌이가 시각적으로 포개지는 상황도 없애는 방향이다.

**추가 배치 정책 제안(미확정):** 같은 위치를 차지하는 신규 소용돌이는 이전 소용돌이를 **교체**하고 하나만 남긴다. 단순히 합체 계산만 없애고 여러 개를 포개서 중복 피해를 주는 방식은 사용자 의도에 어긋날 수 있다. 새 소용돌이를 옆으로 배치하는 대안도 있으며 **구체적인 중복 생성 처리 규칙은 확정 전까지 임의로 구현하지 않는다**.

## 구현 후 테스트

- 원작의 중심 방향 당김, 0.25초 틱 피해, 지속시간, 시간 성장, 이동을 Godot 실제 엔진에서 실측할 것.
- 0명·1명·10명 적, 보스·엘리트, 이동 중/시간 만료, 4오브, 갈래·추적·공전·낙하·분열 등 보조 조합을 테스트할 것.
- 동일 위치로 2~3회 발사 시 **중첩 성장 0**, 겹쳐 보이는 개체 없음, 중복 당김/피해 정책 일치 확인.
- **`thorn`의 중첩과 `orbit_vortex`/`collapse_vortex`의 합성 효과 회귀 검사**.
- 컴파일 성공만으로 완료 처리하지 말고 실제 이동 좌표·반경·적 피해·흡입 변화와 화면을 확인한다.
