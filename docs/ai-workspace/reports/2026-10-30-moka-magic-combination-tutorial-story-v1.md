## 1. 기획 목적과 기존 설정

- 본편 자율 마법 조수 제작 **이전**, 벨루나 마법학원 방과 후 실습장에서 모카가 마법 조합 보충수업을 받는다.
- **루미**: 실습을 주도하는 천재형 선생님. **세라**: 조합 규칙을 정확히 설명하고 오류를 교정. **네라**: 표적 인형과 보조 설명. **모카**: 직접 배우는 학생이자 플레이어의 질문을 대변.
- 모카를 무능하게 그리지 않는다. 마나 총량·실전 능력은 우수하지만 정교한 조합과 배치에 익숙하지 않다는 설정.
- 학습 순서: 공격 장착 → 보조 적용 → 사건 연결 → 연결 전후 보조 범위 → 자유 실습 → 자동 주문 생성 아이디어 → 금서 실험 → 폭주.
- 첫 플레이 약 5~7분의 목표. 실제 조작 시간에 따라 다르며 장면별 대사 넘기기와 튜토리얼 스킵이 가능해야 한다.
- 플레이어는 실습용 **오브 UI**를 조작한다. 시나리오상 모카가 배우지만, 별도 모카 전투 캐릭터를 튜토리얼의 구현 선행 조건으로 삼지 않는다.

## 2. 플레이 규칙과 실습 준비

- 튜토리얼 임시 구체: `별빛탄`, `갈래`, `명중 후`, `꽃폭탄`, `거대화`. 차례가 올 때 가방에 지급하며 신규 구체를 **자동 장착하지 않는다**.
- 실습은 오브1의 1~6번 고정 슬롯에서 진행. **빈칸 유지·실행 시 빈칸 건너뛰기**와 실제 드래그 배치를 그대로 사용한다.
- 보조는 같은 구간에서 오른쪽의 공격에 적용하며, **연결을 지나면 적용 범위가 초기화**된다.
- `명중 후`는 공격 인스턴스의 **첫 유효 명중**에 후속을 발동한다. 매번 피해 틱마다 후속 발동하지 않는다. 후속 위력은 현재 실제 게임 규칙에 따른다.
- 조합 오류는 해당 부분을 경고/비활성화하되, 다른 정상 공격은 실행된다. 오류/상쇄 UI의 색상 상세는 별도 최신 사용자 결정을 따른다.
- 연습 인형은 적을 공격하지 않는다. 시험 발사는 본편 전투 시간을 소비하지 않고 반복 가능. 성공 판정은 배열 조건뿐 아니라 실제 발사·명중·후속 이벤트로 확인.
- 본편 시작 전 튜토리얼 임시 재고를 제거하고 정상 시작 조합·전투 초기화 규칙 적용. 튜토리얼 도중 마석·전투 성장을 임의 지급하지 않는다.

## 4. 예외 상황 대사

| 상황 | 캐릭터 및 대사 | 처리 |
|---|---|---|
| 공격 없음 | 네라: “……아직 오브가 비었어. 별빛탄부터 올려 보자.” | 조작 안내 |
| 공격 뒤에 보조 | 세라: “지금은 갈래의 오른쪽에 공격이 없네. 별빛탄 앞으로 옮겨 봐.” | 구체 강조 |
| 발수 예상과 다름 | 루미: “어라? 한 발뿐이네. 순서를 뒤집으면 어떨까?” | 실패/재시도 |
| 연결 앞 공격 없음 | 세라: “연결은 앞에서 일어날 사건이 필요해. 먼저 공격 마법을 배치해.” | 연결 경고 |
| 연결 뒤 공격 없음 | 네라: “……연결 뒤에 이어서 쓸 마법이 필요해.” | 후속 경고 |
| 연결 연속 배치 | 세라: “연결 사이에 후속 공격이 없어서 조건이 이어지지 않아.” | 오류 부분 비활성 |
| 꽃폭탄 독립 발사 | 루미: “그 배치면 꽃폭탄을 따로 쓰는 거야. ‘맞으면 폭발’시키려면 사이에 연결을 놓아야지.” | 배치 재안내 |
| 범위 오해 | 세라: “연결을 지나면 보조 범위가 새로 시작돼. 갈래는 별빛탄 쪽에만 적용돼.” | 범위 강조 |
| 반복 실습 | 루미: “마음껏 쏴 봐! 여기서는 마석도 안 들거든!” | 한 번만 표시 |

동일 오류 반복 시 대사 전체 재생을 강요하지 않는다. 첫 번째만 음성/대사, 이후 짧은 툴팁 중심.

## 5. 화면·상태·완료 조건

| 단계 | 완료 조건 | 실패/중단 |
|---|---|---|
| T01 공격 | 오브 2번에 별빛탄 장착, 시험 발사에서 1발 유효 명중 | 재배치/재시도 |
| T02 보조 | 갈래가 별빛탄 왼쪽에 있고 시험 시 3발 발사 | 설명 한 번, 재시도 |
| T03 연결 | 별빛탄의 첫 명중 이벤트가 꽃폭탄 후속을 발생 | 명중 안 되면 다시 |
| T04 범위 | 갈래는 앞 공격, 거대화는 뒤 공격에만 적용됨을 실제 검증 | 연결 경계 강조 |
| T05 자유 | 사용자 배치에서 적어도 하나의 정상 공격이 실제로 실행됨 | 시간 제한 없음 |
| T06~08 극 | 대사 진행/스킵 후 정상 본편 시작 | 씬 이중 실행 방지 |

- 첫 튜토리얼은 조작 중 캐릭터 대사가 화면 대부분을 가리지 않게 하며, 조작 중 전투 타이머가 진행되지 않는다.
- 드래그를 놓을 수 없는 칸/수량 중복/시험 초기화/건너뛰기/연속 클릭/장면 재진입을 포함해 상태 누수를 점검한다.
- 적중 이벤트가 나오지 않은 장면을 시각 효과 하나로 성공 처리하지 않는다.
- 모든 마법 종류를 강제로 가르치지 않는다. 원소, 공전, 낙하, 분열, 전체 60종, 합성·오브 성장·상점은 본편 학습으로 남겨 둔다.
- 대사/UI 작업은 현행 오브·인벤·시험 발사 코드를 활용하며 무관한 경제·밸런스·마법 효과를 변경하지 않는다.
- 캐릭터별 일반 엔딩에서 밝혀질 네 가지 실수는 프롤로그에 직설적으로 설명하지 않는다.
