| 완성 합성 | 기존 내부 ID | 구형 레시피 | 기존 코드의 효과 | 최신 기획 |

### 삭제 범위의 경계

1. **완성 합성 `shard_satellite`, `clock_satellite` 2종만 폐기한다.** 일반 공격 **달무리 위성(`satellite`)**, 보조 **분열(`split`)**, 연결 **시간 트리거(`timer`) 자체는 삭제하지 않는다**.
2. `satellite + split` 및 `satellite + timer` 두 쌍에서 **완성 합성 결과가 나오지 않도록** 구현 시 제거한다. 부모 마법·보조·연결을 단독으로 쓰는 일반 기능이 허용되는지는 기존 문법을 따른다.
3. **후속 대체 합성은 지정하지 않는다.** 과거 합성 30종에서 사용자 승인된 **빙정 삼중파 1종 삭제**로 기획 목표가 **29종**이었고, 이번 **2종 추가 삭제로 최신 기획 목표는 27종(3종 공석)**이다. 이 숫자는 **기획상 누적**이며 현재 제품 코드에서 완성 합성이 실제 27종으로 줄었다는 의미가 아니다. 앞으로 빈 자리를 임의 신규 합성으로 채우지 않는다.
4. 기존 [시간 트리거→마법공예 휘감기(3204)식 후속 공전](../decisions/2026-10-31-correction-trail-chain-timer-entangle.md) 사용자 결정은 그대로 유효. **시계 위성 합성 삭제는 `timer` 자체의 휘감기 개편을 취소하지 않는다.**
5. [시한 가시꽃 삭제/빙설 전선으로 대체·빙정 삼중파 삭제](2026-10-31-timed-thorn-replaced-by-hailfront-triple-frost-removed.md)는 그대로 유지한다. 과거 문서에 시계 위성을 보존·검토한다고 적힌 부분은 **이 최신 2026-10-31 삭제 결정으로 이 대상에 한해 갱신**한다.

## 2. 현재 코드와 삭제 구현을 위한 주의점 — 이번엔 코드 미변경

- [`scripts/magic_catalog.gd`](../../../scripts/magic_catalog.gd)에는 아직 두 합성이 `FUSIONS`에 등록돼 있다:
  - `"shard_satellite":{"name":"파편 위성","parents":["satellite","split"],...}`
  - `"clock_satellite":{"name":"시계 위성","parents":["satellite","timer"],...}`
- [`scripts/spell_behaviors.gd`](../../../scripts/spell_behaviors.gd)에는 두 ID 분기가 존재한다(파편 위성 `shard_satellite` 분기, 시계 위성 `clock_satellite` 분기). **게임 구현 시 해당 전용 분기·부속 시각/전기선·예약/상태만 참조 범위를 확인한 뒤 제거**하고, 다른 위성 마법의 공용 처리 코드를 무단 삭제하지 않는다.
- `scripts/spell_progression.gd`의 합성 검색, 도감/보상/제작/훈련장·테스트 데이터·기존 저장/발견 기록·합성 업적에서 두 ID의 유령 참조가 남지 않는지 확인해야 한다.
- 기존 문서 [`docs/MAGIC60-IMPLEMENTATION-v1.md`](../../MAGIC60-IMPLEMENTATION-v1.md)에 적힌 두 종의 효과는 **과거 구현 기록**으로 남긴다. [`MAGIC-60-INTERACTION-TECHNICAL-REVIEW-v1.md`](../../MAGIC-60-INTERACTION-TECHNICAL-REVIEW-v1.md)의 F15/F16 평가 또한 **역사적 검토**이며 이번 사용자 삭제 결정보다 우선하지 않는다.
- [기존 Magic60 전수 검사](../../MAGIC60-FIX-AND-TEST-REPORT.md)에서 시계 위성 전기선의 중복 범위피해 및 고부하 사례가 보고됐지만, 이번 삭제는 **성능 수정을 승인한 게 아니라 해당 합성 자체를 더 이상 유지하지 않겠다는 기획 결정**이다.

## 3. 별도 질문: 열충격 발자국 보고서 존재 여부

**확인 결과: `docs/ai-workspace/reports/` (검토 당시 48개 파일) 및 `docs/ai-workspace/decisions/` (23개 파일)에 '열충격 발자국(`thermal_trail`)'을 대상으로 한 독립 개편 보고서·확정 결정문은 찾지 못했다. `INDEX.md`에도 전용 항목이 없다.**

다만 **이미 일반 마법 구현·기술검토 문서에는 구형 효과가 기록**되어 있다.

- [마법 60종 구현 기록](../../MAGIC60-IMPLEMENTATION-v1.md): **열충격 발자국 = 잔불 발자국(`ember_path`) + 빙결(`element_ice`)**, **원형 잔불 유지 · 동결한 적 접촉에 한 번 열충격**.
- [마법 60종 기술 검토](../../MAGIC-60-INTERACTION-TECHNICAL-REVIEW-v1.md): `F17`에 **동결된 적이 없을 때도 기본 잔불 기능 보존** 및 `F29` 온도 역전과 효과 중복 검토 필요 기록.
- [마법 전수 검사](../../MAGIC60-FIX-AND-TEST-REPORT.md): `fall + thermal_trail` 낙하 보조 결합 표본 테스트. 이는 **새 개편 기획 승인 문서가 아니라 테스트 기록**이다.
- [현재 합성 카탈로그](../../../scripts/magic_catalog.gd): `thermal_trail` 레시피/구형 설명 남아 있음.

**결론:** **열충격 발자국은 기존 목록/구현/전수 검토에 기록된 상태일 뿐, 최근 사용자 승인 개편안의 별도 보고서는 없다.** 이번 사용자 지시에는 해당 합성의 삭제·교체 요청이 없으므로 **유지/변경/폐기를 새로 확정하지 않는다**.

## 4. 향후 삭제 구현 검증 기대값

- `shard_satellite`, `clock_satellite`이 새 합성 후보·도감·훈련장·저장/제작 목록에서 더 이상 활성 완성 합성으로 등장하지 않음.
- `satellite+split`, `satellite+timer` 쌍이 **빈 합성**으로 남으며 **기본 위성/분열/시간 연결 자체는 정상**.
- 구형 전용 파편 생성/전기선 정렬·명중 및 예약/시각 데이터가 다른 주문을 건드리지 않고 안전하게 제거.
- 옛 사용자 저장/도감 ID가 오류를 내지 않게 처리하고, 합성 공석 3종을 임의로 메우지 않음.
- **검증 상태 분리:** 이번은 GitHub 문서·기존 코드 정적 확인만 수행. Godot 컴파일/게임 내 목록/공격 장면/성능 테스트 **미진행**.

**최종 결정:** **파편 위성·시계 위성 대체 없이 폐기. 최신 기획상 완성 합성 27종/3공석. 열충격 발자국은 기존 목록과 기술검토에만 기록된 상태이며 독립 개편 보고서는 없음.**
