## 2. 탱탱볼 독구체의 승인된 핵심

1. **발사체 공격:** 이전 `ember_path`의 플레이어 이동 경로 기반 바닥 장판 생성 메커니즘을 **폐기**하고, **독구체라는 실제 투사체를 발사·생성**하는 공격으로 교체한다. 시전자가 걸어야만 장판이 남는 형태가 아니며, 제자리에 서 있어도 공격 주문은 정상 발사할 수 있어야 한다.
2. **눈에 보이는 '탱탱볼' 탄성:** 구체가 앞으로 이동하면서 **실제 위치/궤적이 튀는 방식으로 바뀌어야 한다**. 공중에 떠서 직진만 하는 구체에 스케일 애니메이션만 주거나, 독장판 위에 둥근 그림만 얹은 것은 요구 미충족. 2D 탑다운 게임에서 수직 튕김의 **실제 전진 좌표와 가시적인 높이·그림자/탄성 표현**, 벽/맵경계/적 접촉 중 무엇을 실제 반사·재충돌 조건으로 쓸지는 **코덱스 세부 기획 검토 항목**이며 아직 사용자 확정 규칙이 아니다.
3. **독 공격:** 닿은 적에게 **실제 충돌/피해 판정**이 있고 독 속성의 공격으로 동작해야 한다. 기존 `element_poison` 상태/독 피해 규칙과 호환되도록 설계한다. 구형 `ember_path`가 갖고 있던 **화상 자동 부여를 없애야 한다**. '독구체' 자체가 **독장판을 남긴다는 지시는 없다**.
4. **독장판 삭제:** 과거 보고서에서 제안한 **플레이어 이동 시 독장판 설치**는 **전면 철회**한다. 신규 기본 독구체가 **이동하며 바닥에 독장판을 깐다/적중 후 독장판을 남긴다**는 추가 속성을 임의 부여하지 않는다. 다만 기존 **독 원소 보조**로 인해 중독된 적의 이동 위치에 생기는 독 흔적은 별도 기존 체계이며 이번 지시로 자동 폐기하지 않는다.
5. **타격 후 진행:** 적 접촉 시 관통·반사·이탈·소멸 중 어떤 행동을 하는지, 충돌 시 튀는 조건과 정확한 방향·횟수, 강화별 구체 개수·크기·속도·사거리·피해·수명·독 지속·반사각, 구체/바닥의 시각 구성은 **미확정**이다. '탱탱볼처럼 튀는 발사체'라는 **핵심 동작만 승인**되어 있으며 임의로 무한 도탄이나 폭발·독장판을 추가하지 않는다.
6. **다른 마법과 시각·역할 구분:** **구형 번개(`ball_lightning`, 기존 그대로 유지)**도 '구형' 투사체지만, 느린 전기구체가 주기 방전하는 마법이다. 이번 **독구체**는 **탄력적 튕김+접촉 독 공격**으로 구분되어야 하며, 구형 번개의 0.4초 주기 자동 방전을 복사하면 안 된다.
7. **화염구 보존:** `fireball`의 기본 화염탄, 독립 운석 합성 `meteor` 및 화염 상태이상은 손상시키지 않는다. 이미 폐기한 `thermal_trail`·`mirror_trail`이 과거 `ember_path`를 부모로 가졌다는 이유로 부활시키지 않는다.

### 실제 동작 합격 기준 (코드 미실행)

- 움직이지 않는 플레이어가 이 주문을 시전하면 **실제 독구체가 발사**된다.
- **독구체의 이동 위치/상태가 튀며 변화**하고, 시각 궤적과 충돌·피해 위치가 일치한다. 단순 '녹색 원만 직진' 혹은 '독 원형 장판 생성'은 불합격.
- 적에게 닿으면 독 관련 유효 피해/상태가 발생하며, 기본 화상·과거 불장판/독장판 자동 생성은 발생하지 않는다.
- 기존 구형 번개의 고유 방전, `element_poison`의 적 이동 독 흔적, 화염구+운석 및 레시피/세이브 호환을 보존.
- 실제 발사/충돌/추가 반사 조건·경계/장애물 처리·강화·다수 구체·성능/종료·저장 회귀를 Godot에서 별도 검증. 본 보고서는 아직 게임 코드나 실행의 증거가 아님.
