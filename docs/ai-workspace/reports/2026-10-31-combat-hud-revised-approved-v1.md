## 3. Tab 가방을 열었을 때

- 상단 왼쪽 가방이 열리고, 그 바로 아래 오브 최대 4개의 마법 슬롯 편집 구조가 이어진다.
- 열린 인벤토리가 **상단 중앙 시계를 가린다. 시계를 축소/이동/다른 패널에 복제하지 않는다.**
- 오른쪽 위 유물 세로열, 왼쪽 아래 체력/보호막/마석, 최하단 EXP 바는 유지한다.
- **일반 Tab 중에는 전투 비정지.** 레벨업 보상 선택 전후 일시정지·명시적 재개와는 구별한다.
- 가방/오브에서 실제 소유 수와 실제 슬롯(오브별 6~8칸), 실제 장착 마법 및 주문 순서만 표시한다.
- 사용자 명시적 채용은 **일반 전투 HUD**이며 Tab 개방 PNG는 함께 검토한 동반 시안이다. 세부 인터랙션·정확한 좌표는 구현 전 별도 검증 가능하다.

## 4. 구 UI 보고서 처리 및 우선순위

**이전 HUD 관련 문서는 구 보고서이며 다음 과거 권고를 폐기한다.**

- 체력·보호막·마석을 **오른쪽 아래**에 배치
- 유물을 **왼쪽 아래** 또는 **오른쪽 아래**에 배치
- 경험치 바를 **최상단**에 배치
- 가방을 열었을 때 시계를 작은 헤더로 **옮겨 계속 표시**
- 시계 아래 **보스 HP바** 추가
- 가방과 오브를 서로 먼 위치에 분리

**다른 화면의 기획까지 일괄 폐기하지 않는다.** 구 보고서에 들어있는 보상 3~4택, 보물상자 1/3/5개, 제작·도감·설정·툴팁 등은 *별도 검토가 필요한 과거 제안*으로 유지한다. 마법 상쇄 노랑/비작동 빨강 및 UI 간결한 문체처럼 별도 승인된 규칙은 그대로 유효하다.

## 5. 구현 단계 검증 조건

1. 오브·가방·시계·유물·자원이 채용 이미지와 같은 **화면 영역**에 존재하고 간섭하지 않을 것.
2. 오브 최대 4, 각 실제 슬롯 6~8칸, 유물 실제 보유 수와 일치하며 가짜 데이터가 없을 것.
3. 가방 개방 시 시계는 **가려지고**, 닫으면 다시 표시될 것.
4. Tab 중 전투 진행을 유지하고, 보상 모드의 정지·재개 규칙은 변경하지 않을 것.
5. 유물 우상단 세로 / HP·보호막·마석 좌하단 / EXP 최하단 전체 폭을 확인할 것.
6. MP 및 보스 HP바를 임의로 추가하지 않을 것.
7. 1600×900뿐 아니라 다른 뷰포트에서도 잘림·드래그·가독성을 검증할 것.
8. Magicraft의 UI **구조 참고**와 원작 이미지/코드의 무단 복제는 구분할 것.
