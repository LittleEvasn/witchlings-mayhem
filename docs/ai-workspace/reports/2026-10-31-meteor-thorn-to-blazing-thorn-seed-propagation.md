## 1. 확정 개편: 단순 원소 부여가 아닌 **번식형 화염 함정**

| 구분 | 구형 유성 가시꽃(현재 제품 코드) | 새 작열 가시꽃(사용자 확정 설계) |
|---|---|---|
| 합성 재료 | `thorn + fall` | **`thorn + element_fire`** |
| 표시명 | 유성 가시꽃 | **작열 가시꽃** (화염 가시꽃 컨셉) |
| 설치/발사 | 낙하 예고 → 착지 시 작은 덫 2개 | **가시꽃 계열 씨앗 설치/전개 동작**을 바탕으로 화염 본체 덫 형성 |
| 발동 조건 | 접근 시 덫 발동 | **적이 본체 덫을 밟거나 접근해 발동** |
| 본체 공격 | 일반 가시꽃 덫과 유사한 폭발 | 불타는 가시가 뻗는 **작열 공격**과 씨앗 사출을 가진 번식형 발동 |
| 씨앗 발사 | 없음 | **본체가 터질 때 작은 화염 씨앗 약 3~4개를 주위로 사출** |
| 씨앗 운동 | 없음 | **씨앗이 실제로 대굴대굴 굴러 이동**, 이동 뒤 **더 작은 화염 가시꽃 덫**으로 전개 |
| 새끼 덫 | 없음 | **본체보다 작은 덫**이 각각 독립적으로 적의 접근/발 밟기를 기다린 뒤 화염 가시 공격 |
| 고유 전투 역할 | 사실상 낙하 + 덫 2개 | **단일 덫 발동이 전장 주변에 후속 함정을 퍼뜨리는 지역 점유·확산** |

### 실제 플레이에서 보여야 하는 순서

1. **본체 씨앗 투척·굴림 → 원형 덫 전개.** 기존 사용자 승인 **가시꽃 덫(`thorn`)의 마법공예 '괴이한 지뢰(1012)' 기반 바닥 튐/굴림/지연 전개** 원리를 잇는다. 본체가 `낙하` 연출로 하늘에서 떨어지면 이전 재료를 바꾸는 의미가 없다.
2. **본체 발동.** 적이 본체 작열 가시꽃을 밟으면 덫이 불타는 가시 공격을 발생시키며 터진다.
3. **새끼 씨앗 3~4개 방출.** 단순히 같은 자리에 4개 장판을 즉시 생성하는 게 아니라 **작은 불꽃 씨앗이 사방으로 실제 튀고 바닥을 따라 구른다**. 발사 수 `3~4`는 사용자가 제시한 범위이고 3 고정/4 고정/무작위/강화별 개수는 미확정.
4. **새끼 덫 전개.** 굴러간 씨앗이 각자의 정지·전개 조건에 따라 **본체보다 작은 소형 화염 가시꽃**으로 펼쳐진다. 이 과정은 불꽃 알갱이 연출이 아니라 플레이 공간에 남는 **실제 함정 생성**이다.
5. **새끼 덫 공격.** 소형 함정 역시 **적 접근/밟기에 반응하여 실제 가시 피해와 화염 계열 효과**를 준다. 새끼 덫의 재번식 허용 여부는 별도 명시(아래 참고).

**최소 정체성:** 일반 `thorn + element_fire`의 기존 설치·발동에 화상만 더한 공격이 아님. **작열 가시꽃 본체 한 번 발동 → 굴러가는 새끼 씨앗 3~4개 → 주변에 작은 신규 화염 덫 생성**이 있어야 한다.

## 2. 확정과 아직 승인되지 않은 설계 제안의 구별

### 사용자 승인으로 기록할 내용

- 이전 **유성 가시꽃**의 `가시꽃+낙하` 조합은 **가시꽃+화염**으로 교체.
- 불에 타는 평범한 덫이 아니라 **발동 후 화염 가시꽃이 주변에 증식**하는 것이 고유 개성.
- 적이 밟으면(접근 발동) 본체가 터지고, **작은 씨앗 약 3~4개가 실제로 굴러간 다음** 주위에 **작은 화염 가시꽃 덫**을 배치.
- 본체와 새끼를 포함해 **가시꽃의 씨앗 굴림→덫 전개→적 접근 감지**라는 흐름을 유지.
- 새 합성의 명칭은 직전 대화에 제시되어 받아들인 **작열 가시꽃**을 우선 명칭으로 기록한다. 더 구체적인 UI 표기/툴팁은 구현 시 조정 가능.

### 제안(미확정): Codex가 임의로 확정하지 말 것

- **새끼 덫은 재번식하지 않음**: 매 새끼가 또 3~4개를 생성하면 개체 수가 급증하므로 **1세대만 추가 생성** 권고. **사용자가 재귀 증식을 명시적으로 확정한 것은 아님.**
- 본체 발동 시 **바깥으로 길게 뻗는 6~8개의 화염 가시, 실제 선형 판정**은 직전 A안 기반의 시각·공격 설계 제안. 개수·사거리·틱·화상량 미확정.
- 새끼의 크기는 **본체보다 작음**까지만 확정. 예: 40~60% 반경, 낮은 피해/수명은 *미승인 예시*.
- 씨앗 발사각·구르는 거리·속력·바닥 반동·충돌/멈춤 시간·서로 겹침/중첩 규칙·무작위성 미확정.
- 새끼 덫의 적에게 주는 **정확한 피해, 화상량, 공격 횟수, 유지시간** 미확정.
- **원소 재귀, 소멸 후 연결, 분열/갈래/메아리, 명중 후·시간 트리거/타 합성**의 자손에게 어떤 연결 권한을 계승할지 명확한 실행 정책 필요. 생성 루프 방지 및 한 시전의 피해 예산/원소량 보존 권고.
- **`얼음 + 낙하` 가능성은 사용자가 제기한 후속 조합 아이디어**이지만, 현재 목록에서 `element_ice + fall`은 **보조+보조**이며 `frost(얼음검)+fall`은 **공격+보조**. 어느 쪽을 새 합성으로 만들지는 **미확정**, 이 보고서에서 합성 추가·교체 확정 금지.

## 3. 원작 참고 및 실제 코드 기준

- 기존 **가시꽃 덫 개편 승인:** [괴이한 지뢰처럼 굴러간 후 원형 덫 전개](2026-10-30-thorn-trap-magicraft-deceptive-mine-deployment.md), [사용자 결정](../decisions/2026-10-30-thorn-trap-magicraft-deceptive-mine-deployment.md). 원본 Magicraft 지뢰 1012는 **씨앗 이동 물리의 참조**이고, **본체에서 새끼 화염 씨앗을 방출하는 번식은 사용자가 제안한 우리 게임의 신규 합성 고유 효과**다. 원작 지뢰의 효과였다고 오기하지 않는다.
- [`scripts/magic_catalog.gd`](https://github.com/LittleEvasn/witchlings-mayhem/blob/main/scripts/magic_catalog.gd): 현재 `meteor_thorn`의 `parents=["thorn","fall"]`, `name="유성 가시꽃"`, `desc="예고 후 낙하 · 착지 때 서로 연결된 작은 덫 둘로 분화"`는 **현재 제품의 구형 정의**, 새 기획 미반영.
- [`scripts/magic_extensions.gd`](https://github.com/LittleEvasn/witchlings-mayhem/blob/main/scripts/magic_extensions.gd): `intercept()`가 `meteor_thorn`을 낙하형으로 예약하고, `attach()`가 반경 65% 덫과 75px 옆에 복제 덫을 두며 짧은 `arc` 연출. **본체 발동 시 새끼 씨앗 생성·롤링·새 덫 전개 구현 없음**.
- [`scripts/spell_runtime.gd`](https://github.com/LittleEvasn/witchlings-mayhem/blob/main/scripts/spell_runtime.gd): `install()`, `update_zones()`에서 가시꽃 장판 설치와 접근 발동 처리. **본체 발동 → 씨앗 자식 생성** 사건은 별도 구현 필요.
- [기존 60종 상호작용 검토](../../MAGIC-60-INTERACTION-TECHNICAL-REVIEW-v1.md)도 `F09` 유성 가시꽃이 “낙하 덫 + 갈래 두 개와 유사”해 독자적인 위험 영역이 필요하다고 지적했다.
- 내부 ID `meteor_thorn`은 **세이브·도감·기존 합성 레시피 호환성을 검토한 후 유지 여부 결정**. 단순 표시명만 바꿔도 기존 ID 사용자/검증/세이브 정책은 별도 처리 필요.
- 기존의 `시한 가시꽃(timed_thorn)`은 **접근과 무관한 예약된 반복 가시 파동** 합성이므로 이번 작열 가시꽃의 후속 함정 번식과 섞거나 삭제하지 않는다.

## 4. 실제 구현 시 수행할 변경(이번엔 구현하지 않음)

1. `magic_catalog.gd` / `spell_progression.gd`: 구형 `meteor_thorn` 레시피의 `thorn+fall`→`thorn+element_fire`, 표시명을 **작열 가시꽃**으로 교체. 기존 저장/레시피와 충돌 확인. `thorn+fall` 일반 조합이 별도로 가능하더라도 그 합성을 작열 가시꽃으로 자동 재선택하지 않음.
2. `magic_extensions.gd`: `meteor_thorn` 전용 낙하 예약·정적 덫 복제 제거. 새로운 `mother` vs `child` 명시적 역할 및 `on_trap_triggered`에서 **씨앗 3~4개**를 실제 발사·운동시키는 별개 전개 단계 구현.
3. `spell_runtime.gd` / `spell_behaviors.gd`: 기존 접근 발동/피해/종료 흐름 안에서 **본체 1회 발동에 새끼 3~4개**가 생기는 사건을 구별하고, **씨앗 굴림 → 소형 덫 전개 → 별도 적 감지/피해**까지 실제 개체 수명을 관리.
4. `magic_visuals.gd`: 본체 가시의 화염 공격, **작은 불씨가 튀고 구르는 시각**, 씨앗의 실제 이동 좌표와 일치하는 소형 덫 전개/무장/기폭 연출.
5. `modifier_effects.gd`/합성 관련 루틴: 화염 자체의 중복 부여/화상, 자식 파생 마법 후속 이벤트·딜 분할/중첩·복제 루프 검토.
6. 기존 승인 `thorn` 기본 씨앗 물리(괴이한 지뢰 참고)를 훼손하지 말고, 새 합성의 추가 세대에 재사용할 구현 경로를 마련한다.

## 5. 구현 후 독립 완료 기준(현재 미실행)

- **일반 가시꽃 vs 단순 가시꽃+화염 vs 작열 가시꽃**을 실제 게임에서 비교. 작열 합성은 **본체 발동→3~4개 씨앗의 실제 굴림→3~4개의 소형 덫 전개→적 접근 후 공격**이 나와야 한다. 단순 화상/2개 정적 덫/화염 파편 VFX만 있으면 불합격.
- 적이 본체를 밟지 않으면 **새끼가 임의 생성되지 않음**. 발동·중복명중·종료 이벤트가 겹쳐도 **본체 하나가 반복해서 자식을 무한 생성하지 않도록** 검사.
- 씨앗 3~4개는 **본체가 있던 위치에 즉시 놓이는 덫**이 아니라 **시간에 따라 서로 다른 좌표로 이동하는 개체**여야 한다. 덫의 표시 크기/히트박스/실제 타격 일치.
- 새끼 덫의 **실제 적 명중·화상**, 정상 종료, 강제 정리, 다음 시전/웨이브 전환에서 유령 덫이나 중복 이벤트 없음.
- 적 0명/1명/다수, 덫 연속 기폭·서로 겹침·화염+가시꽃 중복 설치·맵 경계, 4오브×다수 덫×다수 적·프레임 지연·최대 존/투사체 수 및 실제 프레임 비용.
- 기존 `thorn` 일반 덫과 `timed_thorn`(시한 가시꽃), `fall` 일반 보조, `element_fire` 원소, 연계·연결·재귀가 정상인지 회귀 검증.
- **검증 상태 분리:** 소스/설계 검토(완료) ≠ Godot 컴파일 ≠ 적/덫 실제 판정 ≠ 시각·충돌 일치 ≠ 프레임/게임 체감 (전부 미실행).

**최종 인계 요약:** **유성 가시꽃은 작열 가시꽃(`thorn + element_fire`)으로 대체한다. 적이 본체를 밟으면 화염 가시가 공격하고, 작은 씨앗 3~4개가 사방으로 튀어 대굴대굴 구른 뒤 본체보다 작은 새끼 화염 가시꽃 덫으로 전개된다.** 새끼 재번식 및 정확한 수치·새로운 얼음+낙하 합성은 미확정.
