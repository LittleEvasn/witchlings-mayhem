# 뱀서식 성장 기반 · 2026-10-28

## 구현된 첫 묶음
- 공격/보조/연결은 종류별 실물 하나. 같은 종류 획득은 0→1→2→3, 최대 단계는 후보/구매에서 제외한다.
- 보유 종류 수 제한은 없다. 한 실물을 두 오브에 동시에 쓰는 것은 불가능하다. 기존 두 오브와 각6칸/실행 문법은 유지한다.
- 마석1당 돈1, 경험치2(초기 조정값). 경험치 요구량은 레벨1에서6, 이후 레벨당3 증가. 초과 경험치/여러 레벨업을 큐로 보존한다.
- 레벨업에서 마법·미보유 유물의 서로 다른3개 선택지. 보유 마법 가중치3, 신규/유물1. 확정 지급이 아닌 가중 무작위다.
- 후보 소진 시 돈10 또는 체력20. 최대 체력에서 회복을 고르면 돈10. 후보가2개면2개만 제시하며 복제 카드로3칸을 채우지 않는다.
- 보상 선택/획득 확인/선택적 조합 편집은 전투·적·탄·시전·회피·시간 정지. 계속을 눌러야 재개한다. 재개 직후0.5초 보호.
- 평소 Tab 인벤토리는 계속 비정지. 보상 중에는 보상 선택을 건너뛰는 Tab/Esc가 동작하지 않는다.
- 제작으로 같은 구체를 받아도 자동+1/장착 즉시 반영. 수동 동종 합치기 제거. 마석 직접+1은 사용자가 삭제 확정하지 않아 유지한다.
- 기존 웨이브 완료의 추가 유물 보상은 제거; 유물은 레벨업 후보로 이동. 기존 완료마석/체력회복·준비 흐름은 다음 시간표 개편까지 유지한다.
- 마석 드롭 예산과 짧은5웨이브는 아직 기존 방식이다. 이 단계의 경험치·가격 수치는 최종30분 밸런스가 아니다.
- 기존 제작 합성에 한판당 레시피1회 제한을 적용했다. 상자 합성으로 옮기는 일은 후속이다.

## 저장/편집
- 준비 저장에 레벨/잔여·누적XP/선택 대기열/완료합성 이력을 추가했다. 시험 발사는 성장/돈을 지급하지 않는다.
- 기존 저장은 그대로 읽는다. 종류별 최고 강화에서 추가 실물당1단계씩 합쳐 최대3, 보존 못한 투자 가치는 기존 investment_cost 차액으로 반환한다.
- 정리 전 파일을 파괴하지 않는다. 이어하기 후 저장 시 새 형식으로 갱신된다. 도감/기존 전투 기록은 유지된다.
- 장착 중 강화는 두 오브·편집 초안 모두 토큰 교체/재컴파일. 이전 물건을 되살리는 되돌리기 이력은 초기화한다.
- 마이그레이션에서 중복 장착이 겹치면 활성 오브를 우선 보존한다. 소비된 공격의 고아 연결은 Forge 규칙으로 제거한다. 미완성 조합은 편집 가능하고 무음이다.
