## 운반자와 배회 무리

- 1~4웨이브의 기존30초+12처치 조건을 채우면 마법 재료 운반자 출현 기회가 한 번 생긴다. 선택권이 즉시 가방 UI에 생기던 흐름을 현장 사건으로 바꿨다.
- 플레이어에서340~470 떨어진, 화면 가장자리 여백과 안전거리220 이상을 확보한 지점에1.15초 경고 후 등장한다. 경고 중 플레이어가 진입하면 출현을 취소한다. 안전 지점을 찾지 못하거나 적 상한에 걸려도 예약을 쌓지 않는다.
- 동시에 나오는 특수 적의 경고 지점도240 이상 떨어지게 예약한다. 큰 정예/이름표가 잘리지 않도록 화면 안쪽 여백130을 둔다. 이는 일반 몬스터의 출현 경로를 고정하는 변경이 아니다.
- 홀수 웨이브는 운반자 한 마리. 짝수는 같은 운반자와 기존 근접 역할의 호위3명. 호위는 떨어져 있을 때 대형을 따라가고 플레이어가210 안으로 접근하면 싸운다. 새 적 종3개를 추가한 것이 아니다.
- 운반자는 가까이350 이내면 속도185로 도망가며, 멀리서는 속도75로 배회한다. 가장자리에서 실행 가능한 다음 목적지를 고른다. 접촉 공격은 하지 않는다. 체력85 + 웨이브×12, 호위 체력35×웨이브 HP배율.
- 제한24초. 도주/종료/강제 정리는 처치·드롭을 발동시키지 않는다. 보상 개체와 정예는 일반 적의 화면 밖 재배치 대상에서 제외한다.
- 단독은 운반자, 무리는 운반자와 호위 모두를 처치하면 마지막 위치에 재료가 생긴다. 몸체가 맵 가장자리에 있어도 재료는 플레이어가 갈 수 있는 범위로 보정한다.70 이내에서 회수하면 기존3중1택을 먼저 받는다.
- 운반자/호위는 일반 마석을 추가 드롭하지 않는다. 기존 웨이브18G 보상 예산을 사용하고 보상 ID로 한 번만 지급한다. 놓침/안전 출현 실패/미회수라도 조건을 채웠다면 웨이브 종료 때 같은 선택권을 받는다. 이미 현장에서 받았다면 종료 때 다시 주지 않는다.
- 조건 자체를 못 채운 웨이브는 기존처럼 실제 처치에서 예산 때문에 미지급된 금액만 종료 때 복구한다. 미처치 적의 돈을 생성하지 않는다.

## 보상 전용 무대

인벤/보유 유물은 기존 오른쪽 개인 창, 마법 선택은 별도 `SpellRewardStage`다. 플레이어 아래쪽에 세 카드를 가로로 놓고 중앙 캐릭터와 하단 HUD를 남긴다. 세계 정지·암막·무적·자동 장착은 없다. Esc로 미루거나 나중에 배지에서 다시 열 수 있다.

- 카드: 구체/이름/짧은 행동/성장 맥락. 같은 강화 가능 구체를 보유하면 실제 합산 규칙으로 예상 +단계를 보여준다. 보조/연결은 역할을 짧게 알린다.
- 공개 때 짧은 밝기 복귀 tween, 재료 회수의 기존 효과음/고리, 선택 후 획득 알림과 '조합을 바꿔볼까?' 연결을 사용한다. 긴 강제 애니메이션/히트스톱/화면 흔들기/BGM은 추가하지 않았다.
- 선택하면 가방에만 추가하고 공개 화면은 닫힌다. 다음 선택권은 배지에 보관된다. 오래된 ID/revision 거부, 재고 상한 후보 재보충/18G 회수, 재시작 전 알림 차단을 유지한다.
- UI와 필드 이벤트는 시험 모드에서 진행되지 않는다. 유물 보상→준비 제작→다음 웨이브 흐름을 유지한다.
