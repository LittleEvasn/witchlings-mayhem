# 타이틀 → 루미 준비 → 도입 → 결과/재도전 — 2026-10-28

## 구현 범위

출시 로드맵 2번의 기능 흐름을 구현했다. 기존 루미 한 판, 두 오브, 제작함, 마법/유물/웨이브 수치와 아트를 유지했다. 새로운 캐릭터·회사 로고·BGM·이어하기·도감·보조 합성은 추가하지 않았다. 구매 GUI가 없는 현재 패널은 기능 배치이며 최종 아트가 아니다.

흐름:

`타이틀 → 루미/시작 조합 준비 → 선택적 도입 → 기존 전투↔보상/제작 → 결말 포함 결과 → 같은 조합 즉시 재도전 / 다른 조합 준비 / 타이틀`

## 화면과 동작

### 타이틀
- 기존 실습장 배경과 루미 그림을 사용하고 큰 전체 패널 대신 제목/왼쪽 메뉴/인물로 배치한다.
- 새 실험, 실험 기록, 설정, 게임 종료가 실제 기능으로 연결된다.
- 이어하기/발견 도감은 아직 없으므로 버튼을 만들지 않았다.
- 종료는 확인창을 거치며 최초 선택은 '돌아가기'다. 허구 회사 로고를 추가하지 않았다.

### 실험 준비
- 실제 가능한 마녀는 루미 한 명임을 명시한다. 네 시작 조합을 네 캐릭터처럼 표시하지 않는다.
- 작은 정원/큰 한 발/반짝 연사/얼음 실험을 선택해 구성과 설명을 미리 본다.
- 선택만으로 전투가 시작되거나 재고를 소비하지 않는다. 별도 '실험 시작'으로 확정한다.
- 시작 조합의 실물 지급은 기존 Economy.KITS를 그대로 사용한다.
- '도입 이야기 보기'를 선택할 수 있다. 최초에는 켜짐, 이미 진행했다면 꺼짐이 기본이다.

### 도입
- 별도 설명 페이지 대신 실제 전장 위 아래 대사창에서 기존 세 문장을 한 줄씩 넘긴다.
- 다음/건너뛰고 시작/시작 조합으로 돌아가기 제공. 도입 동안 전투·제작 시간, 생성, 발사 진행 없음.
- 마지막 줄이나 건너뛰기로 전투를 시작하면 `intro_seen`을 기록한다. 중간에 돌아가면 완료로 기록하지 않는다.
- profile-v1의 선택적 bool 필드를 추가했으며 이전 파일은 그대로 유효하다. 진행 중 실험을 저장하는 기능은 아니다.

### 결말과 결과
- 기존 결말과 결과를 하나로 합쳤다. 결과를 보려고 한 페이지를 더 넘기지 않는다.
- 성공/실패 이유와 짧은 결말, 전투/제작 시간, 처치/획득 마석, 두 오브의 실제 6칸 순서/강화 단계, 유물을 표시한다.
- 긴 컴파일 설명을 늘어놓는 대신 장착 슬롯을 표시한다. 효과 설명은 슬롯 툴팁으로 볼 수 있다.
- 같은 시작 조합으로 다시: 도입을 생략하고 새 판으로 즉시 시작한다.
- 다른 시작 조합 고르기: 이전 적/공격을 정리하고 준비 화면으로 이동한다.
- 타이틀 복귀 시 실제 플레이어의 위치/이동/피격 표시와 카메라도 중앙 상태로 복원한다.

### 입력
- 전면 메뉴의 Tab은 GUI 포커스 이동에 사용한다. 전투용 Tab 편집과 충돌하지 않도록 분리했다.
- 화살표/Tab으로 선택하고 Enter로 실행한다. 기본 포커스와 다음/이전 경로를 지정했다.
- Esc: 준비/기록/타이틀 설정/결과 → 타이틀, 도입 → 시작 조합, 종료 확인 → 타이틀. 타이틀의 Esc는 종료 확인이다.
- 일시정지 설정의 Esc는 일시정지로 돌아가며 새 판을 시작하거나 전투를 재개하지 않는다.
- 화면 교체 직후 예약된 포커스가 제거된 버튼을 참조하는 오류를 막기 위해 WeakRef/트리 존재 검사를 사용한다.
