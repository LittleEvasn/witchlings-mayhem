# 처치 성장·시간표·상자·전투 표시 수정 — 2026-10-29

사용자 승인 범위: 직전 피드백 1·2·3·4·6·8·11. 마법 개편/응축/새 콘텐츠/런 길이/통합 보상 편집 UI는 구현하지 않는다. 기존 project.godot 변경은 보존하고 커밋에서 제외한다.

## 구현

### 매 처치 경험치
- 모든 일반 처치가 `xp:1`인 마석을 남긴다. 일반 중갑은 2, 단독 정예는 6.
- 돈은 기존 일반 3처치당1/중갑3 지급을 유지한다. 매 처치1돈으로 바꿔 제작 경제를 3배로 올리지 않았다.
- 마석은 `value`(돈)와 `xp`를 각각 보관한다. 200개 초과 합치기에서도 둘 다 보존한다. 옛 `value`만 있는 데이터는 기존 1돈=2XP로 호환한다.
- 직접 습득은 돈+XP, 휴식/승리 시 잔여 회수는 돈만. 적을 정리하거나 이벤트가 시간 만료된 것은 처치로 치지 않는다.
- 실제 30일반킬: 기존10드롭/10돈/20XP → 현재30드롭/10돈/30XP. XP 곡선 자체는 그대로다. 최종 성장 속도는 후속 플레이 평가 대상이다.

### 일반 출현과 독립 이벤트
- `survival_timeline.gd`: 6분 안의 분 단위 목표10/18/30/24/16/42, 간격1.2/.9/.65/1/1.5/.65초. 후반 장별 밀도1/1.8/3/4.4/6배와 한 번에1~5마리, 기존 장별80~300 상한 유지.
- 목표 달성 시 일반 추가0. 부족해도 한 프레임에 목표 전체를 채우지 않는다. 처치 뒤 재생성은 다음 실제 출현 간격을 기다린다. 옛 0.25초/최소1명 강제 보충과 주기적 일반 pack 호출을 제거했다.
- 첫60초 박쥐,60~120초 박쥐·답안지,120~240초 젤리·답안지, 이후 기존 풀. 새 아트/적 종류를 추가한 작업은 아니다.
- 각 6분 구간: 60초 정예,90초 박쥐 횡단,120초 포위,180초 정예,240초 횡단,300초 정예. 기존 운반자/장별 압박 정예도 유지하되 단독 정예는 기존 동시1 제한을 공유한다.
- 횡단: 기존 박쥐18마리가 화면 밖 한쪽에서 고정 방향으로 이동한다. 플레이어를 꺾어 쫓지 않는다. 최대14초 후 보상 없이 정리한다.
- 포위: 플레이어 중심370거리,24자리 중 연속3자리 비움,최대21마리. 기존 젤리가 제자리에 머물고 파괴 가능,18초 뒤 보상 없이 정리. 처치한 개체만 XP/돈을 준다.
- 전체 상한/안전거리/종별 상한은 이벤트에도 적용한다. 공간 부족 시 일부는 생략되며 생성 빚을 쌓지 않는다. 지연 프레임·중단 시 지난 이벤트를 몰아서 생성하지 않는다.
- 기존30분/6분 휴식/최종 보스 유지. 원작 시간표나 원작 코드의 복원이 아니라 조사 자료를 참고한 우리 튜닝이다.

### 자동 상자
- 레벨업은 기존3중1택. 일반 상자는 개봉 후 선택 없이1/3/5개 지급한다.
- 초기 확률80%/17%/3%는 우리 시험 수치이며 원작 확률이라고 주장하지 않는다.
- 매 항목마다 보유/최대강화/합성 가능 여부를 재계산. 준비된 합성 우선, 이후 보유 마법 강화, 후보가 소진되면 항목당10마석.
- 합성 부모 소모, 부모 자리 치환, +3 상한, 한 판 합성별1회 유지. 같은 상자 안에서 소모된 부모를 신규 지급하지 않는다. 이후 레벨업/제작에는 다시 나올 수 있다.
- 개봉 콜백 중복 지급 방지. 빠른 획득도 같은 자동 경로를 쓴다. 보상·인벤 통합 화면은 만들지 않았으며 현재는 기존 개봉 뒤 짧은 획득 요약만 표시한다. 별도 획득 완료 버튼은 없다.

### 피해 숫자와 화면 비율
- 보호 효과 판정 후의 피해를 표시한다. HP1인 적에50 피해면50 표시. 실제 깎인HP/과잉피해 구분은 기존 측정기를 유지한다.
- 표시만 정수 반올림/양수 최소1. 실제 소수 피해 계산은 변경하지 않는다.
- 수명0.60→0.40초, 글자22→20, 상승32→20. 시작0.1초만 대상을 따라간 뒤 월드 위치에서 짧게 떠오른다. 약한 참조로 대상 삭제 후에도 안전하다.
- 기존 연타0.12초 합산/대상당2·전체64 제한/설정/시험·보상 정지 유지. 원작 DamageNumberManager의 비어 있는 본문을 복원했다고 주장하지 않는다.
- 스크롤 전장 카메라1.0→0.8. 캐릭터·적·이동의 화면상 비중20% 감소, 보이는 월드 가로·세로25% 증가. HUD 크기/월드 이동 수치/충돌·사거리 유지. 시험·측정 카메라는1.0.

## 통합 보상·인벤 UI — 제안만, 미구현

목표: 소유 목록·현재 오브·보상을 같은 순간에 보고 편집한다. 보상 선택 후 자동으로 닫지 않는다. 전체가 정지한 전장을 배경으로 이어지며 마지막에만 명시적으로 전투 재개한다.

1920×1080 기준 가장자리64, 상단 제목/레벨/보상 수, 본문은 왼쪽약60%·오른쪽약40%:

```text
┌──────────── 전투 정지 · 마법 정리 ────────────┐
│ 오브 1 [칸][칸][칸]…    │ 신규/강화 보상 카드1 │
│ 오브 2 [칸][칸][칸]…    │                    │
│ 오브 3 [칸][칸][칸]…    │ 신규/강화 보상 카드2 │
│ 오브 4 [칸][칸][칸]…    │                    │
│ 가방 아이콘 그리드      │ 신규/강화 보상 카드3 │
│ 유물 아이콘 띠          │                    │
├──────── 선택 항목 상세/강화 전후 ────────────┤
│ 되돌리기                         편집 완료·전투 재개 │
└────────────────────────────────────────────┘
```

- 보유한 오브만 표시,각6~8칸 위치 유지. 가방→칸 드래그/교환/오른쪽 해제/되돌리기는 기존 기능을 재사용. 글 목록보다 실제 슬롯과 아이콘이 중심이다.
- 보상 선택 전에도 왼쪽에서 자유롭게 편집. 카드를 가리키면 관련 보유 마법/적용 오브를 강조하고 신규·강화·합성 및 전후 변화를 표시.
- 선택하면 오른쪽은 작은 획득 결과로 바뀌고 왼쪽 가방의 새 항목이나 강화된 칸을 강조한다. **빈칸 자동 장착 없음. 별도 획득 완료 화면/버튼 없음.** 계속 편집 가능.
- 연속 레벨업은 같은 오른쪽 영역에서 다음3택으로 바뀌며 왼쪽 작업 상태는 유지. 필수 미수령 선택이 남으면 재개 버튼에 이유와 남은 수를 표시한다.
- 상자는 오른쪽에서 자동1/3/5 지급 결과를 보여주고 같은 왼쪽 편집을 사용. 선택 카드로 바꾸지 않는다.
- `편집 완료·전투 재개`만 마지막 정지를 해제한다. 일반 Tab 인벤의 비정지 규칙과 구분한다. 이 제안 승인 전에는 해당 UI·상태 흐름을 구현하지 않는다.
