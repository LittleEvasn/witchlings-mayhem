# AI 자동 플레이 · 실제 Godot 마법 검증

## 웹 훈련장에서 사용
[마법 실험실](https://littleevasn.github.io/witchlings-mayhem/)에서 **AI 자동 플레이 · 60초** 버튼을 클릭한다.

- 기존 4개 오브 장착을 임시 보관한다.
- AI 시연용 조합을 오브 4개에 자동 장착한다.
  1. 추적 + 갈래 + 별빛탄
  2. 메아리 + 꽃폭탄
  3. 공전 + 달무리 위성
  4. 빙결 + 서리숨결
- 기존 무적 표적 4명에 6명을 추가해 총 10개 표적을 배치한다.
- 60초 동안 캐릭터의 위치를 스크립트로 변경하고 게임의 **실제 자동 조준·발사 스케줄러·충돌·피해·냉기 처리**를 그대로 실행한다.
- 화면에 경과 시간, 유효 피해, 명중 횟수를 보여준다.
- 60초가 끝나거나 중단하면 기존 장착 구성과 표적 배치를 되돌리고 요약을 표시한다.

이것은 LLM이 실시간으로 상황을 보고 판단하는 사람이 하는 방식의 플레이가 아니라, **재현 가능한 규칙 기반 자동 플레이**다. 화면을 사람이 보는 감각적 판정은 포함하지 않는다.

## 60종 자동 회귀·스모크 검사
- `tests/ai_autoplay_test.gd`
- `scripts/measurement_runner.gd`의 **실제 Godot 런타임**을 사용해 기본 30종, 합성 30종을 각각 컴파일·장착·시전한다.
- 공격 마법은 단독, 보조 마법은 `보조 + 별빛탄`, 연결 마법은 `별빛탄 + 연결 + 꽃폭탄`으로 테스트한다.
- 고정 시드 731, 개별 5초 전투, 오브 위치가 움직이는 자동 입력.
- 별도 60초 세션은 접근하는 몬스터에게 **추적·갈래·별빛탄→명중 후→꽃폭탄**을 사용한다.
- 사전 검사에서 컴파일·런타임·보고서 기록이 실패하면 CI를 실패 처리한다.
- 발사/명중/피해/연결이 없거나 상한에 걸리면 **경고 플래그**를 남긴다. 환경·위치의 영향으로 무피해가 곧바로 코드 버그라는 의미는 아니다.
- 합성 구체 장착을 위해 `sandbox_loadout=true`에서만 경제·제작 비용을 생략한다. **실제 플레이와 일반 측정의 경제 규칙은 변경하지 않는다.**
- 60종이 5초를 버틴다고 모두 정상 효과·올바른 애니메이션·균형 잡힌 밸런스를 입증하는 것은 아니다. 버그별 단위 회귀 테스트는 별도로 필요하다.

## GitHub Actions
`.github/workflows/web-magic-lab.yml`은 `tools/build_web_lab.py --ai-autoplay`를 실행한다. 웹 빌드 성공 전에 실제 엔진 검증을 마쳐야 한다.

- 통과 결과: Actions의 `witchlings-ai-autoplay-60` artifact에 `report.json` 및 `report.csv`가 포함된다.
- 웹 빌드: `witchlings-web-magic-lab` artifact.
- 실행 링크: https://github.com/LittleEvasn/witchlings-mayhem/actions/workflows/web-magic-lab.yml
- 실패 시 로그의 `FAIL` 문구를 살펴보고 `tests/ai_autoplay_test.gd`를 먼저 재현한다.
- CI 환경의 **CPU p95는 실제 Chrome의 FPS를 대신하지 않는다**.

검증 기록은 실제 성공 실행의 SHA와 보고서 파일을 기준으로 남겨야 한다. GitHub Actions에서 아직 성공한 적 없는 실행을 통과로 기록하지 않는다.
