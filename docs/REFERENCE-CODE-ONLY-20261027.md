# 참고작 분석 방식 정정

사용자 최신 지시: 게임 플레이를 요청한 것이 아니라 코드상 확인 요청이었다. 직접 게임 실행·플레이·조작·캡처를 하지 않는다. 캡처가 필요하면 사용자에게 요청한다. 코드만으로 확인 못하면 **“코드만으로는 분석 불가능합니다”**라고 보고한다.

총괄이 실제 플레이로 잘못 해석해 데모 실행/캡처를 시도했다. 담당자는 창은 찾았으나 두 캡처 경로 모두 시간초과여서 메뉴/전투를 관찰하거나 게임 입력을 하지 못했다. 관찰7항목은 실플레이로 확인되지 않았다. 이후 호출은 사용량 제한으로도 실패했으며, 반복 호출하지 않는다. 사용자 지시 후 분석자 실행 중단을 확인했다. 추가 게임 실행/제어/복구는 수행하지 않았다.

wm_reference_analyst 역할, AGENTS.md, handoff를 코드 전용으로 수정. 게임플레이 코드는 변경하지 않았다. 향후 분석의 근거는 코드·설치 데이터·사용자가 제공한 캡처이고, 정량 코드값과 체감/실제 플레이는 구분한다.
