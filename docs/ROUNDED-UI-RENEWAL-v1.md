## 구현 범위
사용자가 제공한 자사10화면/괴수공주18화면의 차이를 기준으로, 첫 시각 기준 화면인 타이틀·시작 선택·준비 제작·시험을 개편했다. 괴수공주 원본 그래픽을 복사하지 않았다. 전투 수치/마법 규칙/경제/저장 형식은 바꾸지 않았다.

- 타이틀: 전투 바닥 대신 크림·라벤더 메뉴 배경, 기존 루미 일러스트와 원형 배경, 둥근 Jua 제목, 주요 시작 버튼과 그림이 있는 도감/기록/설정 버튼. 실제 이어하기와 새 실험 확인을 유지.
- 시작 선택: 긴 텍스트 버튼을 2×2 시작 조합 카드로 교체. 실제 구성 구체의 아이콘, 선택 강조, 공통 지급품, 도입 토글, 기존 키보드 포커스/확정 동작 유지.
- 준비 제작: 오른쪽 폭1036(논리1600) 작업대. 좌상단 두 오브 6칸, 좌하단 가방/제작안/완성합성 카드 격자, 오른쪽 선택품 상세·행동 변화·재료·장착/강화. 제작안4개는 한 화면에, 진열 유물로 추가된5번째는 스크롤. 합성18개는 3열 카드. 공간 확보를 위해 준비 중 전장 노출을 종전65%에서 약34%로 변경했다. 전체 음영/전장 입력차단막을 추가하지 않았다.
- 시험: 폭520으로65% 이상 시험 공간을 유지. 같은 둥근 색·아이콘과 두 오브를 사용하며 제작·강화는 금지한다. 전투 중 개인 가방은 기존 작은 비정지 창 유지.
- 인터페이스 기호18개를 SVG로 통일. 완성18종은 재료 두 아이콘을 조합해 표시. 드래그 미리보기도 같은 아이콘으로 마우스 중앙에 표시한다. 새 캐릭터/배경 일러스트 생성 없음. 이는 구매 GUI를 적용하기 전의 자체 UI 시안이며 최종 납품 아트라고 주장하지 않는다.
- `mayhem_skin.gd`가 색·버튼 상태·카드·글꼴·아이콘을 관리한다. 기존 `crafting_theme` 구매 스킨 진입점은 보존했다.
- Jua OFL 원문을 assets/fonts에 동봉하고 export include_filter에 넣었다.
