## 우리 게임의 초기 제안

- 초기 월드 크기4800×3600 Godot 단위, 현재 캐릭터 크기/이동 속도240 유지, 카메라 zoom1을 기준으로 제안한다. 현재1440×900 논리 화면에서 가로3.33×세로4화면, 면적 약13.3화면이다. 데모 기본 경계 비율보다 조금 작게 시작하는 안이다.

- Camera2D가 플레이어를 따라가고 끝에서는 멈추게 하며 HUD는CanvasLayer에 유지한다.
