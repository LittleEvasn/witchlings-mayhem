# 출시 규모·성장 흐름·FHD UI 권고 · 2026-10-27

상태: 화면 변경만 구현. **2026-10-27 사용자 후속 승인으로4절 UI 방향은 확정**, 실제 UI 개편 구현은 별도다. 콘텐츠 수, 웨이브 시간, 경제는 제안이다. 강화는 후속 사용자 방향(+3/보이는 행동 변화)이 이 문서의 기존+4 제안보다 우선하며 docs/GROWTH-SPECTACLE-AND-SCOPE-v1.md에 검토했다. 현재 실행 규칙을 이 문서만으로 덮어쓰지 않는다. 게임 아이디어 담당 Astra/high 1회 읽기 검토와 총괄의 실제 코드 확인을 종합했다.

## 2. 웨이브 시간

현재 코드는90 / 105 / 120 / 135 / 보스 상한150초다. 권고 첫 실험은 **60 / 75 / 90 / 105 / 보스 목표120·상한150초**다.

- 일반 전투 합계330초, 보스 목표 포함450초=7분30초, 시간 상한480초=8분. 보스 조기 처치는 허용하므로 한 판의 실제 최솟값은 보스 처치에 따라 다르다.
- 질문의 최소/최대 웨이브 길이는60~150초. 보스150초를 강제로 버티게 하는 구조가 아니다.
- 준비는 시간 제한이 없어 준비 포함 총시간에 강제 최댓값은 없다. 사람의 준비시간을 별도로 기록한다.
- 첫 제작이 여전히 늦게 느껴지면1웨이브45초까지 시험하는 다음 후보가 있지만, 첫 적용을 무작위45~60초로 바꾸지는 않는다.
- 단순히 종료시각만 당기면 뒤의 무리/정예/보상이 잘린다. 일반 생성 시간표와 성장 예산을 새 시간에 맞춰 함께 배치한다. 예컨대1웨이브30초 보상 기회는60초 안에서 발견→추격→선택 여유가 있어야 한다.
- 후기 웨이브는 새로운 행동·정예·보상 사건 때문에 길어진다. 같은 적을 더 오래 잡으며 제작을 기다리는 시간은 늘리지 않는다.

괴수공주의 정확한 스테이지 길이는 이번에 코드로 확보하지 못했다. 위 초는 사용자 관찰의 ‘초반 짧고 점차 길어짐’을 우리 게임에 적용한 제안이며 참고작 실측값이 아니다.

## 3. 강화·합성을 쓰지 않는 이유와 바꿀 순서

코드 근거: economy.gd의 PRICES/investment_cost/craft_quote, spell_progression.gd의 paid_cost/FUSIONS, prep_board.gd의 detail/fusion.

현재 기본 구체는8~18G. 유료 강화는 ceil(기본가격 × (1.25 + 0.25 × 현재단계))씩 들며, 합성은 서로 다른 지정 공격 두 개가 모두+4이고 추가12G다. 무료 시작 부품/도구상자 할인 없이 두 재료를 구매해 유료 강화하는 경로의 합성 투자는192~238G다. 뇌광창은 별빛탄60+벼락120+합성12=192G. 이는 모든 경로의 최소비용이 아니다. 같은 기본 구체5개를 합치는 경로는 더 저렴하지만 동일 종류를 확보할 기회가 필요하다. 두+4를 재료로 소비하므로 다른 오브의 장착이 비는 기회비용도 있다.

플레이어가 생존 가능한 조합을 이미 갖췄다면 싼 새 보조/구체를 사거나 돈을 남기는 선택은 합리적이다. 강화 메뉴가 있다는 사실만 강조하거나 적 체력만 늘려 강제하지 않는다.

권고 실험:
1. 기존0~4 및 병합 계산은 유지한다. 처음 준비에서 선택한 마법+1을 고민할 수 있게 한다.
2. 유료 강화의 단계별 비용을 기본가격의0.5 / 0.75 / 1 / 1.25배 올림으로 시험한다. 총 유료합성 경로는 약120~148G가 된다. **수치 변경 제안이고 현재 미적용**이다.
3. 지정 재료 확보와 마석 배분을 맞춰 셋째 준비에서 한 합성을 집중 투자로 완성하고, 마지막 일반 웨이브와 보스에서 충분히 써본다. 획득 돈 전체를 합성 하나에 써야만 통과하는 구조는 피한다.
4. 합성은 ‘두 주문→한 슬롯’의 압축과 두 부모 행동의 결합을 결과 미리보기로 보여준다. 소비되는 실제 구체, 다른 오브에서 빠지는 슬롯, 남은 준비물, 완성 후 장착 위치를 실행 전에 표시한다.
5. 보조+4, 공격+4 두 개 따로 사용, 합성 하나 사용을 비슷한 총비용으로 비교한다. 합성 피해 배율1.8만 보고 이득이라 하지 않는다. 발사주기·유효명중·영역 유지·연결·남은 슬롯까지 본다.

## 4. 전체 UI 방향

한 줄 방향: **귀여운 마녀의 작은 실험 작업대. 전투에는 전장, 준비에는 두 오브와 재료를 중심에 둔다.**

참고: https://gameui.matme.info/blog/archives/126184 의 Endfield 전투/보상/메뉴 이미지를 브라우저로 확인했다. 모서리 HUD, 중심 전장 여백, 큰 핵심 이미지와 짧은 행동 버튼의 계층을 참고한다. 그 게임의 군용/SF 색·다수 메뉴를 그대로 복사하지 않는다. MAJO 페이지도 열었으나 도입 화면 정도만 확인했으므로 전체 UI를 분석했다고 하지 않는다. https://x.com/LerSentAI/status/2112442886042349895 원문은403으로 확인 불가했다.

### 전투
- 왼쪽 위: 캐릭터 작은 초상/체력/회피 상태. 긴 사용법 상시 표시는 초반 안내 뒤 숨김.
- 위 중앙: 현재 웨이브와 남은 시간. 총경과 시간은 결과나 작은 보조 정보.
- 오른쪽 위: 마석과 일시정지. 처치/위력 등의 디버그·세부 수치는 상세창으로.
- 아래 중앙: 오브 두 개의6칸을 서로 다른 둘레색/번호로 구분. 보조→공격→사건 연결을 실제 슬롯 순서대로 읽힌다. 문법 오류는 해당 위치만 강조.
- 인벤: 오른쪽 약 화면28% 폭의 개인 창. 전장을 흐리게 만들지 않고 시간/공격 계속. 중앙 캐릭터와 접근로가 보인다.
- 마법 선택: 아래 중앙의 가로3카드, 짧은 출현/획득 피드백, ‘나중에’. 긴 수식은 상세에서. 선택 후 보유함에 넣고 원하는 오브로 드래그한다. 미래 멀티에서도 개인창 상태만 바뀐다.
- 실전 보상창과 인벤은 동시에 큰 패널 두 개를 띄우지 않는다. 정교한 편집은 준비 중에도 가능하다.

### 준비·제작
- 화면 왼쪽/중앙을 ‘오브1 6칸 / 오브2 6칸’ 두 줄에 할당한다. 보유함은 바로 아래, 구체 드래그 거리를 줄인다.
- 오른쪽은 선택 재료의 큰 아이콘·이름·현재 효과→강화 후 효과·비용·실행 버튼. ‘합치기 / 마석 강화 / 완성 합성’은 소비가 서로 다름을 짧게 분리한다.
- 신규 제작 제안과 발견한 합성 설계도를 탭으로 나눈다. 세부 설명을 항상 길게 펴두지 않는다.
- 선택한 합성은 실물 재료 진행도(예: 별빛탄+2/목표+4)와 ‘남은 강화2단계’를 두 부모에 각각 표시한다. 없거나 미달인 조건을 즉시 읽게 한다.
- 아래 오른쪽: ‘시험’과 강조된 ‘다음 웨이브’. 준비 시간 제한 없음.
- 체계는 하나의 글자 크기/여백/색 규칙으로 만들고, 기존 길게 나열하는 문서형 설명을 줄인다. 장식/아이콘의 최종 아트는 별도 단계다.

권고 FHD 최종 배치 영역(픽셀, 미구현 UI 설계): 전투 가장자리24~32, 오른쪽 개인창폭480~520, 오브바 하단높이100~120, 보상 가로3카드 전체폭1080~1200/높이260~300. 본문20~22px, 중요 수치/카드제목26~32px, 보조안내16~18px, 실제 설명길이/한국어 줄바꿈으로 검수. 해상도가 커졌다고 패널과 글자 수를 늘리지 않는다.

## 5. 실제 화면 변경 범위

- project.godot 기본 출력1920×1080, 기본 모드는 테두리 없는 전체화면이다. 창 모드는 Windows 작업표시줄/창틀 때문에 실제 높이가 자동 축소될 수 있어 FHD 모니터 전체를 쓰도록 했다. 다른 해상도 모니터의 전체화면은 해당 모니터 크기를 사용한다. 내부 논리 좌표1600×900에 FHD에서 canvas_items 등비 배율1.2를 사용한다. FHD로 출력하지만 논리 좌표1920개를 강제하는 것은 아니다. 세로 시야900 유지, 가로1440→1600으로 넓어지며 월드가 화면 전체를 채운다.
- 기존1440×900 UI 내용은 중앙 안전 영역으로 옮겨 레이아웃과 슬롯 간격을 보존한다. 모달 입력 차단/음영은 전체 뷰포트를 덮는다. 이것은 위의 UI 전면 개편 구현이 아니다.
- 시험장의 고정1440×900 월드는 유지한다. 넓어진 화면 가운데 같은 실험 공간을 정렬하므로 기존 측정 환경을 임의 확대하지 않는다.

## 6. 다음 순서와 확인할 것

1. 현재 강화된 적 압박으로 사람 한 판 확인: 움직임 필요성, 억울한 피격, 첫 제작 대기감. 이전 무회피봇2웨이브 사망은 사람 난이도 확정 근거가 아니다.
2. 웨이브 단축과 성장 경제를 한 묶음으로 조정하고, 기존 빌드가 계속 유효한 가운데 첫 강화/첫 합성 시점을 확인한다. 도중 선택/지급과 종료 보상 중복 금지.
3. 그 흐름에 맞춘 준비 UI와 합성 미리보기 구현. 오른쪽 전투창의 가독성과 선택 중 이동은 유지한다.
4. 부족한 적2행동/유물6개를 작게 추가하고 실제 선택 차이를 확인한다. 새 마법 대량 추가는 나중이다.
5. 최종 SD 아트 샘플, 명확한 적/마법 아이콘과 VFX, 사용자 제공 BGM·효과음 마감. 설정(화면/음량/입력), 최초 안내, 결과/발견 기록, 성능·저장·독립 빌드, 출시 자료/권리 정리. 멀티는 마지막 별도 단계다.

판단 기록: 강화 선택률/선택 이유, 첫+1/+4/합성 시각, 합성 뒤 남은 전투시간, 합성을 위해 포기한 구체, 정지/이동 생존, 창을 열고 맞은 횟수, 평균 제작 체류. 자동검사 통과와 재미 평가는 구분한다.
