# 전투 개인 창·마법 선택·오브 자동 조준 구현

2026-10-27. 사용자 확인: 설계서 ②중간 보상 ③개인 창 ④전투/UI 상태 분리부터 구현한다. 적대 세력·도주 운반자·배회 무리는 보류한다. 최신 지시가 이전 마우스 조준 규칙보다 우선한다.

## 실제 변경

- Tab: 오른쪽 폭416/논리1440의 개인 준비함을 열고 닫는다. 조합·마법 선택·보유 유물 세 탭. HUD와 전장을 유지하고, 세계 상태는 combat 그대로다. 이동·회피·적 공격·자동 시전·웨이브 시간은 계속 진행한다. 무적이나 감속 혜택을 추가하지 않았다.
- 개인 조합: 기존 두 오브×6칸, 끌어 이동·교환·삽입·우클릭 해제·되돌리기를 재사용한다. 구체를 바꾸면 즉시 재컴파일한다. 문법이 틀린 오브만 침묵하며 다른 오브는 계속 시전한다. 잘못된 임시 조합으로도 창을 닫을 수 있고 HUD에 오류를 표시한다.
- 긴 설명의 보상 카드는 내부 스크롤을 사용해 아래 HUD를 침범하지 않는다. 카드에는 앞부분의 핵심 설명을 표시하고 전체 설명은 툴팁으로 남긴다. 보유 유물 조회도 전투를 멈추지 않는다.
- Esc는 드래그 취소 → 개인 창 닫기 → 기존 1인 일시정지 순서로 처리한다. Tab/Esc가 GUI 포커스에 먹히지 않도록 입력 경로를 분리하고, 전투 HUD/개인 창 버튼은 Space 회피를 버튼 작동으로 소비하지 않는다.
- 제작·강화·합성·시험 발사는 웨이브 사이 기존 준비 화면에 남긴다. 시험은 전투 시간·경제·일시 상태와 분리하며, 시험 중 중간 보상은 생성/소비하지 않는다. 네트워크 멀티를 구현한 것은 아니다.

## 중간 마법 3중1택

새 적이 없는 이번 범위에 맞춰, 1~4웨이브마다 **전투 30초 경과 및 해당 웨이브 12처치 이상**에서 한 번 선택권을 발급한다. 이는 첫 적용 수치이며 재미/경제 실측으로 확정한 최종 밸런스가 아니다. 보스전에는 발급하지 않는다.

- HUD `마법 선택 N` 배지만 나타나고 창을 강제로 열지 않는다. 준비 시간까지 선택을 미룰 수 있다.
- 기본 공격·보조·연결 구체 세 종류 중 하나를 가방에 넣는다. 자동 장착·자동 강화·기존 주문 교체는 없다. 기존 장착/여분 수량과 재고 최대12개 규칙을 따른다.
- 후보는 처음 발급 때 고정하고 재열기로 다시 추첨하지 않는다. 재고 상한에 걸린 후보만 다시 채운다. 보상 ID와 revision을 검사하여 연타·오래된 버튼·재시작 전 콜백으로 복제할 수 없다.
- 모든 구체가 재고 상한이면 그 선택권의 예산18G를 한 번 회수할 수 있다. 이후 합치기 등으로 공간이 생기면 새 후보를 제공한다.
- 현재 처치 마석 예산에서 웨이브마다18G 상당을 선택권 몫으로 할당한다. 1웨이브 일반 처치 마석 상한은48→30, 완료 보너스20은 유지된다. 선택권을 얻지 못한 경우 실제 처치에서 예산 때문에 미지급된 부분만 종료 때 복구한다. 미처치 적의 돈을 지급하지 않는다.
- 1~4웨이브 마석 최대 예산280 + 완료 보너스80 중 최대72G 상당을 구체4개로 옮긴다. 선택한 기본 구체는8~18G 상당이며 싼 구체를 골랐다고 차액을 환급하지 않는다. 총 가치 상한을 늘리지 않는 초기 배분이며 실제 구매 경험이 동일하다는 뜻은 아니다.
- 사망·실험 종료·재시작은 대기 선택권을 정리한다. 웨이브 종료는 이미 얻은 선택권을 준비 화면으로 넘긴다.

## 자동 조준과 마법 동작

`scripts/auto_targeting.gd`가 현재 카메라 안의 살아 있는 적을 **플레이어 기준 거리순**으로 정렬한다. 같은 거리면 인스턴스 ID로 순서를 고정한다. 각 오브는 자기 발사 위치에서 해당 적 위치를 향해 쏜다.

| 상황 | 동작 |
|---|---|
| 표적이 두 마리 이상 | 오브1=최근접, 오브2=두 번째 가까운 적 |
| 한 마리만 있음 | 두 오브가 그 적을 공유 |
| 표적이 부족한 추가 오브 | 마지막 유효 순위를 공유 |
| 적이 없음/모두 화면 밖 | 마지막 이동 방향으로 자동 발사를 유지 |
| 앞 오브가 같은 틱에 적을 죽임 | 죽은 표적을 제외하고 다음 유효 순위를 선택 |

세 번째 이후 인덱스를 받는 선택 함수와 검사는 준비했지만 **세 번째 오브/슬롯/획득 기능은 추가하지 않았다.** 기존 추적 보조는 발사 이후 유도/낙뢰 주변 적 추적 등 기존 역할을 유지하므로 초기 조준 순서가 이후 모든 유도 타깃을 영구 고정한다는 뜻은 아니다.

- 일반 벼락: 플레이어 주변90~360 거리의 무작위 지점에 예고 후 낙뢰. 커서 위치를 읽지 않는다. 추적 보조가 있으면 낙뢰 지점 근처의 적을 추적하다 낙하 전에 고정한다. 월드 가장자리에서는 중심을 유효 범위 안으로 제한한다.
- 연결로 발동한 벼락: 명중/소멸 사건 위치를 유지한다. 합성의 내부 낙뢰도 명중 위치를 유지한다. 둘은 커서 추적 공격이 아니며 무작위 플레이어 주변으로 옮기면 기존 연결/합성 의미가 깨진다.
- 얼음 부채·기본 투사체·부메랑·씨앗 등의 초기 방향은 해당 오브의 자동 표적에서 얻는다. 위성은 기존 플레이어 주위, 잔불은 기존 이동 경로에 생성한다.
- 코드 검색 결과 전투 공격의 직접 `get_global_mouse_position()` 참조는 제거됐다. `_update_mouse_aim()` 이름은 이전 검사 도구 호환용 진입점으로만 남기고 내부에서는 자동 조준을 호출한다. 측정기의 의도적인 합성 target_point 설정은 플레이어 커서 입력이 아니다.
