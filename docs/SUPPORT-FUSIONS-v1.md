# 보조·연결 완성 합성 v1

2026-10-28. 로드맵 4번 실제 구현. 승인된 RELEASE-EXPERIENCE-AND-ASSETS-v1.md 5절의 9종을 제작·장착·실제 마법 실행·시험·도감·체크포인트에 연결했다.

기본 18종은 유지한다. 기존 공격 합성 9종에 보조 7종·연결 2종을 더해 완성 합성은 18종, 전체 구체는 36종이다. 새로운 기본 공격 9종을 만든 것은 아니다.

## 제작·역할

지정된 서로 다른 +3 실물 두 개와 12마석을 소비해 결과 한 개를 만든다. 결과는 한 칸이며 추가 강화하지 않는다. 제작함 → 합성 도감에서 재료·종류·행동을 보고 제작한다. 여분이 있으면 다른 오브의 장착 실물은 유지한다. 장착 재료가 소모되면 기존 실물 재조정 경로로 반영한다. 소비 직전 재고 revision을 검증하고, 소비를 되돌리기로 복제할 수 없게 기존 제작 이력 초기화를 유지한다.

| 결과 | +3 재료 | 플레이어가 보는 행동 |
|---|---|---|
| 파상 분열 | 갈래 + 메아리 | 갈래 공격을 시간차로 세 차례 펼친다. |
| 군집 추적 | 갈래 + 추적 | 갈라진 공격이 서로 다른 가까운 적을 나눠 노린다. |
| 추격 관통 | 관통 + 추적 | 적을 지난 공격이 다음 적으로 향한다. 고정된 공격은 새 배치만 바꾼다. |
| 도약 관통 | 관통 + 연쇄 | 관통한 공격의 정상 종료 위치에서 주변 적으로 한 번 더 퍼진다. |
| 압축 거성 | 거대화 + 응축 | 느리지만 크게 밀어내는 한 방을 만든다. |
| 커지는 메아리 | 거대화 + 메아리 | 반복하는 공격이 뒤로 갈수록 커진다. |
| 잔향 연쇄 | 연쇄 + 메아리 | 연쇄가 때렸던 자리를 잠시 뒤 다시 때린다. |
| 이중 사건 | 명중 후 + 소멸 후 | 첫 명중과 정상 소멸 때 뒤 주문이 각 한 번 나온다. |
| 지연 점화 | 명중 후 + 메아리 | 첫 명중한 자리에 잠시 뒤 뒤 주문이 나온다. |

앞의 일곱 개는 일반 보조와 같이 같은 오브의 오른쪽 공격들에 적용한다. 뒤의 두 개는 두 공격 사이에 놓는 연결이다. 연결 자식은 독립 순차 시전으로 다시 발사하지 않는다. 기존 일반 보조와 함께 장착하거나 같은 완성 보조를 중복 장착할 수 있다.

## 초기 수치·중복 계산

공격별 고유 패턴은 보존한다. 기본 보조 부모 +3의 모든 수치를 그대로 곱한 결과가 아니라, 슬롯 압축과 새로운 행동을 얻는 완성형이다. 아래는 첫 구현 수치이며 사람의 전체 플레이로 최종 균형을 확정한 값은 아니다.

- **파상 분열:** 추가 갈래 2개, 0/0.24/0.48초에 세 파동. 파동 위력은 각 1/3이며 기존 갈래 분배를 그 안에서 한 번 적용한다. N개면 추가 갈래 2N, 파동 1+2N개에 각각 1/(1+2N) 예산. 일반 메아리를 더 붙이면 반복 예산을 별도로 더하며 파동과 메아리 개수를 곱하지 않는다.
- **군집 추적:** 추가 갈래 2개, 회전 반응 0.55·탐색 배율 0.75의 추적 기여. 발사 시 다른 표적을 나누고 비행 중 재탐색도 분산 인덱스를 유지한다. 중복은 갈래/추적 기여를 합산한다. 적이 적으면 공유한다.
- **추격 관통:** 추가 관통/분산 설치 4회와 같은 추적 기여. 직진탄은 명중 뒤 최대 약0.65라디안씩 다음 적으로 회전하고, 기본 부메랑도 남은 추가 접촉을 곡선으로 이은 뒤 귀환한다. 중복은 추가 대상 4N 및 추적 기여 합산이다.
- **도약 관통:** 추가 관통 4회. 정상 종료 때 180거리 안 최대3명에게 해당 공격의 50% 피해. N개면 추가 관통4N, 파급 대상3N. 파급은 피해 사건만 만들며 새로운 주문·상태·연쇄·연결을 재귀 생성하지 않는다. 같은 발자국 시전 묶음은 마지막 정상 종료 때 한 번만 파급한다.
- **압축 거성:** 크기2.16배, 피해3배, 첫 밀침100, 전체 순환 대기3배. 중복 시 크기·피해·대기는 각각 거듭제곱, 첫 밀침은100N. 냉기나 정원 성장 자체를 이 피해 배율로 키우지 않는다.
- **커지는 메아리:** 0.25초 뒤 크기1.3배·위력45%, 0.5초 뒤 크기1.7배·위력45%로 재현. N개는 2N개를 0.25초 간격으로 더하며 크기는1.3/1.7쌍을 반복한다. 복사본이 다시 복제되거나 뒤로 갈수록 피해까지 기하급수로 늘지 않는다.
- **잔향 연쇄:** 최대5명, 거리220의 기존50% 홉 감쇠 연쇄. 실제로 때린 각 위치를 기록하고0.35초 뒤 반경32에서 해당 홉 피해의50%로 재타격한다. 적이 이동하면 빗나간다. 재탐색·재연쇄·새 연결은 없다. 중복은 최대 연쇄 대상5N이 되고 같은 위치의 잔향을 N번 복제하지 않는다.
- **이중 사건:** 명중/소멸에 각각50% 분배. 각 사건별 최초 한 번이며 두 사건을 한 triggered 플래그로 묶지 않는다. 이50%는 가지 예산이어서 다음 연결에서도 유지된다. 예: 별빛탄→이중 사건→별빛탄→명중 후+3→별빛탄은 중간/마지막 탄 모두11피해다. 일반 연결의50~100% 직접 후속 위력 규칙은 유지한다.
- **지연 점화:** 최초 명중 위치와 방향을 고정한 뒤0.6초 후 직접 후속100% 한 번. 메아리 부모의 일반 보조 효과를 후속에 자동 부착하지 않는다. 공격 개체별 첫 사건 한 번이다.

보조 기여는 컴파일 시 출처를 유지한 채 한 번만 계산한다. 상위 보조의 flag를 자식에 다시 합치는 대신 자식의 컴파일된 오른쪽 범위를 사용한다. 완성 보조와 일반 보조의 기여는 같은 효과 프로필에서 해석한다.

## 정리·저장·도감

지연 후속과 잔향은 런타임 소유 예약 목록에 저장한다. 실행 전에 generation과 전투/시험 상태를 확인한다. 웨이브 종료·시험 종료·강제 초기화는 예약을 지우며 정상 소멸 사건을 만들지 않는다. 오래된 프로그램 개체가 편집 후 새 지연 주문을 예약하는 것도 막는다. 반복·예약·탄 수의 기존 안전 상한 및 차단 측정은 유지하지만 아래 대표 조합은 상한에 기대지 않았다.

도감의 완성 합성 분모는18로 확장되고 발견한 합성의 공격/보조/연결 역할과 레시피를 표시한다. 기존 프로필·준비 저장을 초기화하지 않는다. 새 ID를 기존 스키마의 합법적 구체로 인정하므로 이전 준비 저장도 그대로 읽을 수 있다. 실물/구매/보상 규칙은 변경하지 않는다.

## 고부하 성능: 개선과 남은 문제

짧은 시험 뒤 더 복잡한 두 오브를 무적 표적24개에 계속 발사했다. 디버그 실행에서 낙뢰가 수십 개 겹치며6~10FPS까지 저하됐다. 같은 장면의 마법 표시를 잠시 숨기면60FPS로 돌아왔고, 그리기 호출은1609→284로 줄어 표시 비용이 큰 병목임을 확인했다. 해당 비표시 조작은 진단용 메모리 변경이며 최종 게임은 표시를 유지한다.

낙뢰 예고·충격 원·연쇄/번개 선의 기존 윤곽을 `draw_multiline`/`draw_multiline_colors`로 묶었다. 공격 판정·위력·후속 개수는 줄이지 않았다. 논리 낙뢰 자체를 합치는 시도는 같은 조건에서 이득이 확인되지 않아 되돌렸다. 색 배열 API의 선분당 색 개수를 잘못 사용한 중간 렌더 오류를 수정한 뒤535+40 검사가 오류 없이 통과하고 새 게임 로그도 깨끗했다. 별도의180프레임 MCP 측정은8초 평가 제한에 걸려 폐기하고 짧은 런타임/모니터 관찰로 대체했다.
