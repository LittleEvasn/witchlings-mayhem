# 피드백 반영 — 수동 장착·즉시 수령·연결별 보조 범위

2026-10-29. 사용자의 최신 피드백과 ‘바로 진행해’ 승인으로 직전 작업의 세 규칙을 변경했다. 이 문서가 개편3의 자동 장착/수령 확인과 과거 전역 오른쪽 보조 범위보다 최신이다.

## 완료한 범위

1. **새 마법은 가방에 보관.** 일반 신규 획득·제작은 빈 오브/빈칸이 있어도 장착하지 않는다. 자동 장착 모듈과 UI 토글을 제거했다. 옛 프로필의 `auto_equip` 키는 읽기 호환만 남고 값이 true여도 기능은 되살아나지 않는다. 중복 획득 +1 강화는 장착 중인 같은 실물을 같은 자리에서 갱신한다.
2. **보상 선택 한 번으로 끝.** ‘획득 완료’/계속/선택 후 편집 화면을 제거했다. 클릭 시 한 번 지급하고 즉시 전투로 복귀하며 짧은 비정지 획득 메시지만 남긴다. 밀린 보상이 있으면 전투를 재개하지 않고 다음 선택으로 넘어간다. 인벤은 사용자가 Tab으로 열고 전투는 계속된다.
3. **연결마다 보조 범위를 초기화.** 보조는 오른쪽 공격들에 적용하되 다음 연결 구체에서 끝난다. 후속 공격은 연결 뒤에 직접 놓은 보조만 받는다. 빈칸/다단계/부분 실행은 유지하며 UI 적용 대상 강조도 실제 컴파일 결과와 일치한다. 사용되지 않은 앞 보조는 회색 경고가 생기며 정상 공격을 막지 않는다.
4. **메아리는 해당 공격만 반복.** 메아리 및 완성 보조의 시전 반복 복사본은 부모의 후속 연결을 가지고 가지 않는다. 따라서 앞 메아리가 후속까지 반복시키지 않는다. 후속 앞에 직접 놓은 메아리는 후속 공격 자체를 반복한다. 첫 유효 명중/정상 소멸만의 발동, 직접 후속 위력 50/65/80/100%, 분배 예산과 세대 정리는 유지한다.

예:
- `[거대화][별빛탄][명중 후][꽃폭탄]`: 별빛탄만 거대화.
- `[별빛탄][명중 후][거대화][꽃폭탄]`: 꽃폭탄만 거대화.
- `[메아리][별빛탄][명중 후][꽃폭탄]`: 별빛탄 반복본은 꽃폭탄을 추가 발동하지 않는다.
- `[별빛탄][명중 후][메아리][꽃폭탄]`: 꽃폭탄 자체를 반복한다.
- 연결 없는 `[거대화][별빛탄][꽃폭탄]`: 두 독립 공격 모두 거대화.

## 유지한 구분

- ‘새 마법을 빈칸에 자동 장착’은 제거했다. **합성에서 이미 장착된 부모를 소비하고 그 부모 자리에 결과를 놓는 동작**은 기존대로 유지했다. 재료가 가방에만 있으면 결과도 가방에 남는다. 상자 합성의 가방 전용 선택도 유지한다.
- 상자의 열기/0.8초 개봉/3택은 유지하되 수령 후 확인은 없다. 설정의 ‘빠른 보상’은 의미를 ‘상자 개봉 생략’으로 바꿨다. 기존 저장값은 그대로 호환한다.
- 1~4오브/6~8칸/오브5회 강화, 종류별 실물1개·중복+1/max3, 상자 합성, 저장/경제/마법 수/유물/아트/BGM은 그대로다. 선택 시간에는 정지, 평소 인벤은 비정지다.

## 검증

- `connector_scope_test`: **133 검사 / 0 실패**. 기본·완성 보조14개 × 연결4개에 대한 앞/뒤 배치, 실제 명중·소멸 후속의 크기/반복/첫 사건, 자식의 직접 보조, 양쪽 메아리, 강제 정리와 슬롯/강조/부분 복구 확인.
- `acquisition_ui_test`: **42 검사 / 0 실패**. 가방 보관·옛 설정 무효·중복 제자리 강화·합성 수량·즉시 복귀·연속 보상·정지/비정지·상자·설정 저장 확인. 직전 자동 장착/확인 화면 전용 기대값은 최신 사용자 규칙으로 교체했다.
- `fixed_slots_test`: **59 검사 / 0 실패**. 기존 자유 배치/부분 실행/되돌리기/저장·합성 검사 유지. 보조 범위 관련 두 기대값만 최신 규칙으로 변경.
- 합계 **234개 관련 검사**. 다른 전체 검사나 30분 플레이/성능 전수 측정은 실행하지 않았다.
- Godot MCP는 연결 세션0개로 사용할 수 없었다. 대신 Godot4.6.2 실제 렌더링 프로세스의 별도 자동 점검으로 보상 버튼에 뷰포트 마우스 누름/해제를 전달했다. 클릭 후 `stage==""`, 모달 없음, 가방 재고1/장착0, HUD 복원 확인. 캡처 `artifacts/reward-feedback-choice.png`, `reward-feedback-after.png`; 기록 `reward-feedback-visual.json`. 테스트는 `record_runs=false`와 별도 프로필을 사용했으며 종료했다. 데스크톱 파란 화면 제어를 쓰지 않았다.
- Sol6.1/high 독립 읽기 검토1명은 합성의 기존 자리 치환 유지 의도를 확인한 뒤 확정 결함 없음으로 보고했다. 검토자는 실행/편집하지 않았다.
- Windows 실행파일 갱신 성공, `project.godot` 기존 변경 보존 및 커밋 제외. 빌드 `artifacts/builds/lumi-run/WitchlingsMayhem.exe`. 배포 빌드/캡처는 로컬 전용이며 소스와 문서를 GitHub에 체크포인트로 올린다.
