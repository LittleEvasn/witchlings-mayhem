# 슬롯형 인벤·보상 동시 편집 — 2026-10-29

사용자가 마법공예 화면을 제시하고 승인한 배치/규칙을 구현했다. 이전 `SURVIVAL-FEEDBACK-FIXES-v1.md`의 통합 UI 제안·미구현 표시는 이 문서로 대체한다.

## 현재 동작

- 일반 Tab 인벤: 왼쪽 위에 가방 한 줄, 보유한 오브마다 한 줄. 큰 오른쪽 개인창 제거. 장착하지 않은 여분은 가방에, 장착한 구체는 실제 오브 칸에 표시한다.
- 슬롯44논리px(1920출력에서 약53px), 아이콘/강화 표시/진단 툴팁. 가방은 한 페이지12칸, 이전·다음 페이지 버튼. 신규 보상을 받은 경우 그 항목이 있는 가방 페이지를 연다.
- 최대4오브·각8칸, 빈칸 위치 유지. 기존 드래그·정확한 칸 이동/교환·우클릭 해제·되돌리기·보조 적용 강조를 재사용했다. 조합이 덜 완성된 상태도 편집/정상 부분 실행 가능하다.
- 일반 인벤은 비정지. 닫으면 가방·세부 칸이 접히고 작은 오브 번호/HUD만 남는다. 기존 넓은 하단 빈 패널도 제거했다.
- 레벨업/상자에서는 같은 인벤과 아래쪽 보상 영역이 동시에 열린다. 보상 선택 전후 모두 실제 장착 편집 가능. 전장 배경은 약하게 어두워지고 중앙은 계속 보인다.
- 보상을 고르면 카드가 접혀 작은 획득 결과만 남고 계속 편집한다. **전투 재개** 버튼을 눌러야 정지가 끝난다. 신규 자동 장착·별도 획득 완료 화면 없음.
- 필수 보상이 남으면 재개 불가. 연속 레벨업은 다음 카드만 표시하면서 편집 상태를 보존하며 중간에 전투 프레임이 진행되지 않는다. Esc 메뉴를 열고 돌아와도 이 세션으로 복귀한다. Tab은 보상 편집 세션을 해제하지 않는다.
- 상자는 기존 자동1/3/5 지급 유지, 열기/빠른 개봉 모두 지급 후 같은 편집 상태로 전환. 상자를3중1택으로 되돌리지 않았다. 합성 우선 지급도 유지한다.

## 레벨업 합성 카드

- 기본은 일반 보상3개. 표시 시점에 완성 가능한 합성이 있으면 **네 번째 카드에 합성1개 추가**, 전체에서1개만 고른다.
- 가능한 합성이 여러 개면 그중 무작위1개. 해당 레벨업을 처음 표시할 때 `fusion_locked`/`fusion_option`으로 고정한다. 화면 재생성·편집·페이지 변경으로 재추첨하지 않는다.
- 보유한 지정+3 두 종류/완성별 한 판1회 규칙 유지. 선택 시 두 재료를 소모하고 무료 완성1개를 지급하며 기존 부모 칸의 치환 규칙을 쓴다. 자동 지급이나 일반 보상과의 동시 획득은 없다.
- 일반 보상을 고르면 합성 재료와 합성 기회는 소비하지 않는다. 다음 레벨업에 여전히 준비되어 있으면 새 합성 후보가 나올 수 있다.
- 현재 보상 선택으로 부모가+3에 도달한 경우 다음 레벨업 표시부터 합성 후보가 된다. 이미 열린 화면을 편집한다고 후보를 바꾸지 않는다.
- 준비 저장의 미수령4카드·잠긴 후보/JSON 호환을 반영했다. 4번째 일반 보상/중복 합성/잘못된 위치는 검증에서 거부한다. 옛 상자 후보는 읽기 호환하며 실제 지급은 새 자동 경로다. 전투 중 이어하기를 추가한 작업은 아니다.

## 코드

- `compact_inventory.gd`: 실제 Slot 제어를 공유하는 가방/오브 줄·페이지·유물·작은 도구줄.
- `personal_window.gd`: 일반 인벤 진입, 사용하지 않는 옛 서랍 구현 제거. 제작/시험 작업대는 기존 화면 유지.
- `level_reward_ui.gd`: 하단3/4카드·개봉·작은 자동 획득 결과·명시 재개.
- `combat_rewards.gd`: 보상→편집 정지 단계, 재개 검증, 고정 네 번째 합성, 레벨업 합성 허용.
- `interface.gd`, `game.gd`: HUD 접힘/복원·편집 새로고침/키 처리. `prep_board.gd`, `prep_slot.gd`: 기존 드래그 슬롯의 작은 아이콘 표시/보상 미리보기.
- `run_checkpoint.gd`: 미수령4카드와 고정 합성 후보 검증.
