- 마우스 입력으로 패시브 선택 → 상점 진입.

- 추천 조합 → 적용하고 상점으로 → 다음 웨이브 버튼 실제 클릭.
- `갈래 → 추적 → 별빛탄 → 명중 후 → 꽃폭탄`으로 2웨이브 진입, 자동 시전 4회 확인.
- 시간 만료도 실제 프레임으로 확인. 불완전한 편집을 취소하고 마지막 적용 주문으로 3웨이브 진입.
- 해당 실행의 게임 로그에 스크립트 오류 없음.
