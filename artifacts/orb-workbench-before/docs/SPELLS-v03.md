# 마법 12종 · 시제품 0.3

수치는 첫 플레이 조정값이다. 기존 6칸 / 최대 두 공격 / 보조 우선 문법과 구체 수량을 사용한다.
마우스 조준과 자동 시전. 모든 구체는 상점 무작위 진열 대상이며 새 그림 에셋은 추가하지 않았다.

기본 시전 간격은 별빛탄·꽃폭탄 0.48초, 부메랑 0.624초, 소용돌이 0.864초, 덫 0.72초다.
거대화가 어느 한 단계에 있으면 전체 간격 1.5배, 양쪽에 있어도 한 번 적용. 패시브 시전 속도로 나눈다.
장판을 후속 공격으로 쓸 때는 선행 공격의 간격을 사용한다. 두 번째 공격은 기본 위력 65%.

## 겹치는 규칙

- 갈래는 각 공격을 세 갈래, 각 위력 65%로 만든다. 씨앗도 각각 설치되며 동일한 구체의 보유 수량을 추가 소비하지 않는다.
- 도탄을 사용할 수 있는 동안 방향을 바꾼 뒤, 도탄이 없거나 대상이 없으면 남은 관통을 사용한다. 별빛탄의 도탄 2회 + 관통 2회는 서로 다른 적 최대 5명을 타격한다.
- 씨앗은 비행 중 적을 만나도 직접 피해를 주지 않는다. 도탄·관통을 소모한 뒤 최종 접촉 위치, 또는 비행 종료 위치에 하나의 장판을 설치한다. 중간 접촉에 장판이 복제되지 않는다.
- 부메랑은 나갈 때 추적·도탄을 적용하고 돌아올 때 플레이어를 향한다. 왕복 타격 목록과 관통 타격 수는 구간별로 초기화하지만 후속 주문 발동 기록과 남은 도탄 수는 초기화하지 않는다.
- 명중 후는 각 원본 투사체당 한 번. 부메랑 귀환·도탄·소용돌이 반복 피해·덫의 다중 피해가 중복 발동시키지 않는다.
- 소용돌이·덫은 실제 첫 피해 위치에서 후속 주문을 발동한다. 허공에 설치하거나 소멸한 것만으로 발동하지 않는다.
- 메아리 복사본은 자기 후속 주문을 한 번 발동할 수 있다. 이때 후속 공격에도 메아리의 위력 감소가 유지된다. 후속 공격에 메아리가 장착되어 있으면 그 공격의 복사본 하나는 허용되며 연결 단계를 더 만들지 않는다.
- 여러 소용돌이의 총 끌어당김 속도는 적별 초당 100px로 제한한다. 중심을 지나 반대쪽으로 튀지 않는다.
- 장판·대기 메아리는 전투 일시정지/편집 중 동결된다. 조합 적용·웨이브 종료·사망·승리·재시작 시 투사체와 함께 제거한다.

## 표시와 한도

- 부메랑: 회전하는 초승달과 진행 방향 흔적.
- 소용돌이: 보라색 나선과 실제 판정 반경의 원.
- 덫: 연두색 꽃잎과 실제 발동/피해 반경의 원. 설치 전에는 작은 씨앗.
- 거대화는 표시와 판정에 같은 배율을 적용한다. 메아리는 같은 공격 모양으로 뒤이어 나온다.
- 투사체 180 / 장판 24 / 대기 메아리 32개. 초과 투사체·메아리는 추가하지 않고 장판은 가장 오래된 것부터 교체한다.
- 하단 좁은 주문 칸에서는 소용돌이 씨앗을 ‘소용돌이’로 표시하고, 편집창과 상점에서는 전체 이름을 표시한다.
- 추천 조합은 보유한 신규 공격을 우선 사용하고, 보유 수량 내에서 보조와 명중 연결을 붙인다.
