# 적과 웨이브 · v0.5

> 후속 변경: 플레이 피드백에 따라 등장 위치 예고와 고정 대형을 제거했다. 현재는 적마다 사방 가장자리의 임의 위치에서 불규칙한 간격으로 등장한다. 실제 생성 순간 플레이어와 220px 거리 및 적 간 겹침을 확인한다. 아래 대형·입구 예고 설명과 기존 측정·스크린샷은 변경 전 기록이다. 적 종류·수량 시간표·체력·보상·공격 예고는 유지했다. 출현 전용 검증: `python tools/run_tests.py random_spawns_test`.

목표는 적 배치에 따라 마법 조합의 효율과 조준 우선순위가 달라지는 것이다. 새 적·마법·외형은 추가하지 않았다. 기능 검증과 재미 평가는 구분한다.

## 실제 변경

`scripts/waves.gd`가 웨이브 시간표, 제목·상점 안내, 체력 배율, 적·원거리 동시 제한, 드롭 예산을 관리한다. 생성기는 현재 전투 시간만 읽으며 SceneTreeTimer를 만들지 않는다. 정지·상점·시험에서는 진행하지 않는다.

| 웨이브 | 배치 | 동시 적 / 원거리 제한 | 드롭 최대 G |
|---|---|---:|---:|
| 1 | 4~5마리의 작은 접근 무리 6회 | 28 / 0 | 30 |
| 2 | 작은 슬라임 8~12마리의 무리 6회 | 46 / 0 | 40 |
| 3 | 일렬 6~7마리와 돌진 적 2마리를 겹쳐 3차례 압박 | 40 / 0 | 48 |
| 4 | 근접 호위 뒤에 원거리 적, 행렬·돌진 적 혼합 | 48 / 3 | 50 |
| 5 | 보스와 간격을 둔 소규모 지원 무리 8회 | 40 / 2 | 24 |

- 1~4웨이브 각 45초, 보스 제한 120초 유지. 보스를 먼저 처치하면 종료한다.
- 압박 묶음 사이에 새 적 생성이 없는 구간이 있다. 이미 남아 있는 적이 자동으로 사라지는 휴식은 아니다.
- 한 웨이브는 주로 마주 보는 두 입구를 사용한다. 플레이어 근처 입구는 피하며 생성 시에도 220px 안전거리를 재확인한다.
- 무리는 앞줄부터 56px 옆 간격, 48px 줄 간격으로 진입한다. 일렬 적은 같은 입구에서 0.6초 간격으로 진입한다.
- 입구에 0.9초 전 접근 표시. 호위의 원거리 적은 근접 적보다 2.5초 늦게 진입한다.
- 원거리 적은 0.7초 동안 멈춰 주황색 방향선을 표시한 뒤 그 방향으로 발사한다. 예고 후 방향을 다시 추적하지 않는다.
- 돌진은 기존 0.8초 예고를 유지한다. 보스 방사탄도 예고가 끝난 뒤 발사한다.
- 생성 제한·입구 점유·안전거리 때문에 실패한 생성은 버린다. 0.3초 이상 지난 요청과 놓친 과거 묶음도 재생하지 않는다.
- 웨이브 완료·사망에서 대기 생성과 경고를 비우고, 재시작·다음 웨이브에서 인덱스와 돈 예산을 초기화한다.

## 수치 변경과 근거

| 항목 | 이전 → 현재 | 이유 |

| 꽃폭탄 기본 간격 | 0.48 → 0.576초 | 범위 공격과 집중 공격의 역할 분리. 범위 70px 유지 |
| 작은 무리 슬라임 | 일반 25 기반 → 18 × 웨이브 배율 | 2웨이브에서 20.16HP, 기본 별빛탄 한 발로 처리 |
| 일반 돌진 적 기본 체력 | 72 → 180 | 3웨이브에서 225HP. 행렬과 함께 등장해 집중 공격할 이유를 제공 |
| 원거리 적 기본 이동 속도 | 75 → 68 | 후방에 남는 시간을 늘림. 기존 웨이브당 +3 유지 |
| 돌진 적 기본 이동 속도 | 65 → 52 | 추격·예고·돌진의 속도 차이 강화. 돌진 속도 345 유지 |
| 일반 적 HP 배율 | 매 웨이브 +20% → 1 / 1.12 / 1.25 / 1.38 / 1.5 | 약한 적은 무리 수로 압박하고 모든 적의 일괄 체력 상승을 완화 |
| 보스 HP | 1500 → 3000 | 기본 주문 모의 전투가 13.15초에 끝나던 문제를 줄이고 지원 무리 합류 시간을 확보 |
| 완료 보너스·상점 가격 | 20G·기존 가격 유지 | 기존 구매 흐름 유지. 무리 수가 돈을 무한히 늘리지 않도록 웨이브별 드롭 상한만 추가 |

보유·구매·조합 규칙은 유지한다. 구체 면역, 강제 상성, 마나 비용은 없다. 소용돌이·덫·왕복탄의 설치/귀환 거리와 지연은 그대로여서 모든 상황에서 동일한 효율을 내지 않는다.

## 실제 마법 엔진 비교

`tests/wave_balance_probe.gd`로 변경 전후 각각 36개 상황을 기록했다. 고정 시드 731, 위력 1, 120Hz 시뮬레이션, 12초, 정지한 적에게 가장 가까운 생존 표적을 조준한다. 실제 투사체·충돌·폭발·장판·메아리·연계 코드를 사용한다. 적의 이동·반격·사람의 조준 실력은 이 비교에서 제외한다. 피해는 남은 체력까지만 합산하며 과잉 피해는 제외한다.

| 조건 | 조합 | 가격 | 변경 후 결과 |
|---|---|---:|---|
| 단일 표적 1600HP | 메아리 + 별빛탄 | 26G | 12초 유효 피해 784.3 |
| 단일 표적 1600HP | 거대화 + 꽃폭탄 | 26G | 12초 유효 피해 260.0 |
| 3×3 밀집, 각 45HP | 메아리 + 별빛탄 | 26G | 9마리 처리 7.27초 |
| 3×3 밀집, 각 45HP | 거대화 + 꽃폭탄 | 26G | 9마리 처리 2.24초 |
| 65px 간격 일렬 6마리, 각 70HP | 관통 + 별빛탄 | 20G | 6마리 처리 4.57초 |
| 동일한 일렬 | 메아리 + 별빛탄 | 26G | 6마리 처리 8.12초 |
| 동일한 일렬 | 거대화 + 꽃폭탄 | 26G | 6마리 처리 11.08초 |

단독 꽃폭탄의 단일 대상 12초 피해는 759 → 400, 별빛탄은 528 유지. 관통 부메랑은 가까운 밀집에서는 2.07초로 강했지만 긴 행렬에서는 비행/귀환 거리 때문에 2마리만 처리했다. 가시꽃 덫은 가까운 정지 밀집에서 1.68초로 강하다. 한 배치에서 빠르다는 이유로 무조건 약화하지 않았고, 긴 행렬·이동하는 적에서의 차이를 남겼다.

원시 결과: `artifacts/balance-before.json`, `artifacts/balance-after.json`.

## 관련 검증

- `waves_test`: 44개 검사 통과. 5웨이브 전체 시간 동안 AI를 진행하는 무공격 누적 검사 포함. 보스 웨이브에는 실제 보스도 생성한다. 생성 안전거리·점유·상한·지난 요청 폐기·공격 예고·정리·돈 중복 방지·상점 안내·시험 시간 정지를 확인했다.
- 실제 창 입력: 기존 작업대 구매·드래그·시험·복귀·시간 종료 중 드래그·취소 14개 통과. 관련 없는 전체 검사 모음은 실행하지 않았다.
- 실제 렌더 화면에서 입구 무리, 행렬, 원거리 공격 방향선, 상점 다음 웨이브 안내를 확인했다.
- 네 번째 웨이브 최대치인 48마리(원거리 3, 돌진 6 포함)를 고체력으로 유지하고 `갈래 → 메아리 → 소용돌이 → 명중 후 → 거대화 → 꽃폭탄`을 실제 간격으로 시전한 창 검사: 준비 30프레임 후 180프레임 측정. 프레임 중앙값 16.666ms, p95 16.780ms, 전투 계산 p95 2.547ms. 최고 적 48 / 투사체 6 / 적 탄 3 / 장판 18 / 이펙트 48. 한 렌더 프레임에 고정 전투 틱을 한 번 진행한 실험이며 모든 조합·기기의 성능 보장이 아니다.

성능 원시 자료: `artifacts/wave-window-performance.json`. 누적 검사: `artifacts/wave-soak.json`. 기능 로그: `artifacts/waves-test-results.txt`.

## 기본 주문과 남은 재미 검토

`wave_play_probe`는 기본 주문(별빛탄 → 명중 후 → 꽃폭탄), 웨이브마다 위력 패시브 1회 누적, 고정 원형 이동과 스크립트 조준, 회피 없음으로 각 웨이브를 따로 시작한다. 1~4웨이브를 45초까지 버텼고 남은 HP는 100 / 100 / 78 / 100, 드롭 돈은 24 / 40 / 36 / 50G였다. 완료 보너스까지 포함하면 상점 예산은 44 / 60 / 56 / 70G로, 상품 2~4개를 살 여지가 있다. 보스는 26.58초에 처치했고 남은 HP는 70이었다.

이는 기본 주문으로 대응 가능한 경로가 있다는 증거이며, 실제 사람의 연속 플레이 결과가 아니다. 매 웨이브 100HP에서 시작했고 스크립트가 조준한다. 원시 자료는 `artifacts/wave-basic-play.json`.

조합별 효율 차이는 측정됐지만, 플레이어가 바꿔 보고 싶을 만큼 재미있는지는 아직 확인하지 못했다. 특히 첫 두 웨이브의 낮은 압박, 기본 연계 주문의 높은 범용성, 상점에서 유용한 구체를 고를 수 있는 빈도는 실제 짧은 플레이에서 확인할 항목이다. 복잡한 마법을 추가하거나 체력만 더 올리기 전에 이 세 가지를 살펴야 한다.
