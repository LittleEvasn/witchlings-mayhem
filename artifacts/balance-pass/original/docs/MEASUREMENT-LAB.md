# 마법 측정실

시작 화면의 **마법 측정실**로 들어간다. 아래 구체를 클릭해서 6칸까지 추가하고 위 슬롯을 클릭해서 제거한다. 구매·보유 개수 제한 없이 기존 조합 문법을 사용한다. 선택 환경 측정 또는 5개 환경 비교를 누르면 실제 투사체·폭발·장판·적 이동 코드를 고정 1/120초 간격으로 실행한다. 전투 밸런스 수치는 변경하지 않았다.

## 화면 사용

- 환경: 단일 표적 / 밀집 / 일렬 / 분산 / 계속 접근.
- 조준: 매 시전 가까운 적을 향하거나, 오른쪽에 고정한다. 유도는 발사 뒤 실제 엔진에서 작동한다. 이 설정은 측정실에만 적용한다. 게임 조준은 마우스다.
- 위력 1, 공속 1, 시드 731, 최대 15초. 표적을 전멸시키면 일찍 종료한다. 계속 접근 환경은 15초 동안 진행한다.
- 현재 측정 중에는 구체·환경을 바꿀 수 없다. 중단한 결과는 저장하지 않는다.
- **최근 결과 → A**로 기준 결과를 잡은 뒤 다른 조합을 측정한다. 환경·시드·조준·위력·공속이 같을 때 DPS·처치·받은 피해의 차이를 표시한다. 구매 가격과 사용 칸 수는 사용자가 함께 비교해야 한다.
- **JSON·CSV 저장**. 완료된 측정은 자동으로도 저장한다. 경로는 `artifacts/measurements/lab-<실행시각>.json`과 `.csv`. 세션의 완료 결과 전체가 들어간다. 화면에는 최근 5개를 표시한다. 세션을 나가기 전에 필요한 결과를 저장한다.

## 기록의 의미

| 기록 | 정의 |
|---|---|
| 유효 피해 | 실제 남은 체력에서 줄어든 양 |
| 원피해 | 적에게 들어간 피해 요청의 합 |
| 과잉 피해 | 원피해 중 남은 체력을 넘는 양 |
| 유효 DPS | 유효 피해 / 실제 측정 시간. 이동·비행·초기 설치 시간을 포함. CSV에는 요청한 `window_seconds`와 실제 `elapsed_seconds`를 따로 저장 |
| 접촉률 | 생성된 투사체 중 적에게 한 번 이상 직접 닿은 비율. 왕복·관통 여러 접촉도 분자는 1회 |
| 피해 횟수 | 폭발·지속 피해까지 포함한 적별 피해 사건 수. 접촉 수와 다름 |
| 폭발 / 폭발 피해 대상 | 폭발 발생 수 / 모든 폭발의 적별 피해 횟수 합 |
| 연계 | 명중 후 주문이 실제 실행된 횟수 |
| 설치 / 지속 피해 틱 | 장판 설치 수 / 소용돌이 장판별 피해 주기 발생 수 |
| 피해 기여 | 첫 주문·연계 주문과 그 메아리 계통별 유효 피해·비율 |
| 끌린 적·초 / 이동 거리 | 여러 소용돌이가 겹쳐도 적당 한 번 집계한 적용 시간 / 합산 실제 이동 거리. 시간은 영역 내 적용이며 0 이동도 포함할 수 있음 |
| 받은 피해 | 측정용 캐릭터가 실제로 받은 피해. 통상 0.85초 무적 적용. 체력을 100만으로 두어 같은 시간 동안 관찰 |
| 평균 생존 적 | 매 고정 프레임의 살아 있는 적 수를 시간으로 적분한 평균. 계속 접근에서 처리 지연 확인 |
| 상한 영향 | 탄 생성 제한·메아리 예약 제한·장판 24개 상한에 의한 교체 횟수 |
| 남은 탄 / 메아리 / 장판 | 측정 종료 때 아직 해결되지 않은 물체. 미접촉 활성 탄을 모두 빗나간 것으로 간주하면 안 됨 |

JSON은 총계, 효과별 기여, 초별 피해·처치·생존 적·탄·장판 수, 처치 시점, 조건과 상한 영향을 보존한다. CSV는 비교용 요약이다. 전체 피해 기여의 합은 유효 피해 총계와 일치한다.

## 환경

- 단일: 고정 표적 하나, 체력 100만, 반지름 24, 끌림 면역. 지속 화력 비교용이며 실제 보스 전투가 아니다.
- 밀집: 3×3 표적, 각 체력 60, 간격 42px.
- 일렬: 6표적, 각 체력 100, 간격 65px. 사거리 제약도 그대로 나타난다.
- 분산: 12표적, 각 체력 60. 시드에 따라 중심 주위 반경 240~310px에 배치.
- 계속 접근: 체력 70, 속도 80인 기본 적이 사방에서 2초마다 4명씩 등장한다. 실제 근접 AI·분리 이동·접촉 공격을 쓴다. 동시 24명 상한, 초과 도착은 버린다. 플레이어는 정해진 작은 원형 경로로 이동한다. 등장 계획은 발사 전에 별도 RNG로 고정하므로 조합이 바뀌어도 같은 시드의 계획은 같다.

고정 표적도 기존 명중 밀치기와 소용돌이의 끌림을 받는다. 단일만 끌림 면역이다. 밀치기로 그리드 갱신 시점과 명중 결과가 변하는 현상도 실제 게임 코드 그대로다.

## 코드로 반복 측정

작업 폴더: 프로젝트 루트. `python`은 사용 가능한 Python 실행 파일로 대체한다.

```powershell
python tools/measure_spells.py --recipe "seek,fan,bloom,impact,vortex" --scenario all --seeds 731,732,733
python tools/measure_spells.py --recipe "seek,fan,bloom,impact,vortex" --recipe "fan,bloom,impact,vortex" --scenario pressure --seeds 731,732,733 --output artifacts/measurements/no-seek
python tools/measure_spells.py --recipe "seek,fan,bloom,impact,vortex" --scenario scatter --aim fixed
```

`--seconds`, `--power`, `--fire-rate`, `--engine`도 설정할 수 있다. `--input jobs.json`으로 작업 배열을 넘기거나, `--all-valid`로 현재 6칸 문법의 모든 정규화 조합을 생성할 수 있다. 보조 순서만 다른 중복은 빼고, 게임과 같은 컴파일 규칙을 사용하는 조합만 측정한다. 이 도구는 GPT나 외부 API를 호출하지 않는다.

```json
[
  {"recipe":["seek","fan","bloom","impact","vortex"],"scenario":"pressure","seed":731,"aim":"nearest","seconds":15,"power":1,"fire_rate":1},
  {"recipe":["echo","bolt"],"scenario":"pressure","seed":731,"aim":"nearest","seconds":15,"power":1,"fire_rate":1}
]
```

전수 실행은 7,790개 정규화 조합(315 단일 주문, 7,475 연계 주문)이다. 기본 실행은 같은 시드 731의 다섯 환경에서 38,950회를 측정하고 요약형 JSON·CSV를 저장한다. 초별 타임라인을 생략해 대량 결과 크기를 줄인다. `--scenario pressure --seeds 731,732,733`처럼 환경과 반복 시드를 제한할 수 있다. 실행 예:

```powershell
python tools/measure_spells.py --all-valid --scenario all --seeds 731 --output artifacts/measurements/all-valid-seed731
python tools/summarize_measurements.py artifacts/measurements/all-valid-seed731.csv
```

전수 탐색의 빠른 선별은 5초로 실행한 뒤 상위 후보를 15초·3개 시드·5환경에서 재측정한다. 실제 결과는 다음 파일이다.

- `artifacts/measurements/all-valid-pressure-5s-seed731.json`·`.csv`: 유효 조합 7,790개를 동일한 계속 접근 환경, 시드 731, 위력 1, 공속 1로 선별 측정.
- `artifacts/measurements/all-valid-pressure-5s-seed731-leaderboard.csv`: 선별 결과의 DPS·피해/비용·처치 순위.
- `artifacts/measurements/refined-candidates-15s-3seeds-v2.json`·`.csv`: 선별 순위 상위 조합과 기준 조합 등 25개 후보를 5환경 × 3시드로 재측정한 375회 결과.
- `artifacts/measurements/refined-candidates-15s-3seeds-v2-leaderboard.csv`: 재측정 조합별 3시드 평균과 환경별 순위. 전멸 시간이 달라도 요청 측정 시간이 같은 실행끼리 올바르게 묶는다.

재측정 압박 환경에서 `갈래·추적·메아리·별빛탄 → 명중 후 → 가시꽃 덫`은 평균 유효 DPS 132.27, 처치 27.67, 비용 80G였다. 현재 조합 `갈래·추적·꽃폭탄 → 명중 후 → 소용돌이`는 101.78 DPS, 처치 19.33, 비용 70G였다. 기준 비용이 각각 다르고, 15초 고정 이동·자동 조준이므로 이 수치가 플레이 재미를 증명하진 않는다. 단일 시험 데이터에서는 새 후보의 피해 절반 이상이 2차 가시꽃 덫 계통에서 나왔고, 이 시험에서 장판 상한 24개에 25회 걸려 교체가 일어났다. 이 상한 영향도 전투에서의 강함을 해석할 때 같이 봐야 한다.

15초 재측정에서 환경별 유효 DPS 1위 후보는 단일 413.48, 밀집 370.29, 일렬 238.41, 분산 192.05, 계속 접근 132.27이었다. 현재 조합은 같은 환경 순서로 143.33, 282.97, 106.35, 71.92, 101.78이었다. 단일은 백만 체력 표적이라 전멸 비교가 아니고, 나머지는 3개 시드 평균이다. 이 차이는 현 밸런스를 자동으로 바꾸기 위한 판정이 아니라, 어떤 효과가 실제 수치 우위를 만드는지 후속 검토할 근거다.

조합 비용은 결과마다 보존된다. 환경별 순위를 볼 때 피해량·처치 수와 비용을 같이 보고, 서로 다른 환경의 수치를 한 점수로 합치지 않는다. 유효하지 않은 조합은 게임의 실제 컴파일러가 거절한다.

## 검증과 첫 비교

`python tools/run_tests.py measurement_test`: 실제 HP 감소 일치, 과잉 피해, 한 폭발의 여러 피해 대상, 갈래 65%, 메아리 55%, 연계 65%, 소용돌이, 기여 합산, 계측 비활성 시 결과 동일, 같은 시드 재현, 내보내기, UI 시작·중단 등을 확인한다.

`artifacts/measurements/initial-comparison.json`·`.csv`: 5조합 × 5환경 × 3시드, 75회. 유도·갈래·꽃폭탄→소용돌이에서 유도/갈래/연계를 각각 제거한 경우와 메아리·별빛탄을 측정했다. 가격은 70/54/56/42/26G로 서로 다르므로 공정한 동일 비용 순위가 아니다. `all-valid-seed731`은 전수 비교 실행 결과다.

단일 조건에서 주력 조합은 15초간 유효 피해 2149.875, DPS 143.325였다. 꽃폭탄 기여 975, 연계 소용돌이 기여 1174.875. 유도를 빼면 DPS 47.775로 내려갔다. 이 조건에서는 유도가 갈래 탄들을 같은 표적으로 모으고, 각 탄이 소용돌이를 설치하는 중첩이 실제로 발생한다. 현재 자식 주문 계수는 `factor*0.65`를 사용하여 부모 갈래의 탄당 65% 감소를 상속하지 않는다. 측정기는 이 동작을 그대로 기록하며, 의도한 규칙인지 판단한 후 별도 밸런스 작업으로 다뤄야 한다.

## 해석의 한계

- 자동 조준·정해진 이동은 비교를 위한 통제 조건이다. 사람의 조준 실수·회피·재미를 입증하지 않는다.
- 단일 표적과 밀집 표적의 DPS를 서로 비교해 우열을 정하면 안 된다. 같은 환경에서 비교한다.
- 전멸하는 환경은 전멸 시간과 과잉 피해를 먼저 보고, 계속 접근은 처치·평균 잔존 적·받는 피해를 함께 본다.
- 종료 뒤 남아 있는 탄·장판의 미래 피해는 포함하지 않는다. 설치형은 지속 시간을 늘려 다시 비교할 필요가 있다.
- 단독·연계·메아리의 피해를 구분해도 모든 보조 효과의 인과적 기여가 자동 계산되는 것은 아니다. 유도 등을 하나씩 제거한 비교가 필요하다.
- 측정기의 경과 벽시계 시간은 렌더링 FPS나 게임 프레임 시간 벤치마크가 아니다.
- 모든 조합의 전수 탐색과 상하향은 이번 작업에 포함하지 않았다.
