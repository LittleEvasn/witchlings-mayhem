# 조합 기반 개편 — 2026-10-23

## 이번 범위

호환성 예외 완화, 공격별 편집, 독립 시전 오브 2개를 구현했다. 강화·합성·유물·맵 확장·멀티는 이번 범위에 포함하지 않았다. 기존 22종 구체와 전투 → 패시브 → 상점 흐름을 유지한다.

## 사용법

1. 오브 1 또는 오브 2를 선택한다. 각 오브는 6칸이며 공격·보조·연결 모두 칸을 사용한다.
2. 공격 ①/② 카드를 선택한 다음 보유 공격을 클릭한다. 보조는 클릭하거나 카드에 끌어 붙인다. 공격을 교체해도 보조는 유지한다.
3. 공격 두 개에는 보유한 연결 구체가 필요하다. 기본적으로 남은 연결 구체를 선택하며 가운데 목록으로 변경한다.
4. ‘공격 순서 ⇄’로 묶음을 뒤집고 ‘다른 오브로 ↗’로 공격과 보조를 함께 이동한다. 꽉 찬 오브에는 이동하지 않는다.
5. 보조 우클릭/보유 목록 드롭으로 해제, 카드 ×로 묶음 제거. 되돌리기는 양쪽 오브를 함께 복원한다.
6. 시험 발사에서 두 오브가 함께 작동한다. 주문 적용은 양쪽을 확정한다. 상점 시간 종료는 마지막 적용 상태를 사용한다.

시작 꾸러미는 오브 1에 있고 오브 2는 비어 있다. 별도 무료 복제를 주지 않는다. 한 오브만 사용해도 되지만 양쪽 모두 공격 없이 적용할 수는 없다. 인벤토리 수량은 양쪽 합산이며 종류별 구매 상한은 2 → 4개로 변경했다. 네 공격 자리까지 동일한 종류를 활용할 수 있도록 한 것이다.

## 호환성 처리

보조 10종 × 공격 9종의 90가지 단일 부착을 허용한다. 이름만 허용하고 무효로 두지 않도록 다음 동작을 추가했다.

| 보조 | 새로 지원하는 동작 |
|---|---|
| 접목 | 소용돌이·덫의 기존 성장 유지. 나머지는 같은 오브/공격 단계의 3회 시전을 모아 합산 위력 ×1.2, 크기 ×1.4로 방출. 12초간 추가 투자가 없으면 저장분 종료. |
| 추적 | 서리숨결은 가까운 적 쪽으로 방향 보정. 위성은 궤도를 유지하며 적 쪽으로 보정. 잔불은 경로 주변 적 쪽으로 제한적으로 이동. |
| 관통 | 벼락·위성·잔불은 진행 방향의 추가 2명을 반 위력으로 타격. 서리숨결은 기존 4명 → 6명. 기존 탄/설치 씨앗 처리는 유지. |
| 도탄 | 서리숨결·위성·잔불은 가까운 추가 적 최대 2명에게 반 위력 타격. 기존 탄/벼락 동작 유지. |
| 메아리 | 위성·잔불에도 기존 0.18초 후 55% 위력 재시전 적용. 위성은 오브/공격 단계별 일반 2세트와 메아리 2세트까지. |

귀환 후는 돌아오는 부메랑에 연결하는 의미상 제한을 유지한다. 파쇄는 어느 공격에도 장착 가능하지만 얼린 적이 있어야 추가 효과가 생긴다. 다른 오브의 서리숨결로 얼리고 파쇄하는 연계도 가능하다.

두 오브는 독립 시전 주기와 원점을 가진다. 적의 냉기·각인은 공유하지만 접목 저장분과 설치물 합치기는 오브별로 구분한다. 전체 투사체·장판·지연 효과 상한은 유지한다. 실제 마법 컴파일러의 보조 → 공격 문법은 유지하고 UI가 순서를 만들어 준다.

## 검증

- `orb_workbench_test`: 216개 통과. 90가지 부착의 컴파일 및 제한 내 실행, 양쪽 수량·독립 시전·상태 연계·이동·되돌리기·시험 격리·대기시간 보존 포함.
- `workbench_test`: 41개 통과. 기존 드래그·구매·취소·상점 시간 종료 흐름.
- `magic_builds_test`: 128개 통과. 기존 특화 마법 동작. 과거 거부 조건과 구매 상한만 새 명세로 변경.
- `spell_expansion_test`: 51개 통과. 시전·지속 효과·종료 정리.
- `measurement_test`: 37개 통과. 실제 엔진 측정과 측정실 동작. 측정실은 기존처럼 한 주문 비교 도구이며 두 오브 합산 밸런스 표가 아니다.
- 실제 실행 화면에서 Viewport 마우스 이벤트로 오브 탭·묶음 이동·되돌리기·시험 발사 버튼을 조작해 성공을 확인했다.
- 상점, 전투 편집, 시험 화면을 확인했다. 겹치던 안내 문구를 제거했다. 스크린샷: `artifacts/orb-workbench-shop.png`, `artifacts/orb-workbench-trial.png`, `artifacts/orb-workbench-editor.png`.

테스트 로그는 `artifacts/*-results.txt`, 재현 UI 설정은 `tools/orb_workbench_visual_probe.gd`에 있다. 기존 파일의 작업 전 복사본은 `artifacts/orb-workbench-before/`에 보존했다.

## 아직 판단하지 않은 것

90가지 부착 실행 검사는 모든 복합 조합의 밸런스 검사가 아니다. 두 오브의 총 화력, 접목 장기 효율, 새 관통/도탄의 체감과 상점 수입 대비 완성 속도는 실제 플레이와 다음 비교 측정에서 판단해야 한다. 과거 단일 오브의 전수 비교 결과를 이번 버전의 근거로 재사용하지 않는다. 기능 검사 통과로 재미가 좋아졌다고 단정하지 않는다.
