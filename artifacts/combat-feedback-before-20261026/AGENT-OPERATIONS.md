# 에이전트 운영 · 2026-10-26

기본 담당자는 이 대화/프로젝트의 개발 책임자다. 별도 상시 팀장 에이전트를 중복 생성하지 않는다.

| 역할 | 모델 / 추론 | 용도 |
|---|---|---|
| 책임자(현재 세션) | Sol 6.1 / low 기본 | 구현·검증·통합, 어려운 작업만 추론 상향 |
| wm_scout | GPT-6 Luna / high | 범위가 명확한 조사·지정 검사 |
| wm_reviewer | Sol 6.1 / high | 위험한 변경의 독립 검토 |
| wm_architect | Astra / low | 필요할 때만 설계 충돌·반복 실패 자문 |

역할 TOML은 `.codex/agents/`, 프로젝트 설정은 `.codex/config.toml`, 호출 정책은 AGENTS.md에 있다.
전역 사용자 설정에는 사용자가 승인한 Witchlings 경로의 trust_level=trusted만 추가했다. 전역 모델·에이전트 기본값은 보존했다. 다른 프로젝트에는 이 역할 설정이 적용되지 않는다.

## 호출 계약
목표 한 문장 / 사용자 규칙 / 관련 파일 / 구체적인 질문 / 수정 금지 범위 / 허용 검사 / 완료 조건을 전달한다.
전체 채팅 기록은 넘기지 않고, 기본적으로 보조 한 명만 사용한다. 작은 일은 담당자 혼자 처리한다.
새 스레드를 사용자 사이드바에 만드는 create_thread가 아니라 작업용 subagent를 쓴다.
읽기 전용은 행동 지침이며 별도 샌드박스 권한 제한이 아니다.

## 시작 위치 주의
이 설정은 Witchlings 프로젝트를 작업 디렉터리로 시작하는 로컬 Codex용이다.
오리겜 등 다른 폴더에서 시작된 대화에는 대상 폴더의 설정이 자동으로 재적용된다고 가정하지 않는다.
그 경우 책임자는 대상 AGENTS.md와 역할 TOML을 읽고 모델·추론·지침을 명시해서 위임한다.
클라이언트가 프로젝트를 신뢰하지 않아 설정을 건너뛰는 경우 이를 보고하고, 신뢰/보안 설정을 몰래 바꾸지 않는다.
현재 세션의 주 모델이 설정 파일 작성만으로 바뀌는 것도 아니다.
