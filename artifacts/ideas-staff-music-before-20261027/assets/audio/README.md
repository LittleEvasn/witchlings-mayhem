# Original run music sketches

Three mono 16-bit PCM loops composed with tools/compose_run_music.py for this project.
No third-party recordings, sample packs, voices or borrowed melodies were used.
Prepare: 88 BPM, combat: 112 BPM, boss: 132 BPM. A minor family, a soft sine-based sound.
These are functional original music sketches for the playable Lumi route, not approved final mastered soundtrack.
The game loops the imported WAV with AudioStreamWAV and keeps independent music/effect mute preferences.
