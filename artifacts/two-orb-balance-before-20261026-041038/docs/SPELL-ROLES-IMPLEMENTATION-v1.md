# 구체 역할 정리 1단계 구현

2026-10-26 · Godot 4.6.2 · 보조 강화·전반 밸런스 조정 전

## 이번에 바뀐 플레이 규칙

- 공격 9종·완성형 합성 5종은 유지. 일반 보조는8종, 연결은 명중 후/소멸 후2종.
- 파쇄 구체를 제거했다. 서리/빙결화로 냉기3이 되면 얼음 껍질을 만들고, 이후 냉기를 주지 않는 직접 공격이 추가 피해20×냉기 출처의 power·rank 가중평균을 주며 깬다. 동결도 끝나고1.5초 재동결 제한이 생긴다. 보스는 정지 없이 껍질만 받는다.
- 냉기 공격 자체·연쇄 추가타격·합성 내장 추가타격은 껍질을 깨지 않는다. 냉기를 방금 부여한 타격도 스스로 깨지 않는다. 마무리 공격의 응축/공격력으로 파쇄를 다시 배가하지 않는다.
- 접목 구체와 비설치 주문3회 수집을 제거했다. 소용돌이와 가시꽃(해당 기반 합성 포함)은 같은 오브·슬롯·설정으로48px 이내에 심으면 한 영역으로 보이며 범위가 커진다. 서로 다른 원본 시전3질량에 최대 반경+20%.
- 각 설치물의 피해·수명·첫 명중/종료 연결은 보존한다. 수명을 갱신하거나 이미 소비한 피해를 복구하지 않는다. 덫은 기존0.25초 준비 후 접근 기폭한다. 갈래·메아리 조각은 한 원본 계통당 성장 질량 최대1.
- 성장 군집에는 논리 설치물 최대12개를 넣고, 넘으면 새 군집을 만든다. 실제 활성 기여가 사라지면 범위도 줄어든다. 전체 zone24 안전 상한은 유지한다.
- 귀환 후 구체를 제거했다. 부메랑/달고리가 정상 귀환하면 소멸 후가 현재 마우스 조준 방향으로 한 번 발동한다. 돌아오기 전 정상 수명 만료도 소멸 후다. 강제 정리에서는 발동하지 않는다. 달고리의 내장 위성은 그대로 생성된다.
- 도탄(bounce)은 표시 이름을 연쇄로 바꿨다. 모든 공격의 첫 직접 피해에서 가까운 다른 적에게 추가 타격을 잇는다. 기본 추가2명, 중복당+2명. 홉마다50%로 감소한다. 탄의 진행 방향을 바꾸거나 주문 전체를 복제하지 않는다.
- 설치 주문의 연쇄는 전달 씨앗이 아니라 실제 설치 본체의 첫 피해에서 발동한다. 지속/왕복/잔불의 추가 접촉으로 연쇄를 다시 시작하지 않는다. 원래 영역 피해 대상은 추가 연쇄에서 제외한다.
- 연쇄 추가 타격에는 원본의 비례 상태량이 들어갈 수 있지만 연쇄/명중 연결/합성 고유 효과/새 주문을 다시 생성하지 않는다.

## 이번에 유지한 수치와 후속 작업

설계서의 기본 갈래 총1.2배, 메아리35%, 응축 가산식, 새로운 관통 감쇠, 갈래 후속 지분 분할, 전 공격의 새 겹침 정책은 아직 적용하지 않았다. 기존 갈래 개당0.65·메아리55%/0.18초·거대화1.6/대기1.2·응축3/대기2.5·각인 수치와 child_factor0.65를 유지한다. 공격 피해·공속·가격·적·웨이브·수입도 이번에 일괄 조정하지 않았다.

연쇄는 역할 변경 자체 때문에 이전 ‘전체 탄 도탄/영역별 별도 추가타격’과 피해 분포가 달라진다. 이번에는 기존 비탄 추가타격의50%를 홉별로 사용했고, 설계서의 기본35%와 강화별 증가치는 보조 강화/측정 단계로 남겼다. 파쇄20과 성장 최대반경20%는 기본화되는 새 역할의 초깃값이다. 밸런스 검증 완료를 뜻하지 않는다.

관통이 일부 비탄에서 가짜 직선 추가타격을 주는 기존 동작과 보조 전부 compatible=true도 이번에는 유지했다. §1 역할 정리의 네 변경과 무관한 보조 적용 범위/UI 개편은 다음 단계다. 보조 강화는 아직 제공하지 않는다. 유물·소환·마나는 추가하지 않았다.

## 기존 데이터와 시작 꾸러미

신규 판의 정원 꾸러미는 거대화+소용돌이, 냉기 꾸러미는 서리→명중 후→별빛탄이다. 냉기 꾸러미는 기존 무료 별빛탄/명중 후를 재사용하므로 중복 지급하지 않는다.

scripts/spell_role_migration.gd는 옛 recipe에서 graft/shatter를 제거하고 on_return을 expire로 변환한다. 게임의 준비/편집/시험 진입에도 변환 경로를 연결했다. 옛 실험 JSON을 읽는 측정 runner에도 레시피 변환을 넣었다.

진행 중 옛 보유품이 있으면 graft/shatter 보유 수량당18G 환급, on_return은 같은 수의 expire로 바꾼다. 장착은 재고 예약이므로 두 번 환급하지 않는다. 두 오브·편집본·실행본·선택·Undo·드래그 revision을 함께 갱신하고, 예약 수량이 맞지 않으면 원본을 그대로 남긴다. 재실행해도 환급되지 않는다. 옛 상품만 남은 경우에는 판매를 정리하고 가짜 환급은 하지 않는다.

현재 런 저장 파일은 없으므로 영구 저장 포맷은 만들지 않았다. 외부에서 비공식 강화 폐기 토큰을 주면 기존 화폐 강화식 환산액을 포함해 환급한다. 실제 영수증이 없는 외부 입력에 대한 호환 정책이다.
