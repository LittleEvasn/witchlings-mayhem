# 슬롯 마법 실행과 강화 · 2026-10-25

이 문서는 현재 조합 실행 규칙이다. 이전 문서의 “공격 최대 두 개·연결 하나·같은 보조 중복 금지” 설명을 대체한다. 두 오브, 오브별 6칸을 유지한다.

## 슬롯을 읽는 규칙

- 독립 공격은 왼쪽부터 순차 시전한다. `[별빛탄][꽃폭탄]`이면 별빛탄 다음 꽃폭탄이다.
- 일반 보조는 같은 오브에서 오른쪽의 모든 공격에 적용한다. `[갈래][별빛탄][꽃폭탄]`은 둘 다, `[별빛탄][갈래][꽃폭탄]`은 꽃폭탄만 강화한다.
- 보조 적용은 컴파일할 때 각 공격의 개수·원본 슬롯·강화 단계 기록으로 확정한다. 연결 시 부모의 보조를 다시 복사해서 중복 적용하지 않는다. 보조의 강화 단계 기록은 준비했지만 강화된 보조 구체는 아직 제공하지 않는다.
- 연결은 앞 공격의 사건을 받아 뒤 공격을 실행한다. 연결된 공격은 독립 순차 시전에 포함하지 않는다. 한 오브의 6칸 안에서 여러 단계 연결이 가능하다.
- `[별빛탄][명중 후][꽃폭탄][소멸 후][벼락]`은 별빛탄 적중 → 꽃폭탄 → 꽃폭탄 정상 종료 → 벼락이다.
- 명중 후는 주문 개체당 첫 유효 명중 한 번이다. 갈래로 생긴 각각의 탄은 자기 연결을 갖는다. 소멸 후는 정상 수명 종료·소비 시 발동한다. 화면 밖 제거·상한 때문에 강제 제거·웨이브 종료·시험 정리는 발동시키지 않는다.
- 귀환 후·파쇄·접목의 기존 특수 동작은 이번 작업에서 유지했다.
- 잘못된 임시 배열도 편집할 수 있다. 해당 오브만 시전을 멈추고, 오류 칸을 붉게 표시한다. 다른 유효한 오브는 계속 실행할 수 있다. 시험 시작·전투 복귀·준비 완료에는 유효한 배열이 필요하다.

## 시간과 피해

독립 주문 사이 간격은 기본 0.12초다. 마지막 독립 주문 뒤에는 전체 프로그램에서 가장 느린 공격의 기존 간격을 기준으로 한 순환 대기가 있다. 거대화 최대 중복 수의 `1.2^n`, 응축 최대 중복 수의 `2.5^n`을 적용한다. 둘 다 공속으로 나눈다. 두 오브는 각자의 시간과 순서 위치를 갖는다. 누락된 과거 시전을 한 프레임에 따라잡지 않는다.

기존 연결의 후속 위력 계수 0.65는 유지했다. 각 단계의 갈래 피해 감소는 그 단계에서 한 번씩 계산하며 부모 갈래 감소를 다시 상속하지 않는다. 따라서 오른쪽 전체에 보조가 적용되는 새 범위와 다단계 분기는 이전 두 단계 조합과 화력이 달라질 수 있다. 기본 공격 피해·가격을 일괄 변경하지 않았다.

현재 중복 규칙은 `Spells.STACK_RULES`에 기록하고 구체 설명에 표시한다.

| 보조 | 중복 효과 |
|---|---|
| 갈래 | 한 개 3갈래, 두 개 5갈래… 개당 갈래 +2. 각 피해는 0.65씩 곱함. 서리숨결은 부채꼴 방향 수, 벼락·위성은 지점·위성 수가 증가. 잔불은 기존 흔적의 좌우 분산 폭이 증가 |
| 추적 | 첫 구체 기존 추적, 추가마다 탐색·회전 성능 +50%. 공격 종류에 맞는 기존 추적 동작 유지 |
| 관통 | 개당 추가 타격 +2. 설치 씨앗은 해당 수에 맞춰 피해 예산을 나눠 배치 |
| 도탄 | 개당 도탄·추가 연계 타격 +2 |
| 거대화 | 개당 크기·범위 ×1.6, 순환 대기 ×1.2 |
| 메아리 | 개당 55% 반복 한 번. 0.18초씩 간격을 두며 반복 자체는 재복제하지 않음 |
| 응축 | 개당 직접 피해 ×3, 순환 대기 ×2.5 |
| 접목 | 기존 합체·3회 수집 방식. 중복 수에 따라 성장 크기와 완성 보너스 증가 |
| 각인 | 개수만큼 각인 축적량·동일 시전 상한 증가. 직접 피해는 개당 ×0.85 |
| 파쇄 | 개당 기본 추가 피해 +30. 동결 소비 방식 유지 |

탄·장판·벼락 등의 기존 수량 상한 외에 틱당 마법 실행 64회, 연결 깊이 6 제한을 둔다. 상한은 `emits_blocked`, `chain_depth_blocked`, `echoes_blocked`, `projectiles_blocked`, `strikes_blocked` 등으로 측정기에 기록한다. 보조 중복에 따른 과도한 분기를 임의로 무한 생성하지 않는다.

## 강화

기본 구체는 0단계, 최대 +4다. 같은 종류 공격 구체끼리만 결합한다.

- 둘 다 강화되었으면 단계 합산: +1과+1 → +2, +2와+1 → +3, +2와+2 → +4.
- 하나 이상 기본이면 높은 단계 +1: 기본과기본 → +1, +1과기본 → +2, +2와기본 → +3, +3과기본 → +4.
- 대상과 재료의 순서를 바꿔도 같다.
- 최대 초과는 예상 단계와 이유를 표시하고 차단한다. 재료·돈을 사용하지 않는다. 초과 정책은 임시다.
- 돈 강화는 기존대로 한 단계씩이다. 서로 다른 +4 두 종류의 완성형 합성도 유지한다.
- 오른쪽 구체 상세창에서 재료 단계를 직접 선택할 수 있다. 기본 선택은 가능한 낮은 재료부터다. 대상·재료·결과를 버튼 위에 표시한다.
- 구체는 전체 인벤토리에 보유하고 두 오브는 그 수량을 예약한다. 재료 여분이 있으면 다른 장착분을 해제하지 않는다. 실제로 장착분까지 소비해야 하면 해당 슬롯을 해제한다. 중간 공격을 소비했을 때 앞뒤 연결도 해제하여 다른 공격으로 조용히 재지정하지 않는다.
- 제작 후 되돌리기 기록은 비워서 소비한 구체를 되살릴 수 없게 한다. 드래그의 편집·재고 버전을 검사한다.

## 편집·시험

기존 두 줄의 6칸 배치를 유지했다. 공격을 빠르게 끼우면 끝에 추가하고 연결을 자동 지급하거나 삽입하지 않는다. 보조 빠른 장착은 첫 공격 앞에 넣는다. 칸 가장자리는 삽입, 가운데는 명시적인 교체·교환, 가방은 해제다.

장착 보조를 선택하면 그 슬롯의 오른쪽 적용 대상 공격들을 강조한다. 같은 종류 보조가 여러 개 있어도 선택한 슬롯의 범위를 사용한다. 가방에서 보조를 선택하면 장착된 같은 종류 보조들의 적용 범위를 보여준다. 줄 아래 실행 요약은 순차와 사건 연결을 구분하고 전체 문장은 툴팁으로 확인한다.

시험 중 편집은 현재 시험 효과·반복 예약을 정리하고 새 배열로 시작한다. 시험 중 웨이브·상점 시간은 진행하지 않는다. 편집 변경은 오브 순서를 처음으로 돌리되 기존 순환 대기를 단축하는 방식으로 악용할 수 없도록 한다.
