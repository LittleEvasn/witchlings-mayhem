# 무작위 출현 + 간헐적 무리 · 2026-10-25

현재 구현 기준은 이 문서와 `scripts/waves.gd`다. `WAVES-v05.md`의 시간표·대형·과거 마법 수치는 이전 작업 기록이다.

## 바꾼 흐름

괴수공주 데모에서 확인한 일반 출현과 이벤트 무리의 독립적인 생성 흐름을 참고했다. 원본 코드를 복사하지 않고 현재 2D 전장과 5웨이브 길이에 맞춰 구현했다.

- 일반 적: 서로 독립된 임의 가장자리에서 1~2마리씩 계속 접근한다.
- 무리: 별도 임의 간격으로 안전한 가장자리 한 곳을 선택한다. 그 주변 240px 폭에 0.16~0.30초 간격으로 합류한다. 다음 무리는 다시 위치를 선택한다.
- 입구 사전 예고와 고정 시간표는 없다. 생성 순간의 짧은 표시 및 기존 공격 예고는 남는다.
- 돌진 적은 무리의 일반 적 2마리 자리를 대신한다. 원거리 호위도 추가 수량이 아니라 일반 적 1마리를 대체한다.
- 실제 도착 순간 플레이어와 220px 거리, 다른 적과 몸 크기 + 3px 간격을 검사한다. 안전한 자리가 없거나 동시 수 제한이면 해당 요청을 버린다.
- 0.5초 넘게 늦은 예약과 큰 시간 점프의 지난 생성은 폐기한다. 적 수 제한이 풀려도 밀린 적이 쏟아지지 않는다.
- 기존 45초 × 4 + 보스 제한 120초, 패시브 보상 → 상점 → 준비 완료, 시험 중 시간 정지를 유지했다.
- 마법 기능·피해·공속·적 HP·이동 속도·상점 가격을 바꾸지 않았다. 측정기의 자동 생성 차단 훅만 새 생성기에 맞췄다.
- 탐험 건물·건물 파괴·보물 적은 이번 변경에 포함하지 않았다.

## 설정

| 웨이브 | 일반 생성 간격 | 무리 간격 / 기본 인원 | 전체 / 원거리 / 돌진 동시 제한 | 드롭 최대 |

| 2 | 1.5~2.1초 | 8.5~11.5초 / 7~10 | 46 / 0 / 0 | 40G |

일반 간격에는 웨이브 시작 1.1배 → 끝 0.85배의 완만한 변화를 적용한다. 첫 무리는 별도 범위(1: 7~9초, 2~4: 5~7초, 5: 10~14초)다. 보스는 돌진 적 제한에서 제외하되 전체 제한에는 포함한다. 완료 보너스 20G는 기존대로다. 상점 안내도 같은 설정을 읽는다.

## 실제 플레이에서 남은 판단

기능 검사 통과가 재미를 입증하지는 않는다. 기존보다 특히 초반 잠재 적 수가 늘었다. 첫 구매 전 압박이 과한지, 계속 움직이면서도 조준을 선택할 여유가 있는지, 드롭 상한에 너무 일찍 도달하는지는 연속 플레이로 확인해야 한다. 무처치 상태에서 플레이어 주변으로 적이 모이는 것은 여전하며, 이 작업은 적의 기본 추격 AI를 바꾸지 않는다. 난도가 과하면 우선 일반 간격·무리 수를 조정하고 마법을 일괄 약화하지 않는다.
