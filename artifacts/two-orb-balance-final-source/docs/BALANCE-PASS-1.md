# 마법 밸런스 1차 조정 — 2026-10-21

이 문서는 연계 재시전 간격을 바꾸기 전의 기록이다. 현재 규칙과 이어서 마친 비교는 [연계 재시전 조정](BALANCE-RECAST.md)을 참고한다.

## 적용한 규칙

- **갈래 연계 상속**: 부모 탄의 65% 위력을 후속 주문에도 전달한다. 연계 자체의 65%, 자식 주문의 갈래, 메아리 55%는 각각 한 번씩 적용한다. 캐릭터 공격력은 발사 시 저장하여 한 번만 곱한다.
- **거대화**: 크기·범위 1.6배는 유지하고, 전체 시전 간격 페널티를 1.5배에서 1.2배로 줄였다. 후속 주문에만 붙이거나 양쪽에 붙여도 간격 페널티는 한 번이다.
- **관통 씨앗**: 사거리 272→544px. 적 접촉마다 위력의 1/3을 설치하며 최대 세 지점에 놓는다. 접촉을 모두 쓰지 못하면 남은 위력을 비행 종료 위치에 모아 놓는다. 각 장판에서 발동하는 후속 주문도 같은 비율로 나눈다. 도탄과 함께 써도 한 씨앗의 총 피해·연계 계수가 늘지 않는다.
- **구매 비용 표시**: 정가와 별도로 무료 시작 구체(별빛탄·꽃폭탄·명중 후·갈래 각 1개)를 제외한 추가 구매 비용을 측정실과 JSON·CSV에 표시한다. 같은 구체가 두 번 필요하면 무료 한 개만 차감한다. 상점 재추첨 비용은 포함하지 않는다.

갈래의 기본 65%, 유도, 메아리 55%, 공격 주문 기본 피해, 패시브 보상 수치는 유지했다. 빠른 첫 주문으로 느린 후속 주문을 운반하는 규칙도 유지한다. 이번 변경은 완성된 최종 밸런스가 아니다.

## 비교 조건과 재현 파일

- 실제 전투 엔진, 1/120초 고정 간격, 위력·공속 1배, 시드 731/732/733.
- 단일·밀집·일렬·분산·계속 접근 환경, 최대 15초. 고정 표적을 전멸시키면 조기 종료한다.
- 발사 시 가장 가까운 적을 조준하는 비교 조건이다. 실제 게임의 마우스 조준은 바꾸지 않았다.
- 수정 전 20조합 × 5환경 × 3시드 = 300회. 기존의 일치하는 결과 135회를 재사용하고 165회만 추가 실행했다.
- 첫 조정 후 300회. 씨앗 사거리에서 문제가 확인되어 해당 3조합 45회만 재실행하고, 추가 구매 비용 30~48G의 대안 6조합 90회를 비교했다.
- 최종 결과는 중복 조건을 교체한 **26조합 × 5환경 × 3시드 = 390회**다. 7,790개 전수 탐색은 반복하지 않았다.
- `artifacts/balance-pass/before.json`·`.csv`: 수정 전 300회.
- `artifacts/balance-pass/after.json`·`.csv`: 최종 390회.
- `artifacts/balance-pass/comparison.csv`: 환경별 전후 DPS·전멸·처치 비교. 신규 후보는 수정 전 칸이 비어 있다.
- `artifacts/balance-pass/after-leaderboard.csv`: 같은 환경·조준·시간·위력·공속끼리의 후보 요약. 정가 대비 비율 순위는 실제 추가 구매 비용 순위와 다르다.
- `artifacts/balance-pass/jobs.json`, `followup-jobs.json`: 실행한 조건. `after-structure`는 씨앗 사거리를 늘리기 전 중간 실험이며 최종 결과가 아니다.

재실행은 다음 명령으로 한다. 마지막 사거리 변경은 관통 씨앗이 포함된 세 조합에만 영향을 주므로 나머지 첫 조정 결과를 재사용했다.

```powershell
python tools/measure_spells.py --input artifacts/balance-pass/jobs.json --output artifacts/balance-pass/recheck
python tools/measure_spells.py --input artifacts/balance-pass/followup-jobs.json --output artifacts/balance-pass/recheck-followup
```

## 관찰한 변화

아래 값은 같은 조건의 3회 평균이다. 서로 다른 환경의 DPS를 하나의 점수로 합치지 않았다.

| 조합 / 환경 | 수정 전 | 수정 후 | 해석 |
|---|---:|---:|---|
| 유도·갈래·꽃폭탄 → 소용돌이 / 단일 DPS | 143.33 | 115.91 | 부모 갈래 감소가 후속 장판에 적용됨 |
| 갈래·유도·메아리·별빛탄 → 부메랑 / 단일 DPS | 413.48 | 315.31 | 연계 상속으로 23.7% 감소. 여전히 강한 집중 공격 후보 |
| 갈래·유도·메아리·별빛탄 → 가시꽃 / 접근 적 처치 | 27.67 | 26.00 | 연계 피해를 줄여도 실제 처치 감소는 비교적 작음 |
| 거대 꽃폭탄 / 밀집 9명 전멸 | 3.69초 | 2.17초 | 넓은 범위의 장점을 살리면서 과도한 간격 페널티를 완화 |
| 관통 소용돌이 / 일렬 6명 | 15초 내 3명 | 11.14초 전멸 | 비행 거리가 늘어 뒤쪽까지 장판을 설치 |
| 관통 가시꽃 / 일렬 6명 | 15초 내 2명 | 7.76초 전멸 | 설치 지점이 앞·중간·뒤로 분산됨 |

**관통 씨앗에는 명확한 손해도 있다.** 관통 가시꽃의 단일 DPS는 60→20, 밀집 전멸은 1.83→4.88초다. 위력을 세 지점에 나누므로 한곳의 폭딜은 약해진다. 단일 적이나 좁은 무리는 일반 씨앗·거대화를, 긴 줄은 관통 씨앗을 고르는 방향이다. 분산된 적에게도 무조건 좋아지지 않는다. 이 교환이 구매 가치로 느껴지는지는 실제 플레이에서 확인해야 한다.

대안 후보 중 유도 없이 `갈래·메아리·관통·별빛탄 → 꽃폭탄`은 추가 구매 30G로 계속 접근 환경 평균 20명 처치였다. 기존 주력 조합은 34G로 18명이다. `거대 꽃폭탄`은 14G로 밀집 9명을 2.17초에 정리했다. 기존 주력은 34G로 1.91초다. 유도·갈래·메아리 조합이 모든 비용 구간과 환경에서 반드시 최선이라고 볼 근거는 없다. 동시에 고비용 유도·갈래·메아리 연계는 여전히 강하므로 다른 조합과 동등해졌다고 주장하지 않는다.

갈래·유도·별빛탄은 접근 환경 DPS 81.41로 가시꽃 단독 83.22를 넘지 않았다. 따라서 이번에는 갈래 기본 피해와 유도를 추가 하향하지 않았다. 공격 속도 보상은 이번 측정에서 변화시키지 않았으므로 선택률이나 강함을 판정하지 않았다.

## 기능 확인과 남은 판단

- 관련 마법 검사 50개, 측정 검사 33개 통과. 부모·자식 양쪽 갈래, 메아리, 공격력 변경 중 발사 시점 스냅샷, 씨앗 분할·남은 몫·도탄 조합·긴 줄 도달, 종료 시 정리를 포함한다.
- 최종 390회에서 원피해=유효 피해+과잉 피해, 효과별 기여 합산, 탄 180개·장판 24개 상한 위반 0건.
- 실제 게임 렌더링으로 일렬 표적의 다중 설치와 구매 비용 안내를 확인했다. `artifacts/balance-pass/piercing-seed-line.png`는 1.58초 시점의 진행 중 배치 확인이며 완료 결과 화면이 아니다.
- 기본 공격 5종의 단독 조합은 수정 전후 결과가 동일했다. 무관한 전체 게임 검사는 실행하지 않았다.
- 자동 조준과 고정 이동 경로는 사람의 조준 부담을 반영하지 않는다. 고정 표적 환경은 시드가 달라도 배치가 같고, 분산·접근 환경에서만 시드별 배치가 달라진다.
- 장판 교체 상한의 영향, 후속 주문을 빠른 탄으로 운반하는 이점, 부메랑의 짧은 나가는 구간은 남아 있다. 관통 부메랑은 이 일렬 배치에서는 개선이 없었지만 접근 환경에서는 단독 10명 대비 15.33명을 처치했다.
- 재미, 구매 선택의 다양성, 공속 보상 선호가 개선됐는지는 실제 한 판으로 판단해야 한다. 다음 콘텐츠 확장은 위력 배수보다 적의 위치와 공격 방식을 바꾸는 마법을 우선 검토한다.
