# 마법 특화 개편 — 구현·측정 보고

2026-10-22 · Godot 4.6.2 · Witchlings' Mayhem 0.6

기획의 기능 범위를 한 번에 연결했다. 22종 구체, 네 시작 꾸러미, 연구 구매, 조합 편집·시험, 실제 전투 엔진과 측정실까지 구현했다. **기능 완료이며, 재미와 최종 밸런스가 검증됐다는 뜻은 아니다.**

## 바로 해보기

F5 → 첫 실습 시작 → 꾸러미 선택. 꾸러미는 직업 제한이 아니라 시작 구체만 결정한다. 공통으로 별빛탄·명중 후를 지급한다.

| 꾸러미 | 시작 주문 | 시도할 행동 |
|---|---|---|
| 작은 정원 | 접목 → 소용돌이 | 같은 자리에 모아 심고 적을 유인하기 |
| 큰 한 발 | 응축 → 꽃폭탄 | 긴 시전 간격에 맞춰 여러 적을 한 번에 맞히기 |
| 반짝 연사 | 갈래 → 각인 → 별빛탄 | 같은 적에게 각인을 쌓아 폭발시키기 |
| 얼음 실험 | 서리숨결 → 명중 후 → 파쇄 → 별빛탄 | 가까이 접근해 얼린 뒤 깨뜨리기 |

웨이브 뒤 무료 패시브 → 60초 상점 → 다음 웨이브 흐름은 유지한다. 상점 첫 칸 **연구 목록**에서 원하는 구체를 정가로 한 번 구매할 수 있다. 나머지 세 칸은 무작위이며, 가능한 경우 한 칸은 현재 주문과 호환되는 관련 구체를 제안한다. 새 상품을 눌러도 연구 구매 횟수는 초기화되지 않는다. 세 번째 복사본과 불필요한 두 번째 연결 구체는 판매하지 않는다.

보유 구체는 스크롤 목록으로 표시한다. 6칸 드래그 편집·되돌리기·시험 발사를 유지했고, 같은 공격에 속하는 보조 구체를 위쪽 선으로 묶었다. 시험에서는 WASD·회피로 움직이며 위성·잔불도 확인할 수 있다. 상점 시간과 웨이브는 진행하지 않는다.

## 추가된 10종

| 종류 | 구체 | 실제 동작 |
|---|---|---|
| 보조 | 응축 | 해당 단계 피해 ×3, 전체 시전 간격 ×2.5. 냉기·각인·접목 성장량은 늘리지 않음 |
| 보조 | 접목 | 같은 계통의 소용돌이·덫이 가까이 설치되면 한 위치에 합쳐 최대 3단계 성장 |
| 보조 | 각인 | 기본 피해 ×0.85, 6스택에서 폭발. 같은 원시 시전의 갈래·지속 타격에는 축적 상한 적용 |
| 보조 | 파쇄 | 이미 얼어 있는 대상의 껍질을 한 번 소비해 추가 피해 |
| 공격 | 서리숨결 | 짧은 부채꼴, 냉기 3스택으로 동결. 보스는 이동 가능한 파쇄용 껍질만 얻음 |
| 공격 | 벼락 | 지정 지점에 0.45초 예고 후 낙하. 추적을 붙여도 마지막 0.15초는 위치 고정 |
| 공격 | 달무리 위성 | 플레이어 주위를 공전하며 접촉 피해. 연계로 나오면 발동 지점을 중심으로 공전 |
| 공격 | 잔불 발자국 | 최근 이동 경로에 최대 4조각 설치. 정지하면 발밑 하나. 겹칠 때 가장 강한 피해만 적용 |
| 연결 | 소멸 후 | 앞 주문의 정상 종료 위치에서 후속 시전. 화면 밖 제거·강제 정리에는 발동하지 않음 |
| 연결 | 귀환 후 | 부메랑을 실제로 회수했을 때 현재 조준 방향으로 후속 시전. 귀환 실패·시간 초과에는 발동하지 않음 |

총 공격 9종·보조 10종·연결 3종. 최대 6칸, 공격 2개와 연결 1개, 보조 → 공격 문법을 유지한다. 의미 없는 조합은 컴파일 시 이유를 표시한다. 예를 들어 접목+별빛탄, 추적+서리숨결, 관통+벼락, 메아리+위성은 허용하지 않는다.

접목은 중심을 이동시키거나 수명을 계속 연장하지 않는다. 처음 설치부터 최대 6초, 성숙 시 남은 피해 예산에 한 번만 보너스를 준다. 같은 시전에서 갈래·메아리를 많이 만들어 성장 횟수를 부풀리지 못한다. 미성숙 덫도 수명이 끝나면 부분 투자분으로 한 번 터진다.

전투 중 조합 변경 시 이미 날아간 탄·설치한 장판은 당시 설정으로 끝까지 동작하고, 다음 시전부터 새 조합을 쓴다. 서로 다른 적용 세대의 장판은 접목하지 않는다. 새 조합 적용으로 응축 대기 시간을 줄일 수 없다. 시험 편집은 이전 시험 효과를 정리하고 즉시 새 조합을 시작한다.

위성은 공격 단계별 최대 2세트(조합 변경 전후를 합산), 잔불은 전체 12조각, 전체 장판은 24개로 제한한다. 화면·웨이브 종료 시 상태·예약·공전·장판을 함께 정리한다. 현재 VFX는 기존 시제품 방식의 선·도형 표시를 확장한 것이며 최종 아트가 아니다.

초안의 낙뢰 예약 상한 48개는 구현에서 32개로 제한했다. 측정의 자리 변경 압박은 재현 가능한 큰 이동 경로를 사용한 근사이며, 초안의 원거리 공격을 보고 회피하는 자동 조작까지 구현한 것은 아니다. 성장·각인·동결·파쇄의 발생·피해 기여를 기록하지만, 모든 특화별 행동 지표를 별도 점수로 자동 요약하지는 않는다.

## 수치 조정과 측정 근거

초안 대비 **각인 폭발 기본 피해만 18 → 42**로 조정했다. 기본 피해 15% 감소를 감수하고 6스택을 쌓아도 18 피해로는 손실을 충분히 보상하지 못했다. 동일한 각인→별빛탄의 30초 단일 표적에서 유효 DPS는 43.4 → 51.4, 폭발 횟수는 10회로 같았다. 약한 적은 축적 전에 죽으므로 이 조정이 모든 상황의 화력을 올려주지는 않는다. 기존 마법 가격·피해·패시브·웨이브 보상은 이번 개편에서 바꾸지 않았다.

실제 전투 코드로 810회 측정 후 영향받는 조건 414회와 가격대 비교 75회를 실행했다. 총 1,299회 실행, 같은 조건의 재측정을 교체한 최종 자료는 **1,005개 조건**이다. 시드 731·732·733, 위력·공속 1, 6초/30초를 사용했다. 전수 조합의 최종 순위가 아니다. 전체 조합 생성기는 131,918개 정규화 조합을 생성하지만 이번에 전부 실행하지 않았다.

다음은 30초 한도, 가장 가까운 적 조준, 3시드 평균 유효 DPS다. 밀집·일렬·중장갑은 전멸 시 종료하므로 실제 소요 시간도 함께 봐야 한다. 같은 구체 수·비용을 정확히 맞춘 순위표가 아니며 가격을 명시했다.

| 조합 | 칸 / 정가 / 시작 꾸러미 제외 구매가 | 단일 | 밀집 | 일렬 | 계속 접근 |
|---|---|---:|---:|---:|---:|
| 추적·갈래·꽃폭탄 → 소용돌이 | 5 / 70G / 46G(각인) | 79.2 | 172.8 | 78.8 | 112.1 |
| 거대화·접목·소용돌이 → 꽃폭탄 | 5 / 72G / 26G(정원) | 30.7 | 103.4 | 16.7 | 116.4 |
| 거대화·관통·응축·별빛탄 → 꽃폭탄 | 6 / 74G / 26G(응축) | 42.1 | 91.4 | 73.8 | 99.1 |
| 메아리·추적·각인·별빛탄 → 꽃폭탄 | 6 / 82G / 46G(각인) | 93.1 | 111.3 | 77.7 | 109.7 |
| 거대화·서리숨결 → 파쇄·벼락 | 5 / 72G / 30G(서리) | 35.9 | 11.0 | 5.2 | 33.5 |

표의 화살표는 명중 후다. 기존 조합의 밀집 전멸은 3.12초, 접목은 5.23초, 응축은 5.91초, 각인은 4.85초였다. 계속 접근에서 평균 처치는 각각 45.7 / 46.7 / 40.0 / 44.7 / 3.7, 받은 피해는 184 / 204 / 316 / 216 / 348이다. 측정용 체력은 충분히 높였으므로 이 피해는 실제 생존을 뜻하지 않는다.

서리·위성·잔불에는 별도로 접근·이동하는 `build` 조작을 비교했다. 예를 들어 시드 731에서 서리→명중 후→파쇄→별빛탄은 단일 표적에 접근하면 50.9 DPS, 동결·파쇄 각 16회를 기록했다. 거대화·서리숨결→파쇄·벼락의 밀집은 멀리서 쏘면 3명만 처치했지만 접근하면 9명을 처리했다. **다른 이동 정책의 값을 공통 조건 순위에 섞지 않았다.** 자동 접근이 잔불에서 오히려 피격을 늘리는 경우도 있어 `build`는 최적 조작을 보장하지 않는다.

판단: 행동 차이는 생겼다. 그러나 기존 꽃폭탄 연계가 밀집·움직이는 중장갑에서 강하고, 응축은 빗나감·과잉 피해·긴 공백의 대가가 크며, 서리는 접근 부담 대비 보상이 약한 조건이 많다. 각인은 높은 체력의 지속 타격 대상에서 의미가 있고 약한 적 떼에서는 발동 전에 죽는 경우가 많다. 네 특화의 최종 균형이 맞았다고 단정하지 않는다.

## 검증

- 새 규칙·정리·상점·세대 분리: 128개 통과.
- 기존 마법 확장 회귀: 51개 통과.
- 드래그 작업대·되돌리기·시험 시간 분리: 41개 통과.
- 실제 피해/과잉 피해/기여 합계·측정실: 37개 통과.
- 합계 **257개 검사, 실패 0**. 피해 기여 합과 총 유효 피해의 최대 오차는 부동소수점 오차 수준인 7.1×10⁻¹¹ 미만.
- 네 꾸러미 × 3시드의 첫 웨이브 12회는 일반 체력으로 생존. 첫 상점 41~46G. 고정 원형 이동·근접 목표 조준·회피 미사용의 자동 조작 결과다.
- 별도로 높은 체력으로 네 꾸러미의 5웨이브 흐름 20개 기록을 검사했다. 보상·상점·다음 웨이브·결과 전환 오류 0. **이 검사는 난이도 통과 증거가 아니다.** 계속 도망가는 정원 조작은 마지막 보스를 120초 내 잡지 못했고, 다른 세 자동 조합은 처치했다.
- 실제 렌더 화면에서 꾸러미, 22종 보유 스크롤, 연구 구매, 접목 성장, 냉기/벼락 예고, 단계 묶음 표시를 확인했다.

## 실제 렌더 성능

1280×800 실행 창, 위력 1·공속 1.72의 갈래·메아리·접목·소용돌이→꽃폭탄. 렌더 프레임마다 실제 전투 갱신을 1/60초씩 수행했고, 60프레임 준비 후 360프레임을 측정했다. 계측은 PC 스케줄러·렌더·60Hz 동기화 영향을 포함한다. 소리·물리 프레임 자동 진행은 끄고 동일 갱신을 직접 호출한 비교 장면이다.

| 조건 | 프레임 p50 / p95 / p99 / 최대(ms) | 게임 갱신 CPU p95(ms) | 최대 탄 / 장판 / 드로콜 |
|---|---|---:|---|
| 적 10명 | 16.67 / 16.76 / 16.80 / 16.83 | 1.17 | 12 / 19 / 430 |
| 적 90명 | 16.67 / 17.51 / 18.44 / 19.33 | 12.73 | 6 / 8 / 472 |

보통 웨이브 동시 적 상한은 최대 48명이다. 90명 검사는 그보다 높은 강제 부하이며, 적들이 장판 중앙으로 겹쳐 장식과 몸체가 뭉쳐 보였다. 평균 60Hz만 보고 성능 여유가 충분하다고 단정할 수 없다. 보통 규모에서는 큰 프레임 중단을 관찰하지 않았지만, 90명에서는 16.7ms 예산을 넘기는 프레임이 있다. 모든 조합·하드웨어의 최악 상황을 보증하지 않는다.
