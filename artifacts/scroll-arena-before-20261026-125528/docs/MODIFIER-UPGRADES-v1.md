# 보조 구체 +4 강화 구현

> 2026-10-26 후속: 두 오브 측정·밸런스가 적용되었다. 갈래/메아리 현재 수치·후속 지분·장판 처리량은 [TWO-ORB-BALANCE-v1.md](TWO-ORB-BALANCE-v1.md)가 우선한다. 아래 수치는 해당 단계의 기록으로 보존한다.

## 적용 범위

갈래·추적·관통·연쇄·거대화·메아리·응축·각인 8종에 기본~+4를 적용했다. 공격 강화와 동일한 무료 동종 결합/화폐 +1 경로를 사용한다. 연결은 강화하지 않고, 기존 공격 완성형 합성 5종은 유지한다.

이번 단계는 역할 설계서의 기본 구체 하향안을 함께 적용하지 않는다. 직전 버전의 0단계 효과·중복 수치가 출발점이다. 따라서 이 문서의 수치가 SPELL-ROLES-AND-MODIFIER-UPGRADES.md의 초안 표보다 우선한다. 설계서의 갈래 예산 분할·메아리35%·응축 가산식·관통 적용 예외·새 겹침 규칙은 여전히 미적용이다.

### 관통의 공격별 적용

- 별빛탄/꽃폭탄: 첫 접촉은 기존 피해, 이후 관통 접촉/폭발은 단계 배율. 매번 배율을 거듭 곱하지 않는다.
- 부메랑: 출발과 귀환의 첫 접촉을 각각 기준으로 삼는다. 뒤 적에게만 배율.
- 소용돌이/가시꽃: 기존 설치 지분과 개수를 유지하고 설치 본체의 피해만 배율 적용. 성장 질량·후속 주문 지분은 증가하지 않는다.
- 서리: 원래 기본4명 뒤의 추가 관통 대상만 배율, 냉기량은 그대로.
- 벼락/위성/잔불: 이번에는 기존 직선 추가타격을 유지하며 그 추가타격 피해에 배율을 적용했다. 이 동작의 정체성/적용 예외 정리는 별도 후속 검토다.

## 중복 장착과 강화의 계산

n=오른쪽 해당 공격에 적용되는 같은 종류 보조 개수, r_i=각 보조의 rank, 평균 rank=Σr_i/n. n=0이면 해당 보조 미적용.

- 갈래: 분기1+2n, 각 위력=∏(0.65+0.05r_i). 강화는 분기 수를 늘리지 않는다.
- 추적: 성능1+0.5(n-1)+0.25Σr_i.
- 관통: 추가2n명/분산 지점, 피해 배율1+0.10×평균 rank.
- 연쇄: 추가2n명, 홉 위력(0.5+0.025×평균 rank)의 j제곱(j=1부터), 탐색거리160+10×평균 rank.
- 거대화: 크기1.6^n×(1+0.05×평균 rank), 대기1.2^n.
- 메아리: 각 구체마다 반복1회, 각 반복 위력0.55+0.05r_i. 높은 강화부터0.18/0.36…초에 실행. 동일 보조의 자리 교환은 결과를 바꾸지 않는다.
- 응축: 직접 피해3^n×(1+0.10×평균 rank), 대기2.5^n.
- 각인: 축적량n+0.15Σr_i, 직접 피해0.85^n. 원본 시전 계통+대상별0.25초 간격/최대 축적2×해당 계통이 적용한 최대 축적량. 다른 단계에서 더 높은 각인이 적용되어도 이미 쌓은 양은 유지하고 남은 한도만 사용한다.

평균을 쓰는 관통·연쇄·거대화·응축은 낮은 단계의 구체를 추가하면 강화 효율 부분이 내려갈 수 있다. 대신 추가 대상이나 기존 중복 배율이 붙는다. 같은 구성에서 한 구체의 rank를 올리는 것은 비감소한다. 이 절충은 UI의 실제 합산값으로 확인할 수 있다.

## 실행·강화·편집 계약

- 보조별 count와 source id/rank/slot을 보존하고 공격 단계마다 합산 프로필을 컴파일한다. 이후 연결된 자식은 자기 프로필을 한 번 사용한다. 부모의 보조를 다시 누적하지 않는다.
- 메아리 복사본/합성 내장 자식이 fan/echo를 끄면 이전 캐시의 남은 효과까지 꺼진다. 응축·rank 배율도 해당 피해 계산에서 한 번씩만 적용한다.
- 강화는 기본+기본→1,1+기본→2,2+기본→3,3+기본→4,1+1→2,2+1→3,2+2→4. 대상/재료 순서와 무관. +4 초과는 결과와 이유를 표시하고 재료·돈을 쓰지 않는다.
- 화폐 강화 가격·구체 기본 가격·상점 수입·재고 한도12는 기존 유지. 합치기는 실제 두 구체를 소비하고 하나를 만든다.
- 두 오브 장착분은 재고 예약이다. 여분 재료 우선, 없으면 실제 장착분까지 소비한다. 보조 소비로 인접 공격 연결을 지우지 않는다.
- 같은 보조가 여러 칸에 있을 때 UI에서 선택한 칸을 강화한다. 이미 다른 칸에 결과 등급이 있어도 새 결과 위치를 추적하여 선택/적용 강조를 유지한다.
- 제작 후 Undo·stale drag 무효화, 실행본·두 오브·시험 발사 즉시 반영. 기존 발사체의 스냅샷은 소급 변경하지 않는다.
- UI에 +단계 배지/실행 요약, 실제 합산 강화 전후, 선택 재료·소비량을 표시한다. 무료 합치기와 돈 강화의 결과가 다르면 버튼별 툴팁에 각각의 범위를 표시한다. 부족한 돈 때문에 실행은 막혀도 예상 효과는 볼 수 있다.
- 실패 quote의 inventory는 미리보기용 예상값이다. ok=false인 quote는 Economy.craft/game.craft_spell에서 적용하지 않는다.

예: [갈래+2,별빛탄,명중 후,꽃폭탄]과 다른 오브의 갈래+2를 합치면 첫 오브가 갈래+4로 바뀌고 다른 오브의 해당 보조는 사라진다. 미리보기에는 첫 오브 두 공격의75→85%와 다른 오브 공격의갈래 해제까지 기록된다.
